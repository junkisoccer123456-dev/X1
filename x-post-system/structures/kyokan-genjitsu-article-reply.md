# 構文名：共感列挙→企業目線の現実→記事リプ誘導型

## この構文が読まれやすい理由
- 冒頭が「最近〇〇な人が増えている」という観察なので、宣伝に見えず、自分も当てはまるかと読み始める。
- 共感パートで「事情は様々」と読者の言い分を先に全部受け止める。味方だと思わせてから落とす。
- 「ただ……」の一拍のあと、**企業側の視点**という読者が知らない事実を出す。ここで「このままだとまずい」という不安が立つ。
- 不安が立った状態で終わる。解決策は本文に書かない。
- リプで「詳しくはここに」と出すので、解決策を知りたい読者だけが記事に行く。押し売りにならない。

## 基本構造
```
①観察の提示（最近〇〇する人が増えている）
 ↓
②「なぜ今？」という疑問を代弁
 ↓
③共感の事情を3つ列挙（立場／環境／切実な思い）
 ↓
④「事情は様々」「本人にしか分からない地獄がある」で受け止める
 ↓
⑤「ただ……」で反転
 ↓
⑥企業側（選ぶ側）の視点の厳しい現実を提示
 ↓
⑦面接官の疑問・懸念を具体的に（疑われること／心配されること）
 ↓
⑧自分の見解で締める（早めに動かないと不利／保証はない時代）
 ↓
【リプ】解決策は記事にあると案内（対象者＋読んで損はない）＋リンク
```

## 抽象テンプレート
```
最近は、【属性・年齢】で【行動】する人が結構います。

【長年の経歴】なのに、なぜ今になって...？ と思うかもしれませんが、「【見えてきたもの】」ということだと思います。

【立場】になって、「【内心のセリフ】」と悩んだり、
【環境変化】で、「【内心のセリフ】」という状況に直面したり、
「【切実なセリフ】」という思いがあったり、
抱えている事情は様々です。

一見【表面上の状態】でも、その人にしか分からない【しんどさ】があります。

ただ......

厳しいのが、企業側の視点だと「【不利な属性】」は「【有利な属性】」よりよっぽど【不利益】で、【結果】になりやすいことです。

【面接官の疑問】と、面接官も思います。
【疑われること】もありますし、「【懸念】」と心配もされます。

【早めにやっておくべきこと】しておかないと、【今の状況】は色々と不利だよな、と思います。
【時代背景】だから。

【リプ】
【対象者】が【解決できること】は、ここに詳しく書いています。
【対象者】は、読んでおいて損はないです。
```

## 相性の良いテーマ
- 「手遅れ感」「このままでいいのか」を抱える層向けのテーマ
- 選ぶ側（企業・面接官・人事）の本音を知っている発信者が書けるテーマ
- 解決策が長く、投稿では書ききれないテーマ（記事・固定ポストへ送る前提）

## 相性の悪いテーマ
- 選ぶ側の視点が使えないテーマ
- 解決策が一言で済むテーマ（リプに送る意味がない）

## 文体・見た目のメモ
- 文章量：500〜700字の長文。段落ごとに空行で区切る
- 共感パートは「〜したり、」で3つ並べ、リズムを作る
- 「ただ......」は単独1行
- 断定は避け、「と思います」で見解として言う（煽りに見せない）
- リプは3〜4行で短く、宣伝感を出さない

## 注意点
- 不安を煽るだけで終わらせない。必ずリプで解決策へ送る。
- 現実の厳しさは「人格」ではなく「準備・経歴の見え方」に向ける。
- 数字や統計は根拠がなければ使わない。
