# 構文名：2列対比型

## この構文が読まれやすい理由
- 1行目が列ヘッダだけ。前置きも権威づけもなく、**表がいきなり始まる**。離脱する隙がない。
- 2つの群を**同時に左右に並べる**。片方を伏せてリプに回さないかわりに、
  比較そのものが価値になる。自分の候補が右側にあったら、そこで手が止まる。
- 各列10項目で情報量が出るので、保存される。
- リプがないので1投稿で完結する。連投を組まなくていい分、運用が軽い。
- 最後の1行で**どう読むかを指定する**。これがあることで、ただの表が主張になる。

## 基本構造
```
①❶【左群の名前】　　❷【右群の名前】（囲み数字でラベル、左右に並べる）
 ↓
②・項目　　　・項目 を10行、全角スペースで右列の開始位置を揃える
 ↓
③締め1行（片方の群が何を意味するかの解釈。もう片方には触れない）
```

## 抽象テンプレート
```
❶【左群の名前】　　❷【右群の名前】

・【左1】　　　　　・【右1】
・【左2】　　　　　・【右2】
（…10行）

左側は「【左群の意味づけ】」です。
```

## 相性の良いテーマ
- 2群に分けると差がはっきりするテーマ（難易度、前提条件、順番）
- 読者が自分の候補を探せるテーマ
- 片方を否定せずに並べられるテーマ

## 相性の悪いテーマ
- 片方が明確に悪とされるテーマ（否定が入ると角が立つ）
- 1項目ごとに説明が必要なテーマ
- 左右の項目数が揃わないテーマ

## ⚠️ 運用上の注意
- 片方の群を「ダメ」と読ませない。**難易度や前提条件の違いとして置く**のが作法。
  参考投稿も右側（経験が要る職種）を否定していない。
- 左右の項目数は必ず揃える。揃っていないと表に見えなくなる。
- 締めの1行は片方だけに触れる。両方に触れると長くなって締まらない。

## 文体・見た目のメモ
- 全体で200〜300字
- 記号は囲み数字（❶❷）と ・ のみ
- 全角スペースで列を揃える。左列は11〜13文字幅に収めると、スマホで崩れにくい
- 表の部分は体言止め、締めの1行だけ です・ます調にすると締まる
- CTAは入れない
