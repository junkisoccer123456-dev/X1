# 構文名：二択→片方推し→理由3つ型

## この構文が読まれやすい理由
- 1行目が**条件の揃った二択**（数字と働き方をセットにした2つの選択肢）。
  読者は読み始めた瞬間に自分の答えを決めるので、続きを「採点」として読む。
- 2行目で**どちらかを言い切る**。「人によります」を書かないので、賛否が生まれて伸びる。
  強い語（「マジで」）を1つだけ混ぜると、断定が意見として受け取られる。
- 理由を①②③の3行に圧縮する。1行1理由で解説を書かないので、読む負荷がほぼゼロ。
- 理由の並べ方が**時間軸**になっている（今 → 市場での評価 → あとから取り返せるか）。
  3つ目で「逆は無理」と**不可逆性**を出すのが決め手。ここで反論が消える。
- 締めが1行の言い換え。選ばなかった側を否定せず、「順番の話」に落とすので角が立たない。
- 全体が200字前後。二択の投稿はリプ欄で議論が起きるので、本文は短いほうが効く。

## 基本構造
```
①【選択肢A：数字＋条件】と、【選択肢B：数字＋条件】。（二択を1行で提示）
 ↓
②【対象読者】が選ぶべきは【どちらか】です。（言い切る。強い語を1つ）
 ↓
③①【理由1：今の負荷が将来の何に変わるか】
 ↓
④②【理由2：市場での評価がどう動くか】
 ↓
⑤③【理由3：あとから取り返せるかどうか（不可逆性）】
 ↓
⑥締め1行（選ばなかった側を「順番」として肯定する）
```

## 抽象テンプレート
```
【条件A1】で【条件A2】の【選択肢A】と、
【条件B1】で【条件B2】の【選択肢B】。
【対象読者】で選ぶべきは【A か B】です。

①【選んだ側の負荷】は【将来の資産】に変わる
②【選んだ側の属性】で【評価される場所】の見方が一段上がる
③【選ばなかった側】は後からでも行けるけど、逆は無理

【選ばなかった側】は【時期】からで十分です。
```

## 相性の良いテーマ
- 条件が数字で揃えられる二択（年収、勤務時間、規模、年数）
- どちらを選ぶ人もいる、答えが割れているテーマ（割れていないと議論が起きない）
- 「あとから取り返せるかどうか」で差がつくテーマ（不可逆性が理由3になる）

## 相性の悪いテーマ
- 片方が明らかに正解のテーマ（当たり前の話になる）
- 健康・家庭・体調が絡む二択（断定すると無責任になる。この型では扱わない）
- 条件が揃わない二択（比較にならず、ただの好みの話になる）

## 文体・見た目のメモ
- 文章量：160〜240字。短さが武器。解説を足した瞬間に型が死ぬ
- 1行の長さ：理由の3行は20〜30字で揃える
- 改行/空行の使い方：二択2行＋断定1行＋空行＋理由3行＋空行＋締め1行
- 絵文字：参考投稿になし。使わない。記号は囲み数字（①②③）のみ
- 理由に数字（「年収が◯万上がる」）を入れない。入れるなら根拠が必要になる型

## ⚠️ 運用上の注意
- 二択の数字は**実在の会社の提示額として書かない**。
  「年収◯◯万で△△な会社」という条件の組み合わせとして置く（個社の断定を避ける）
- 選ばなかった側を「ダメ」と書かない。この型は「順番の話」に落とすのが作法
- 体を壊す・家庭が壊れる水準の働き方を推す使い方はしない。
  推すのは**負荷と引き換えに何が残るか**の話に限る
