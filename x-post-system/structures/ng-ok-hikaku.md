# 構文名：NG連打→OK提示型

## この構文が読まれやすい理由
- 同じラベル（「お見送りの人」）を繰り返してNG例を並べるので、**リズムで読まされる**。
- NGがセリフそのままなので、読者は自分の回答と照合してしまい、当事者になる。
- 本文では正解を出さない。「では、どう答えるか..」で切るため、リプが必ず開かれる。
- リプ1で正解のセリフ、リプ2で原理の解説、と**二段階で引っぱる**ので滞在時間が伸びる。
- 「99%お見送り」のような強い断定は、選ぶ側の立場だから許される。立場と主張が一致している。

## 基本構造
```
①「〇〇、△△したら一発アウトです。」の断定フック
 ↓
②ラベル＋NGセリフ（同じラベルを3回繰り返す）
 ↓
③「これ99%〇〇です。では、△△はどう答えるか..」で切る
 ↓
④【リプ1】ラベル＋OKセリフ（軸を変えて3パターン）
　　　　　＋「本当に見ているポイントは...↓」で再度引っぱる
 ↓
⑤【リプ2】原理を①〜④の見出し＋解説で提示
```

## 抽象テンプレート
```
【場面】、【一見正しそうな行動】は一発アウトです。

【NGのラベル】
「【NGセリフ1】」
【NGのラベル】
「【NGセリフ2】」
【NGのラベル】
「【NGセリフ3】」

これ【強い断定】です。
では、【成功する人】はどう答えるか..

【リプ1】
【OKのラベル】（【軸1】）「【OKセリフ1】」
【OKのラベル】（【軸2】）「【OKセリフ2】」
【OKのラベル】（【軸3】）「【OKセリフ3】」
じつは、【立場】が本当に見ているポイントは...↓

【リプ2】
【 〇〇で絶対に抑えるべきn個のポイント 】
①【見出し】＋解説
②〜④
```

## 相性の良いテーマ
- 答え方・書き方・伝え方で結果が変わるテーマ（転職理由、志望動機、自己PR、逆質問）
- NGとOKをセリフで書き分けられるテーマ

## 相性の悪いテーマ
- 正解が人によって変わるテーマ（言い切れない）
- セリフにできないテーマ

## バリエーション

### A. 本文内で逐次解説する長尺版（参考投稿⑨）
リプに逃がさず、本文で「1つ目〜5つ目」を解説しきる派生。
各項目を「NG表現の引用 → 何が問題か → どう読まれるか → 言い換え」の4行で統一する。
冒頭に「真面目に書いているつもりでも」と書き手を責めない予防線を置くのがポイント。
参考：`../references/2026-09-23/10-職務経歴書NG表現.md`

### B. 4連打＋模範解答型（2026-09-23 追加・参考投稿⑦）
NGを**4連打**にし、各NGの直後に一言斬り（「→ 根拠ゼロ。交渉材料なし。」）を入れる派生。
畳みかける圧が出るぶん、正解の重みが増す。
正解はリプに逃がさず、**本文内で長文の模範解答を見せきる**。そのまま暗記素材として保存される。
絵文字でラベルを立ててもよい（面接官／お見送り／内定）。
参考：`../references/2026-09-23-nori/07-希望年収NG4連打.md`

### C. Q&A一問一答型（2026-09-23 追加・参考投稿②）
NG1つ＋OK1つだけの最小構成。1投稿1質問なので短文アカウントに向く。

```
①冒頭に方法論のラベル（「〇〇は3つの角度から攻めると論破できます」）
 ↓
②Q.【面接での質問】
 ↓
③NG：【一行の悪い回答】
 ↓
④OK：「【そのまま使える長めのセリフ】」
```
OK例は長めにして、暗記素材として使える形にするのがポイント。
参考：`../references/2026-09-23-kei/02-NGOK一問一答.md`

**2026-10-05 追記（参考投稿⑤）**：同じ骨格で、NG/OKのラベルを ❌／⭕️ の記号にして
末尾にCTAを付けた形も確認。冒頭1行は方法論のラベルではなく
**答えの結論**（「〇〇は、他社では言えない理由にするのが答えです↓」）にしてもよい。
記号は ❌NG ／ ⭕️OK と、記号＋英字の2文字セットで書く。

## 文体・見た目のメモ
- 文章量：本文200〜300字／リプ各300〜400字
- セリフは必ずカギ括弧で囲む
- 絵文字なし
- 断定を使うが、根拠のない割合（99%など）は**肌感と分かる書き方**にする

### D. カード型NG/OKリスト（2026-09-29 追加・参考投稿①②）
セリフではなく**リストで比較**する派生。
冒頭で世間の言い分を一度肯定し、「ただし資格のほうに期限がある」と切り返してから、
NG群を本文に、OK群をリプに置く。

```
①世間の言い分をカギ括弧で肯定（「転職はいつでもできる」けど）
 　または事実の提示（〇〇の求人はいつでもあります。ただ、扱ってもらえる期間には終わりがある）
 ↓
②「〇〇カード」と言い換えて希少性を作る（切れば無くなる手札として扱う）
 ↓
③【使わないほうがいい群】を2行に圧縮して列挙（1つずつ吟味させない）
 ↓
④「逆に〇〇カードを使うべきなのは↓」で切る
 ↓
⑤【リプ】使うべき群を1行1項目で縦に並べる（じっくり読ませる）
 ↓
⑥一言だけ推しを添える（特に〇〇かなと）。無くても成立する
```

同じリストでも、NGは横に詰め、OKは縦に開く。ここが意図的な設計。
参考投稿は ❌ ⭕️ で群を分けているが、絵文字禁止のアカウントでは
【使わないほうがいい】【使うべき】の括弧見出しに置き換える。
参考：`../references/2026-09-29-haru/01-カード型NGOKリスト.md`

### E. ❌5連打→⭕️リプ長文型（2026-10-05 追加・参考投稿⑥）
本文は「一生〇〇できない人の行動」と断定してから ❌やりがち を5項目。
❌側だけで本文を終わらせ、⭕️の中身は出さずに ⇩ で切る。
【リプ】は保存誘導から入り、方法を①〜④の見出し＋解説で出す。
そのあとに**常識否定の段落**と「AとBは違う」の対比を置き、本質の一言で締めてCTA。

```
一生【結果】できない人の行動
❌やりがち
・【行動1】
・【行動2】
・【行動3】
・【行動4】
・【行動5】

⭕️【期間】で【成果】する方法⇩

【リプ】
【この投稿は必ず保存して実践してください】

①【方法の名前】（【カッコで補足】）
【なぜ従来がダメか】。【原理】。【AよりBが正解】。

②【方法の名前】
【やめること】。【代わりにやること】。【これで何が変わるか】。

③【方法の名前】
【原因】。【具体的な方法】。【効果】。

④【方法の名前】
【やること】。【従来の否定】。【効果】。

多くの人が「【世間の常識】」が【目的】だと思っている。
でも、【前提】を無視した【根性論】は、【疲れるだけの結果】で何一つ【残らない】。

「【やった気になる行動】」と
「【本質的に効く行動】」は違う。

本質を掴めば、
【高いコスト】をかけなくても、【身近な環境】で【成果】は爆発的に伸びる。

【CTA】
```

❌と⭕️はそのまま使う（【】の見出しに置き換えない）。
本文は200字以内に収めて、長文は全部リプに逃がすのがこの型の勘所。

### F. NG/OK1組＋動詞書き換え処方型（2026-10-05 追加・参考投稿⑤）
バリエーションC（一問一答）の派生。Q.を置かず、冒頭で**損している箇所を名指し**してから
NG1行／OK2行を見せ、最後に**どの単語をどう書き換えるか**という汎用の処方で締める。

```
①【対象読者】が【場面】で損してる【箇所】。
 ↓
②変えるべきは「【やめるべき書き方】をやめる」こと。
 ↓
③NG
　 【悪い1行】。
 ↓
④OK
　 【良い書き方（改行して2行。数値のビフォーアフターを入れる）】
 ↓
⑤「【NGの動詞】」と「【OKの動詞】」は天と地の差があります。
 ↓
⑥僕が見てるのは、【表面的なもの】より、【本質的なもの】です。
 ↓
⑦【直し方を1文で】。動詞を「【NG動詞】」から「【OK動詞1】」「【OK動詞2】」「【OK動詞3】」に
　 書き換えるだけでいいです。
```

この型の核は**最後の一文**。NG/OK例は1組しか出さないので、
「動詞を3つのうちどれかに変えるだけ」という**持ち帰れるルール**が価値になる。
NG側は1行で短く、OK側は改行して2行にする。長さの差がそのまま情報量の差に見える。
OK例には必ず**数値のビフォーアフター**（800ms→120ms）を入れる。ここが説得力の全部。
