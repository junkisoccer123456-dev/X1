# 構文名：NG連打→OK提示型

## この構文が読まれやすい理由
- 同じラベル（「お見送りの人」）を繰り返してNG例を並べるので、**リズムで読まされる**。
- NGがセリフそのままなので、読者は自分の回答と照合してしまい、当事者になる。
- 本文では正解を出さない。「では、どう答えるか..」で切るため、リプが必ず開かれる。
- リプ1で正解のセリフ、リプ2で原理の解説、と**二段階で引っぱる**ので滞在時間が伸びる。
- 「99%お見送り」のような強い断定は、選ぶ側の立場だから許される。立場と主張が一致している。

## 基本構造
```
①「〇〇、△△したら一発アウトです。」の断定フック
 ↓
②ラベル＋NGセリフ（同じラベルを3回繰り返す）
 ↓
③「これ99%〇〇です。では、△△はどう答えるか..」で切る
 ↓
④【リプ1】ラベル＋OKセリフ（軸を変えて3パターン）
　　　　　＋「本当に見ているポイントは...↓」で再度引っぱる
 ↓
⑤【リプ2】原理を①〜④の見出し＋解説で提示
```

## 抽象テンプレート
```
【場面】、【一見正しそうな行動】は一発アウトです。

【NGのラベル】
「【NGセリフ1】」
【NGのラベル】
「【NGセリフ2】」
【NGのラベル】
「【NGセリフ3】」

これ【強い断定】です。
では、【成功する人】はどう答えるか..

【リプ1】
【OKのラベル】（【軸1】）「【OKセリフ1】」
【OKのラベル】（【軸2】）「【OKセリフ2】」
【OKのラベル】（【軸3】）「【OKセリフ3】」
じつは、【立場】が本当に見ているポイントは...↓

【リプ2】
【 〇〇で絶対に抑えるべきn個のポイント 】
①【見出し】＋解説
②〜④
```

## 相性の良いテーマ
- 答え方・書き方・伝え方で結果が変わるテーマ（転職理由、志望動機、自己PR、逆質問）
- NGとOKをセリフで書き分けられるテーマ

## 相性の悪いテーマ
- 正解が人によって変わるテーマ（言い切れない）
- セリフにできないテーマ

## バリエーション

### A. 本文内で逐次解説する長尺版（参考投稿⑨）
リプに逃がさず、本文で「1つ目〜5つ目」を解説しきる派生。
各項目を「NG表現の引用 → 何が問題か → どう読まれるか → 言い換え」の4行で統一する。
冒頭に「真面目に書いているつもりでも」と書き手を責めない予防線を置くのがポイント。
参考：`../references/2026-09-23/10-職務経歴書NG表現.md`

### B. 4連打＋模範解答型（2026-09-23 追加・参考投稿⑦）
NGを**4連打**にし、各NGの直後に一言斬り（「→ 根拠ゼロ。交渉材料なし。」）を入れる派生。
畳みかける圧が出るぶん、正解の重みが増す。
正解はリプに逃がさず、**本文内で長文の模範解答を見せきる**。そのまま暗記素材として保存される。
絵文字でラベルを立ててもよい（面接官／お見送り／内定）。
参考：`../references/2026-09-23-nori/07-希望年収NG4連打.md`

### C. Q&A一問一答型（2026-09-23 追加・参考投稿②）
NG1つ＋OK1つだけの最小構成。1投稿1質問なので短文アカウントに向く。

```
①冒頭に方法論のラベル（「〇〇は3つの角度から攻めると論破できます」）
 ↓
②Q.【面接での質問】
 ↓
③NG：【一行の悪い回答】
 ↓
④OK：「【そのまま使える長めのセリフ】」
```
OK例は長めにして、暗記素材として使える形にするのがポイント。
参考：`../references/2026-09-23-kei/02-NGOK一問一答.md`

## 文体・見た目のメモ
- 文章量：本文200〜300字／リプ各300〜400字
- セリフは必ずカギ括弧で囲む
- 絵文字なし
- 断定を使うが、根拠のない割合（99%など）は**肌感と分かる書き方**にする
