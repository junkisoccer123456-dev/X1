# 構文名：視点反転→問い→両方肯定型

## この構文が読まれやすい理由
- リストも数字も記号も使わない**地の文だけの短い投稿**。
  リストが並ぶタイムラインでは、文章だけの投稿のほうが逆に目が止まる。
- 1行目が「迷っている人の行動の癖」の指摘（外に目が向きやすい）。
  責めていないのに、当てられた感じがするので読み進める。
- 2行目で**視点を反転させる**（今いるから積めるものもある）。
  煽らずに反対側の事実を置くだけなので、反発が出ない。
- 真ん中に**持ち帰れる問い**を1つだけ置く（「ここであと1年いたら何が増えるか」）。
  答えを与えずに問いで止めるので、読者の頭の中で考えが続く。
- 締めが**両方の選択を肯定する**（残るのも立派な選択）。
  「転職しろ」とも「残れ」とも言わないので、どちらの立場の読者も保存できる。
- 全体で140字前後。発信者の人格だけが残るタイプの投稿なので、フォローにつながる。

## 基本構造
```
①【迷っている人の行動の癖】を1行で指摘する（〜すると、〜が向きやすい）
 ↓
②「でも」で視点を反転させる（今の場所だから得られるものを2つ並べる）
 ↓
③急ぐ前に確認したいことを**問いの形**で1つ置く（「〜したら何が増えるか」）
 ↓
④選ばれにくい側の選択を肯定して締める（〜なら、それは立派な選択だと思う）
```

## 抽象テンプレート
```
【迷う場面】と、【目が向きやすい方向】に目が向きやすい。
でも【今の場所】だから【得られるもの1】や、【今いるから積める経験2】もある。
【急いで決めがちなこと】を急ぐ前に「【持ち帰れる問い】」は見ておきたい。
【選ばれにくい側】にも意味を持たせられるなら、それは立派な選択だと思う。
```

## 相性の良いテーマ
- 二者択一で迷っている読者がいるテーマ（辞めるか残るか、受けるか待つか）
- どちらを選んでも正解になりうるテーマ（片方が明確に正解だと、この型は嘘になる）
- 行動の前に一度立ち止まる価値があるテーマ

## 相性の悪いテーマ
- 社名・数字・手順が主役のテーマ（この型は地の文しかないので情報を載せられない）
- 片方を強く推したいテーマ（両方肯定の締めと矛盾する）
- 危険を知らせるテーマ（立ち止まらせる型なので、警告には向かない）

## 文体・見た目のメモ
- 文章量：130〜160字。改行も空行もなし、または1か所だけ
- 1行の長さ：句点で自然に折る。箇条書きにしない
- 絵文字：参考投稿になし。使わない。記号もいっさい使わない
- 語尾：「〜と思う」で締めると押し付けにならない。断定しない唯一の型
- 一人称は出さなくてよい（haruの参考投稿も出していない）

## ⚠️ 運用上の注意
- 問いは**1つだけ**にする。2つ置くと考えが散って保存されない
- CTAを置かない。両方肯定の締めのあとに誘導を足すと、途端に宣伝に見える
- 「どちらでもいい」で終わらせない。**選ばれにくい側を肯定する**のが締めの役割
