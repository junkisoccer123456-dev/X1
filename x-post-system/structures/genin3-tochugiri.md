# 構文名：原因3つ→語の途中で切る型

## この構文が読まれやすい理由
- 1行目が**矛盾の提示**（「Aは通るのに、Bで落ち続ける」）。
  読者の頭の中にある「なぜだろう」をそのまま文字にするので、自分の話として読み始める。
- 「原因は、だいたい3つのどれかです」で**範囲を有限にする**。
  3つなら読める、と判断されるので離脱しない。「どれか」なので責められている感じがしない。
- 核心は3つ目を**語の途中で切る**こと。
  「3. 志望動機が、」で終わるので、文として未完成のまま目が止まる。
  「続きは↓」のような誘導文を一切使わずにリプを開かせられる。
- リプの1行目が**切った続きの文節から始まる**。
  読者の頭の中で文が繋がるので、リプが「答え合わせ」として読まれる。
- リプの後半で**相手側の感情**を代弁する（「ここで一番がっかりします」）。
  自分が損していることが具体的に見えるので、最後の行動提案が受け入れられる。
- 締めが「今日できる1つの確認作業」。負荷が低いので保存される。

## 基本構造
```
①【状態A】は通るのに、【状態B】で落ち続ける人。（矛盾を1行で提示）
 ↓
②原因は、だいたい3つのどれかです。（範囲を有限にする）
 ↓
③1. 【原因1：ズレの指摘】
 ↓
④2. 【原因2：終わり方の指摘】
 ↓
⑤3. 【原因3の主語だけ書いて、助詞で切る】
 ↓
⑥【リプ】切った続きの文節から再開して、原因3を言い切る
 ↓
⑦なぜそれが致命的なのかを2行（期待とのギャップの形にする）
 ↓
⑧相手側の感情を代弁する1行（「ここで一番がっかりします」）
 ↓
⑨今日できる確認作業を1つだけ提案する
 ↓
⑩「それだけで変わります」で締める（CTAなし）
```

## 抽象テンプレート
```
【通過する工程】は通るのに、
【落ちる工程】で落ち続ける人。
原因は、だいたい3つのどれかです。

1. 【書いたこと】と【話す内容】がずれている
2. 【理由の説明】が、【視点が外に向いたまま】終わっている
3. 【原因3の主語】が、

（リプ）
【原因3の続き】になっている。

【工程A】で「【相手の期待】」と思わせたのに、
【工程B】では別の人に見える。
【相手】は、ここで一番がっかりします。

【工程B】の前に、【今日できる確認作業】をしてみてください。
【確認する観点】が同じか。それだけで変わります。
```

## 相性の良いテーマ
- 「前の工程は通るのに次で落ちる」構造があるテーマ（書類→面接、一次→最終、内定→入社後）
- 原因が3つくらいに収まるテーマ（4つ以上は切る位置がぼやける）
- 3つ目に一番言いたいことを置けるテーマ（切るのは3つ目なので、そこが本題になる）

## 相性の悪いテーマ
- 原因が1つしかないテーマ（3つ並べる意味がない）
- 原因が人や環境のせいで終わるテーマ（読者が今日動けないので締まらない）
- 社名・数字が主役のテーマ（この型は文章の未完成で引くので、リストには向かない）

## 文体・見た目のメモ
- 文章量：本文120〜160字／リプ180〜240字。本文は短いほど切れ目が目立つ
- 1行の長さ：原因の3行は長さを揃える（揃えると3つ目が切れていることが際立つ）
- 改行/空行の使い方：フック2行＋空行＋原因3行。原因の間に空行は入れない
- 絵文字：参考投稿になし。使わない
- 切る位置は**助詞のあと**（「が、」「は、」「を、」）。名詞で切ると未完成に見えない

## ⚠️ 運用上の注意
- 原因を4つ以上にしない。3つで「どれか」が成立する
- リプで原因1・2に戻らない。切った3だけを回収して、原則に上げる
- 締めにCTAを置かない。参考投稿も置いていない。
  「今日やること1つ」で終わるほうが、この型は保存される
