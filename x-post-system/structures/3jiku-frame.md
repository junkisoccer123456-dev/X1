# 構文名：3軸フレーム提示型

## この構文が読まれやすい理由
- 型（フレーム）と記入例だけで、解説がない。**読者が自分の場合を埋めたくなる**。
- 3行で終わるので、読む前に読み切れると分かる。保存のハードルが極端に低い。
- 「99%聞かれる」のような**避けられなさ**を頭に置くと、準備しない理由がなくなる。
- 穴埋めできる形なので、そのままテンプレートとして使われ、引用されやすい。
- 短いのに実用度が高いため、投稿の間を埋める「軽い一本」としても使える。

## 基本構造
```
①「〇〇は、3つの軸で答えると【相手】も納得する」
 ↓
②【例】
 ↓
③軸1（範囲）：内容
 ↓
④軸2（範囲）：内容
 ↓
⑤軸3（範囲）：内容
```

## 抽象テンプレート
```
【避けられない場面】で必ず問われる【対象】は、
3つの軸で答えると【相手】も納得します

【例】
【軸1の名前】（【範囲】）：【内容】
【軸2の名前】（【範囲】）：【内容】
【軸3の名前】（【範囲】）：【内容】
```

## 相性の良いテーマ
- 3つに分解すると整理できるテーマ（時間軸、対象軸、目的軸）
- 「何を答えればいいか分からない」と悩まれているテーマ
- 記入例を出せるテーマ

## 相性の悪いテーマ
- 3つに割れないテーマ（無理に割ると嘘になる）
- 例が具体的に書けないテーマ（フレームだけだと薄い）

## 文体・見た目のメモ
- 文章量：100〜150字。これ以上長くしない
- 軸の名前は短く（短期・中期・長期／現在・過去・未来 など）
- 例は必ず1セット入れる。フレームだけでは保存されない
- 絵文字なし

## バリエーション

### B. 検討項目型（●＋→解説＋CTA／2026-10-05 追加・参考投稿②）
フレームの穴埋めではなく、**動く前に考えるべき検討項目**を3つ出す派生。
原型（100〜150字）より長く、1本400〜600字になる。

```
『【読者が思っていること】』と思った時に考えて欲しい事。

以下挙げるポイントを考えずに、とにかく【目先の行動】だけを【目的】にしてしまうと、
【どうなるか（具体的な悪い状態）】可能性が高い。

●【検討項目1】
→【何を整理するのか】。【できていない人への一言】。

●【検討項目2】
→【別の観点】。【特定の読者層への呼びかけ】。

●【検討項目3】
→【見落とされがちな観点】。【どう判断するか】。

上記の内容を整理しても納得できない場合は、
一人で抱え込まずに第3者に相談するべき。
“【目先の感情】”を“【本質的な問い】”に変換することが、後悔しない【領域】選択に繋がります。

誰に相談するか迷ったら...↓
【CTA】
```

ポイントは3つ。
- 冒頭で「考えずに動くとどうなるか」を**具体的な悪い状態**で予告する（ジョブホッパーになる など）
- ●の項目名は体言止め、→ の解説は2文まで
- 締めは**言い換えの一言**（“辞めたい”を“どう生きたい”に変換）。ここが引用されやすい
