# 構文名：3軸フレーム提示型

## この構文が読まれやすい理由
- 型（フレーム）と記入例だけで、解説がない。**読者が自分の場合を埋めたくなる**。
- 3行で終わるので、読む前に読み切れると分かる。保存のハードルが極端に低い。
- 「99%聞かれる」のような**避けられなさ**を頭に置くと、準備しない理由がなくなる。
- 穴埋めできる形なので、そのままテンプレートとして使われ、引用されやすい。
- 短いのに実用度が高いため、投稿の間を埋める「軽い一本」としても使える。

## 基本構造
```
①「〇〇は、3つの軸で答えると【相手】も納得する」
 ↓
②【例】
 ↓
③軸1（範囲）：内容
 ↓
④軸2（範囲）：内容
 ↓
⑤軸3（範囲）：内容
```

## 抽象テンプレート
```
【避けられない場面】で必ず問われる【対象】は、
3つの軸で答えると【相手】も納得します

【例】
【軸1の名前】（【範囲】）：【内容】
【軸2の名前】（【範囲】）：【内容】
【軸3の名前】（【範囲】）：【内容】
```

## 相性の良いテーマ
- 3つに分解すると整理できるテーマ（時間軸、対象軸、目的軸）
- 「何を答えればいいか分からない」と悩まれているテーマ
- 記入例を出せるテーマ

## 相性の悪いテーマ
- 3つに割れないテーマ（無理に割ると嘘になる）
- 例が具体的に書けないテーマ（フレームだけだと薄い）

## 文体・見た目のメモ
- 文章量：100〜150字。これ以上長くしない
- 軸の名前は短く（短期・中期・長期／現在・過去・未来 など）
- 例は必ず1セット入れる。フレームだけでは保存されない
- 絵文字なし
