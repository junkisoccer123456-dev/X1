# 構文名：2タイプ分類→攻略提示型

## この構文が読まれやすい理由
- 「2種類のパターンが存在します」と言われると、読者は**自分が当たるほうを知りたくなる**。ここで離脱が止まる。
- 分類そのものが新情報になる。世の中で名前がついていないものに名前をつけると、それだけで価値が出る。
- 分類のあとにタイプ別の処方が来るので、読者は自分に関係ある側だけ読めばいい。読む負荷が低い。
- 権威づけが数字（支援人数など）なので、分類の信頼性が担保される。分類は「見てきた量」が根拠になる型。
- 短い。3〜5行で完結するので、長文が並ぶタイムラインで逆に目立つ。

## 基本構造
```
①権威づけ（見てきた量・立場）＋「〇〇には2種類のパターンが存在します」
 ↓
②① タイプAの名前
　 ② タイプBの名前
 ↓
③①は、【攻略法】と刺さる
 ↓
④②は、【攻略法】と刺さる
```

## 抽象テンプレート
```
【権威づけ：見てきた量】して気づきましたが
【対象】には2種類のパターンが存在します

① 【タイプAの名前】
② 【タイプBの名前】

①は、【Aに効く行動・話し方】と刺さる

②は、【Bに効く行動・話し方】と刺さる
```

## 相性の良いテーマ
- 相手（面接官、上司、評価者、会社）が2つに分かれるテーマ
- タイプによって取るべき行動が変わるテーマ
- 分類に名前をつけられるテーマ

## 相性の悪いテーマ
- 3タイプ以上に分かれるテーマ（2つだから読みやすい。増やすと普通のリストになる）
- タイプ別の処方が同じになるテーマ（分ける意味がない）

## 文体・見た目のメモ
- 文章量：100〜200字。短さが武器
- タイプ名は「〇〇型」で統一すると覚えられやすい
- 断定でよい（「100%刺さる」のような強さが、この型では効く）
- 絵文字なし
