# 構文名：厳しい現実→条件提示型

## この構文が読まれやすい理由
- 「不可能ではないですが」と**一度肯定してから落とす**ので、頭ごなしの否定より最後まで読まれる。
- 条件の並べ方が誇張気味（「三刀流みたいな人」）で、否定なのに笑える。強い主張なのに角が立ちにくい。
- 短い。2段落で終わるため、長文が続くタイムラインで逆に目立つ。
- 最後に通過条件を①②③で出すので、「で、どうすれば？」の答えがある。ただの冷や水で終わらない。
- **選ぶ側の立場でしか言えない内容**なので、同じ主張でも重みが違う。

## 基本構造
```
①「〇〇は不可能ではないですが」と一度肯定
 ↓
②実現に必要な条件を誇張して列挙（「〜を全部積んだ人ならいけます」）
 ↓
③さらに不利な事実を1行足す
 ↓
④【改行】
 ↓
⑤通る人の条件を①②③で提示
 ↓
⑥「これが揃わないと厳しいです」と言い切って終わる
```

## 抽象テンプレート
```
【難しい挑戦】は不可能ではないですが「【条件A】・【条件B】・【条件C】」を
全部積んだ【誇張した例え】みたいな人ならいけます。さらに【不利な事実】。

【挑戦】で通るのは ①【必要条件1】 ②【必要条件2】 ③【必要条件3】
これが揃わないと厳しいです。
```

## 相性の良いテーマ
- 願望と現実にギャップがあるテーマ（未経験転職、年収大幅アップ、短期間での成果）
- 世間で「できます」と言われがちで、実際は条件が厳しいテーマ
- 発信者が選ぶ側・審査する側の立場で語れるテーマ

## 相性の悪いテーマ
- 条件が人によって大きく変わるテーマ（言い切ると嘘になる）
- 数字の根拠が必要なテーマ（この型は短いので根拠を書ききれない）

## 文体・見た目のメモ
- 文章量：150〜250字。**この構文は短さが武器**なので長くしない
- 断定で終える。語尾をぼかさない
- 絵文字なし。CTAも入れない（言い切りの余韻で終わらせる）
- 「肌感です」を一言入れると、断定しつつ誠実に見える

## 注意点
- 断定が強い型なので、**事実ではなく判断**であることが分かる書き方にする。
- 特定の属性を見下す表現にならないよう、否定するのは「行動・準備」であって人格ではない。
