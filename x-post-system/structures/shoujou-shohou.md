# 構文名：症状連打→一言処方型

## この構文が読まれやすい理由
- 前置きがゼロ。1行目がいきなり症状なので、当てはまる人は最初の1行で止まる。
- 「症状→同じ処方」を6回繰り返す。**同じ語尾の連打がリズム**になり、読み飛ばせない。
- 症状が身体感覚（睡眠・食欲・笑う回数）なので、読者が自己診断してしまう。
- 繰り返しで感情が高まったところで、最後の2段落だけ通常の文章に戻る。この落差で結論が刺さる。
- 「根性ではなく環境のサイン」と**読者を responsible にしない**解釈を与えるので、共感で終われる。

## 基本構造
```
①【症状1】→【処方】
②【症状2】→【処方】
（…5〜7回、同じ処方を繰り返す）
 ↓
③通常文に戻り、症状の解釈を与える（「〇〇が足りないんじゃなくて、△△のサイン」）
 ↓
④行動を後押しする一言で締める
```

## 抽象テンプレート
```
【症状1】→【処方】
【症状2】→【処方】
【症状3】→【処方】
【症状4】→【処方】
【症状5】→【処方】
【症状6】→【処方】

【症状群】って、【責められがちな原因】じゃなくて、【本当の原因】のサイン。
【今のままだとどうなるか】。【変えたらどうなるか】。
```

## 相性の良いテーマ
- 読者が「自分のことだ」と感じる身体感覚・日常のサインがあるテーマ
- 原因が本人ではなく環境にあると言えるテーマ

## 相性の悪いテーマ
- 手順や理屈の説明が必要なテーマ
- 症状が5個以上出ないテーマ

## ⚠️ 運用上の注意
体調・メンタルに触れる型なので、**断定しすぎない**。
「環境を変えれば必ず治る」と言い切らず、受診や休養の選択肢を否定しない書き方にする。
転職を煽る文脈で健康不安を使いすぎると、不安商法に見える点にも注意。

## 文体・見た目のメモ
- 文章量：150〜250字と短い
- 症状は5〜7行。増やしすぎるとくどい
- 絵文字なし。矢印は → で統一
- 最後の2段落は改行を入れて呼吸を変える
