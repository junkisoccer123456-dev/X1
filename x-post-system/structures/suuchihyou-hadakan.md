# 構文名：数値表＋肌感解説型

## この構文が読まれやすい理由
- 【】の見出しに「実は〜で変わる」と入っているので、**読者が知らない変数を提示された形**になる。
  「スキルじゃないのか」という引っかかりでスクロールが止まる。
- 本体が**表**なので、文字を読まずに目が走る。しかも2要素のかけ合わせ（職種×業界）なので、
  読者は自分の行を一瞬で見つけられる。**自分の位置が分かる表は保存される**。
- 表のあとに「僕が見てきた肌感だと」と置くことで、数字の出典問題を回避しつつ、
  **選ぶ側しか持っていない情報**として成立させている。
- 締めが「書類を盛るより、近い求人を選ぶが先」と**行動の優先順位**になっている。
  読者が今日からできることに落ちるので、納得感で終われる。

## 基本構造
```
①【〇〇、実は"△△"で□□が変わる】の見出し（""で変数を浮かせる）
 ↓
②表：2要素のかけ合わせ×評価 を5行（全角スペースで右列を揃える）
 ↓
③「僕が見てきた肌感だと」＋表の読み方を1文（何で決まっているのか）
 ↓
④よくある誤解の指摘（「落ちてる人の多くは〇〇が弱いんじゃなくて、△△だけ」）
 ↓
⑤行動の優先順位で締める（「〇〇より△△が先。そこに尽きるかと」）
```

## 抽象テンプレート
```
【【対象】、実は"【隠れた変数】"で【結果】が変わる】

【要素A1】×【要素B1】　　【評価1】
【要素A1】×【要素B2】　　【評価2】
【要素A2】×【要素B1】　　【評価3】
【要素A2】×【要素B2】　　【評価4】
【要素A3】×【要素B2】　　【評価5】

僕が【見てきたもの】を見てきた肌感だと、【結果】って
【読者が思っている要因】より"【本当の要因】"で動くものです。
振り返ると、【悪い結果】の人の多くは【責めがちな原因】が弱いんじゃなくて、
【本当の原因】だけなんですよね

結局、【読者がやりがちな努力】より「【本当にやるべきこと】」が先。そこに尽きるかと思います。
```

## 相性の良いテーマ
- 2つの軸のかけ合わせで結果が変わるテーマ（職種×業界、年齢×経験、規模×ポジション）
- 読者が「スキル・努力の量」で説明していることを、**別の変数で説明し直せる**テーマ
- 行が5つで足りるテーマ（増やすと表に見えなくなる）

## 相性の悪いテーマ
- 軸が1つしかないテーマ（ただのランキングになる）
- 評価が全部同じになるテーマ（差が出ないと表の意味がない）
- 出典のある統計が必要なテーマ（この型は肌感で書くので、公的数値を装ってはいけない）

## ⚠️ 運用上の最重要ルール
参考投稿はこの表の右列を**パーセンテージ**（68% / 52% / …）で出しているが、
これは投稿者自身の肌感であって統計ではない。
**出典のない数字は書かない**というルールがあるアカウントでは、
右列を次のどちらかにする。

1. **段階表現にする**（「いちばん通る」「まあ通る」「半分くらい」「かなり厳しい」「まず通らない」）
2. `【　】` のプレースホルダで出力し、**本人が自分の肌感の数字を入れてから投稿する**

2026-10-05 の tamura 向け生成では **1（段階表現）** を採用した。

## 文体・見た目のメモ
- 文章量：250〜350字
- 表は5行固定。左列は「A×B」の形で統一し、**全角スペースで右列の開始位置を揃える**
  （左列を12〜14文字幅に収めるとスマホで崩れにくい）
- 左列は上から下へ「近い → 遠い」の順に並べる。読者が自分の行を下に探すほど不安になる設計
- 解説は3段落。1段落目で表の読み方、2段落目で誤解の訂正、3段落目で優先順位
- 2段落目の末尾は句点を打たず「〜なんですよね」で止めると口語のトーンが出る
- 絵文字なし。CTAは本文に入れない
