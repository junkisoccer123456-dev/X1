# 構文名：DM相談引用→危機の指摘→記事リプ誘導型

## この構文が読まれやすい理由
- 冒頭が断定（危機の指摘）なので、スクロールが止まる。
- すぐ後ろに「DMで多い相談」の引用が来る。本人のセリフなので、読者が「これ自分だ」と感じる。
- 相談者を「優秀」と先に認めるので、優秀な読者ほど自分ごと化する。そのうえで「だからこそ危ない」と反転する。
- 答えは本文で出さず、リプの記事に送る。個別相談を受けていないスタンスとも矛盾しない。

## 基本構造
```
①危機を断定する1行（パワーワード）
 ↓
②「最近DMで多い相談がこれです」＋相談の引用（カギ括弧1〜2行）
 ↓
③相談者は優秀であることを認める（評価・環境は悪くない）
 ↓
④「だからこそ危ない」と反転
 ↓
⑤危ない理由を2〜3点（短文）
 ↓
⑥人事部長としての一言見解で締める
 ↓
【リプ】個別相談は受けていないが、よく聞かれる質問の答えを記事にまとめた（PR）
```

## 抽象テンプレート
```
【読者の属性】が、一番危ないです。

最近、DMで一番多い相談がこれです。

「【相談者の本音】」

【能力・環境は悪くない】。だからこそ、危ないと思っています。

【危ない理由1】。
【危ない理由2】。
【危ない理由3】。

【人事部長としての一言見解】。

【リプ】
個別の転職相談は受けていませんが、DMでよく聞かれる「【質問】」の答えは、ここにまとめています。（PR）
```

## 相性の良いテーマ
- 優秀層・安定層に危機感を持たせたいテーマ（大手の安心、AI、年功序列、市場価値）
- 本人に不満がなく、動く理由がない層に向けたテーマ

## 相性の悪いテーマ
- 緊急性の高い悩み（今すぐ辞めたい等）。この構文は「静かな危機」向き。

## 文体・見た目のメモ
- 文章量：200〜350字
- 引用は「」で1〜2行。作り話の個別エピソード（年収・社名・人数）は入れない
- 数字は使わない。見解は「と思っています」「だったりします」で言う
