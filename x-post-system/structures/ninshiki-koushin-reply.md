# 構文名：認識アップデート→リプ回収型

## この構文が読まれやすい理由
- 1行目が「【回数】してわかったこと」。**経験の量を数字で見せる**だけで権威になる。
  肩書きではなく回数なので、誰でも使えるのに説得力が出る。
- 本文が「◾️昔そう思っていたこと」の3項目で終わる。
  読者は**いま自分が思っていること**をそこで見つけるので、自分の話として読む。
- 2つ目の見出し「◾️【回数】してわかった真実↓」だけ出して切る。
  **同じ3項目に別の答えが並ぶ**ことが予告されているので、リプが必ず開かれる。
- リプの3項目が本文の3項目と**1対1で対応している**。
  並べた瞬間に差分が読めるので、解説がいらない。
- 真実の側は**具体的で角がある**（「上司で決まる」「部下が辞めてると気づかない上司」）。
  一般論に逃げないので引用されやすい。
- 締めで**行動を1つだけ指定して、逃げ道も用意する**
  （最初の3か月は全力で。それでも合わないなら環境を変えてOK）。
  やることと許可が同時に置かれるので、読者が追い詰められない。

## 基本構造
```
①【回数・年数】してわかったこと
 ↓
②◾️【昔の立場】の頃に思ってたこと
　・【当時の認識1】
　・【当時の認識2】
　・【当時の認識3】
 ↓
③◾️【回数】してわかった真実↓ で切る（中身は出さない）
 ↓
④【リプ】・【真実1】（①に対応）
　　　　　・【真実2】（②に対応）
　　　　　・【真実3】（③に対応）
 ↓
⑤締め：やることを1つ指定 ＋ それでも駄目なときの逃げ道を許可する
```

## 抽象テンプレート
```
【回数】【動詞】してわかったこと

◾️【昔の立場】の頃に思ってたこと
・【当時の認識1】
・【当時の認識2】
・【当時の認識3】

◾️【回数】【動詞】してわかった真実↓

（リプ）
・【真実1：主語をずらす】
・【真実2：一番ヤバいものを具体化する】
・【真実3：時間軸を短くする】

だから【やること】は全力で。それでも【条件】なら【逃げ道】してOKです。
```

## 相性の良いテーマ
- 経験を積む前と後で認識が反転するテーマ（会社選び、上司、評価、働き方）
- 当時の認識が**読者のいまの認識**になっているテーマ（自分ごと化が起きる）
- 3項目に収まるテーマ（4つ以上だと対応が追えなくなる）

## 相性の悪いテーマ
- 認識が変わらないテーマ（対比にならない）
- 社名・数字が主役のテーマ（この型は認識の対比だけで持たせる）
- 回数や年数を言えないテーマ（1行目の権威づけが成立しない）

## 文体・見た目のメモ
- 文章量：本文110〜140字／リプ130〜170字
- 記号は ◾️ と ・ のみ。◾️ が見出しの役割を担う
- 当時の認識は**きれいごとで書く**。真実の側で角を出すので、落差がそのまま効く
- 真実の3項目は長さを不揃いにする（2つ目を一番長くすると目が留まる）
- 絵文字：参考投稿になし（◾️ は記号として使う）

## ⚠️ 運用上の注意
- 本文とリプの項目数を必ず揃える（3対3）。対応が崩れると型が死ぬ
- 回数・年数は**アカウントカードに登録されている範囲**でしか書かない。
  登録がない場合は「〜を見てきてわかったこと」のように回数を使わない形にする
- 締めの逃げ道を省かない。「全力で」だけで終えると説教になる
