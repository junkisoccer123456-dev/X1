# 構文名：段階別懸念→整理フレーム型

## この構文が読まれやすい理由
- 冒頭が【読者を名指す括弧見出し】＋**よく来る相談のセリフ**。
  自分がまさに聞きたかったことが1行目にあるので、読む理由を説明しなくていい。
- 「【Xがある＝即不採用】ではありません」と**最初に不安を否定**する。
  ここで安心させてから「ただし」で条件を出すので、残酷な話でも最後まで読まれる。
- 本体が**程度別の3段階**（3か月／半年／1年以上）。
  読者は自分が今どの段落にいるかを探すので、全部読まずに済まない。
- 各段階が「**相手が聞いてくること**」のセリフ列挙になっている。
  抽象的な注意ではなく、面接で実際に飛んでくる言葉なので、そのまま準備に使える。
- 段階が進むごとに**確認される深さが変わる**（事実 → 背景 → 採用後のリスク）。
  この設計が「長引くほど不利」を納得させる。脅しではなく仕組みの説明になっている。
- 後半で【A→B→C→D】の**整理の順番**を渡す。不安の指摘で終わらず、手順が残る。
- 配分の数字（【過去2：現在3：未来5】）が効く。
  程度の話を**数字1つに畳む**ので、覚えて帰れる。
- 締めの直前に短い命令形を3行（隠さない／盛らない／謝らない）。
  長文のあとに短文が来るとリズムが変わり、ここだけスクショされる。
- 最後が**再定義**（Aの時間ではなくBの時間）＋保存誘導。
  意味を書き換えてから保存を促すので、押し付け感が出ない。

## 基本構造
```
①【読者を名指す見出し】
 ↓
②よく来る相談をセリフで（「〜ですよね…？」これ、本当によく相談されます）
 ↓
③状況のバリエーションを列挙（理由はさまざま、と受け止める）
 ↓
④🔶【立場】としてまず伝えたい。
　【Xがある＝即不採用】ではありません。ただし、【程度】が増すほど確認したいことは増えます。
 ↓
⑤◆段階1（軽い）
　　位置づけ1行（十分あり得る範囲）
　　「【聞かれること1】」
　　「【聞かれること2】」
　　「【聞かれること3】」
　　など【何を整理しておくか】
 ↓
⑥◆段階2（中くらい）…「ここからは」＋聞かれること3つ＋【背景】まで確認される
 ↓
⑦◆段階3（重い）…「さらに」＋聞かれること4つ＋【採用後のリスク】まで確認される
 ↓
⑧「だから大切なのは【間違った努力】ではありません」
 ↓
⑨【A→B→C→D】の順番を提示＋①〜④の問いに分解
 ↓
⑩▪️ケース別の言い換えを3つ（〜なら、〜で終わらず〜まで伝える）
 ↓
⑪やりすぎ注意の指摘（【〜を埋めようとして、〜を長くしすぎない】）
 ↓
⑫配分の数字（【過去2：現在3：未来5】くらいの意識をおすすめします）
 ↓
⑬相手が最終的に知りたいこと3点（【】で3行）
 ↓
⑭短い命令形3行（隠さない。盛らない。必要以上に謝らない。）
 ↓
⑮再定義（【Aの時間】ではなく【Bの時間】です）＋保存誘導
```

## 抽象テンプレート
```
【【読者】の方へ】
「【不安をそのままセリフにしたもの】…？」これ、本当によく相談されます。
【程度の例を3つ】。【理由のバリエーションを列挙】など、事情はさまざま。

🔶【立場】としてまず伝えたい。
【Xがある＝即不採用】ではありません。
ただし、【程度】が増すほど、採用側が確認したいことは増えていきます。

◆【段階1】
【十分あり得る範囲だという位置づけ】。
「【聞かれること1】」
「【聞かれること2】」
「【聞かれること3】」
など【整理しておくもの】を用意しておく。

◆【段階2】
ここからは、
「【聞かれること1】」
「【聞かれること2】」
「【聞かれること3】」
など【背景】まで確認されることがあります。

◆【段階3】
さらに、
「【聞かれること1】」
「【聞かれること2】」
「【聞かれること3】」
「【聞かれること4】」
など【採用後のリスク】まで確認されやすくなります。

だから【説明】で大切なのは、【間違った努力】ことではありません。
【A→B→C→D】
この順番で整理してください。

①【問い1】
②【問い2】
③【問い3】
④【問い4】

▪️例えば【ケース1】なら、【やりがちなこと】より、「【ここまで伝える】」まで伝える。
▪️【ケース2】なら「【浅い説明】」だけではなく、【何を学び、どう活かすか】。
▪️【ケース3】なら、「【言いかけて止まる言葉】」で終わらず、【何を見直し、今どうしているか】。

そして重要なのが【【埋めようとして、過去の説明を長くしすぎない】】
僕は、【過去2：現在3：未来5】くらいの意識をおすすめします。
採用側が最終的に知りたいのは「【過去の中身】」だけではありません。

【【知りたいこと1】】
【【知りたいこと2】】
【【知りたいこと3】】ここです。

【Xは隠さない】。
盛らない。
必要以上に謝らない。

【Xの説明】は、【【過去を弁明する時間】】ではなく
【【相手の懸念を解消して、現在と未来を伝える時間】】です。
面接前に見返せるよう、ぜひ保存を！！
```

## 相性の良いテーマ
- **程度が増すほど相手の確認が深くなる**テーマ
  （空白期間、転職回数、在籍の短さ、希望年収の上げ幅、未経験の度合い、年齢）
- 読者が「不利ですよね？」と不安に思っていて、**答えが「即NGではない。ただし」**になるテーマ
- 3段階に自然に割れるテーマ（2段階だと型が成立しない）

## 相性の悪いテーマ
- 程度の概念がないテーマ（あるかないかで終わるもの）
- 不利が事実として確定しているテーマ（冒頭の否定が嘘になる）
- 手順だけで足りるテーマ（段階別の必要がない）

- 記号の役割を固定する。🔶＝立場宣言、◆＝段階の見出し、▪️＝ケース別、【】＝キーワードの強調

- 命令形3行は体言／用言止めで短く。説明を足さない
- 一人称は「僕」（参考投稿は「私」だが、アカウントの文体に合わせる）
