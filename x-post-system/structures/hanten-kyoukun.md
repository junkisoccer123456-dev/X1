# 構文名：好条件→不安→逆転→教訓型

## この構文が読まれやすい理由
冒頭で「恵まれている状態」を並べるので、読者は自分を重ねながら読み始める。
そのうえで「なのに不安になる」と続くので、**自分でも説明できなかった感情を言語化された状態**になる。

ここから「焦って動いた結果どうなったか」を一気に落とすので、読者は自分の未来を先に見せられる。
説教ではなく「先に起きたこと」として書けるので、反発が出にくい。

最後の教訓が「抜け出すのは簡単でも、戻るのは難しい」のような**非対称の事実**になっているのも効く。
やめとけと言われるより、後戻りできないと言われたほうが止まる。

## 基本構造
```
①❶〜❹で恵まれた前提を列挙（1行ずつ・体言止め）
 ↓
②「なのに、【時期】でふとよぎる。」
 ↓
③心の声をカギ括弧で1行（読者の本音をそのまま書く）
 ↓
④焦って動く（「〜系の会社に転職」など、雑に言い切る）
 ↓
⑤結果が悪化（3語で並べる：終わらない残業・薄給・成果主義）
 ↓
⑥なぜそうなるかを1文で（「〜を勘違いしたまま環境を変えると、〜」）
 ↓
⑦教訓を非対称の事実で締める（「〜は簡単でも、〜は難しいです、、、」）
```

## 抽象テンプレート

```
❶【恵まれた前提1】
❷【恵まれた前提2】
❸【恵まれた前提3】
❹【恵まれた前提4】

なのに、【時期・年次】でふとよぎる。

「【読者の本音をそのまま1行で】」

焦った勢いで「【安易に飛びつく誘い文句】」系の【選択】。

結果、待っていたのは【悪化した状態を3語で】。
【何を勘違いしたか】まま【行動】と、【どうなるか】。

【いまいる場所】の不安は錯覚。【抜ける】のは簡単でも、【戻る】のは想像以上に難しいです、、、
```

## 相性の良いテーマ
- いま恵まれているのに不安、という状態（ホワイト企業／大手／安定した部署）
- 後戻りが難しい選択（転職、職種変更、独立、退職、資格の取り直し）
- 読者が「焦り」で動こうとしている場面

## 相性の悪いテーマ
- 失敗しても戻れるテーマ（非対称にならないので締めが弱くなる）
- 恵まれた前提が置けないテーマ（冒頭の❶〜❹が埋まらない）

## 文体・見た目のメモ
- 文章量：200〜300字。これ以上長くすると落ちの効き方が鈍る
- ❶〜❹は体言止め。説明を足さない
- 心の声は必ずカギ括弧。口語のままにする（「俺は成長できるのか？」）
- 締めは「、、、」で止める（読点3つ。感情が残る）
- 絵文字なし。囲み数字だけ使う
