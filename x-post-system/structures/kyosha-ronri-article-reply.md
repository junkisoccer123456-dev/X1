# 構文名：強者の論理→条件限定→問いで切る型

## この構文が読まれやすい理由
- 冒頭で、世間でよく言われる一般論を「強者の論理」と断じる。常識の否定なのでスクロールが止まる。
- すぐ後に「その人なら確かに成り立つ」と条件つきで認める。頭ごなしの否定ではないので、反感を買いにくい。
- 条件が具体的なので、読者は「自分は当てはまるか？」と自己診断を始める。
- 当てはまらない人の現実を示したあと、最後は「じゃあどうすれば？というと......」で切る。答えが気になった読者が記事に進む。

## 基本構造
```
①「〇〇」は、強者の論理だと思います。（一般論を断定的に限定）
 ↓
②それが成り立つ人の条件を3〜4個列挙し、「その人なら十分」と認める
 ↓
③（ただし〜）の予防線を1行
 ↓
④条件に当てはまらない人の現実
 ↓
⑤「〇〇は主に、△△な人向け」と定義し直す
 ↓
⑥「じゃあ、〜な人はどうすればいいのか？というと......」で切る
 ↓
【リプ】答えは記事に書いている（PR）
```

## 抽象テンプレート
```
「【よく言われる一般論】」は、強者の論理だと思います。

【条件1】、【条件2】、【条件3】。そういう人なら、ぶっちゃけ【一般論】で十分です。
（ただし、【但し書き】）

でも、【条件外の状態】の人が同じことをすると、【悪い結果】になります。

【サービス・方法】は主に、【成り立つ人】向けです。

じゃあ、【条件外の人】はどうすればいいのか？というと......

【リプ】
【答え】は、ここに書いています。（PR）
```

## 相性の良いテーマ
- 世間の定説やアドバイスに「前提条件」が隠れているテーマ
- 読者を「自分はどっち側か」と考えさせたいテーマ

## 相性の悪いテーマ
- 前提条件が学歴・年齢・属性などで、読者を見下す表現になりやすいテーマ（行動・準備の条件に置き換える）

## 文体・見た目のメモ
- 文章量：200〜350字
- 条件は「行動・準備・状態」で書く（学歴・年齢で線引きしない）
- 最後は必ず「というと......」で切り、答えを本文に書かない
