# 構文名：正体伏せ→リプ公開型

## この構文が読まれやすい理由
- **主役の名前を最後まで出さない**。読者は「どこの話だ？」が気になって離脱できない。
- 条件だけを箇条書きで並べるので、読者は勝手に自分の会社や希望と比較する。
- 条件に待遇・選考・実績を混ぜると、「良すぎて嘘では」と「本当なら知りたい」が同時に立つ。
- 「たった数回の面接で」のような**ハードルを下げる一言**が、自分にも可能性があると思わせる。
- リプで正体を公開するため、リプが必ず開かれる。CTAを置く場所として最も強い型。

## 基本構造
```
①【煽り気味の見出し】＋「〇〇はここ↓↓」
 ↓
②条件を箇条書き（待遇／働き方／選考／実績を混ぜる。6〜8個）
 ↓
③ハードルを下げる一言＋「〇〇は…」で切る
 ↓
④【リプ】正体の公開（社名・サービス名）
 ↓
⑤なぜそれが良いのかを1段落で説明
 ↓
⑥フォロー誘導（発信内容を3つ添える）
```

## 抽象テンプレート
```
【対象読者】向けの【強い見出し】
【伏せる対象】はここ↓↓

・【数値条件1】
・【数値条件2】
・【働き方の条件】
・【選考に関する条件】
・【実績・評価】

【ハードルを下げる一言】、【伏せる対象】は…

【リプ】
名前は...
『【社名】』
【事業内容の説明を2〜3行】
【この読者にとって何が良いか】

フォローすると【発信内容1】【発信内容2】【発信内容3】を発信しています
```

## 相性の良いテーマ
- 1社（1サービス・1職種）を主役にできるテーマ
- 条件を数字で並べられるテーマ

## 相性の悪いテーマ
- 主役が複数あるテーマ（伏せる意味がなくなる）
- 条件が地味なテーマ（引っぱった割に、で終わる）

## ⚠️ 運用上の最重要ルール
この型は**数値の塊で成立する**。年収・取得率・売上などは、
必ず有価証券報告書や公式採用ページなど**出典のある数字だけ**を使う。
生成時は `【　】` のプレースホルダで出力し、**本人が出典を確認して埋めてから投稿する**。
誇張した見出し（「人生変わる」等）は、中身が事実で裏づけられる範囲に留める。

## 文体・見た目のメモ
- 文章量：本文300〜400字、リプ200〜300字
- 条件は「・」で統一し、1行1条件
- 絵文字なし（↓↓ は記号として使用可）

## バリエーション

### A. 無名を価値に変える型（2026-09-23 追加・参考投稿①）
条件に「家賃6,000円」「6人に1人が採用」など**生活実感のある数字**を混ぜる派生。
リプで「社名を知ってる人はほぼいないかと」と、**無名であることを価値に変換**する一言を置く。
事業内容は一言で言語化する（「人と機械が触れる接点を握り続けた会社」のように）。
参考：`../references/2026-09-23-nori/01-学歴なしでも入れる企業.md`

### B. 速報型（2026-09-23 追加・参考投稿④）
頭に【日付＋速報】を置き、条件を■で5項目に整理する派生（休日／年収／働き方／事業／応募条件）。
求人票の構造をそのまま使うので、作るのが速い。
リプは社名＋自己紹介＋フォロー誘導だけに絞り、解説を省いて誘導に振り切る。
参考：`../references/2026-09-23-nori/04-速報ティーザー.md`

### C. 無名世界一・リプ4段解説型（2026-10-26 追加・参考投稿①）
本文の条件を**9項目**まで増やし、待遇（年収・休日・残業）／制度（フレックス・託児所・記念日休暇）／
定着と入り口（離職率・有給取得率・中途採用比率）の**3種類を混ぜて**並べる派生。
冒頭に権威フックを置かず、見出しそのものをフックにする
（「20代であれば"〇〇業界未経験でも入れる"世界一の企業」）。

リプが4段に伸びるのがこの派生の中心。
```
①『社名。』＋「社名を知ってる人はほぼいないかと」＋規模の事実
 ↓
②事業の正体（誰も見ない一点を長年磨いた結果、シェア首位）
 ↓
③ビジネスモデル（売った後に入り続ける収益／交換需要）
 ↓
④制度の例外（「〇〇がないというバグ」）
 ↓
⑤「未経験でも20代の採用を受け入れ中↓↓」で引いたまま終わる（CTAなし）
```
Aとの違いは、②で止めずに**③ビジネスモデルまで踏み込む**点。
「良い会社」ではなく「構造的に崩れにくい会社」として読ませられる。

④の制度は、公表資料で確認できないときは書かない。
事業構造の強みをもう1段書くほうに差し替える。
参考：`../references/2026-10-26-nori/01-無名世界一ティザー.md`

### D. 待遇網羅→理由解説型（2026-10-29 追加・参考投稿②）
条件を**10項目以上**並べ、「項目名：値」の形でコロンを縦に揃える派生。
Cと違って並べるのは**待遇だけ**（年収・ボーナス・初任給・労働時間・休日・有給・リモート）で、
事業や制度の話は一切入れない。数字の壁で止めてから落とす型。

条件のあとに**福利厚生の解説を2段**置くのが特徴。
「住宅補助は9.5万も支給されるため、お金しか貯まらない」のように、
1つの手当を取り上げて生活の実感に変換する。そのうえで
「好待遇なのに、穴場で学歴フィルターもないこの企業は、、、」で切る。

リプは4段。
```
①『社名』＋事業の説明2行（シェアや成長の事実）
 ↓
②「なんで年収がここまで高いのか？？」と自分で問う
 ↓
③理由を1行で言い切る（「給料の多くが業績連動だから」）
 ↓
④その理由が成り立つ業界構造を3行（リスクと引き換えである点まで書く）
 ↓
⑤「20代であれば中途採用枠が狙い目。いまのうちに動き出しましょう↓↓」
```
Cとの違いは④の中身。Cは「崩れにくいビジネスモデル」を説明するが、
Dは「**なぜ給料が高いのか**」を説明する。高年収の理由を言語化するので、
金額の大きさが自慢ではなく仕組みとして読まれる。

待遇の項目は、公表資料で確認できないものは書かない。
確認できた数値だけを並べ、福利厚生の2段は**確認できた数値の読み方**に差し替える。
参考：`../references/2026-10-29-nori/00-構文リスト.md`
