# 構文名：正体伏せ→リプ公開型

## この構文が読まれやすい理由
- **主役の名前を最後まで出さない**。読者は「どこの話だ？」が気になって離脱できない。
- 条件だけを箇条書きで並べるので、読者は勝手に自分の会社や希望と比較する。
- 条件に待遇・選考・実績を混ぜると、「良すぎて嘘では」と「本当なら知りたい」が同時に立つ。
- 「たった数回の面接で」のような**ハードルを下げる一言**が、自分にも可能性があると思わせる。
- リプで正体を公開するため、リプが必ず開かれる。CTAを置く場所として最も強い型。

## 基本構造
```
①【煽り気味の見出し】＋「〇〇はここ↓↓」
 ↓
②条件を箇条書き（待遇／働き方／選考／実績を混ぜる。6〜8個）
 ↓
③ハードルを下げる一言＋「〇〇は…」で切る
 ↓
④【リプ】正体の公開（社名・サービス名）
 ↓
⑤なぜそれが良いのかを1段落で説明
 ↓
⑥フォロー誘導（発信内容を3つ添える）
```

## 抽象テンプレート
```
【対象読者】向けの【強い見出し】
【伏せる対象】はここ↓↓

・【数値条件1】
・【数値条件2】
・【働き方の条件】
・【選考に関する条件】
・【実績・評価】

【ハードルを下げる一言】、【伏せる対象】は…

【リプ】
名前は...
『【社名】』
【事業内容の説明を2〜3行】
【この読者にとって何が良いか】

フォローすると【発信内容1】【発信内容2】【発信内容3】を発信しています
```

## 相性の良いテーマ
- 1社（1サービス・1職種）を主役にできるテーマ
- 条件を数字で並べられるテーマ

## 相性の悪いテーマ
- 主役が複数あるテーマ（伏せる意味がなくなる）
- 条件が地味なテーマ（引っぱった割に、で終わる）

## ⚠️ 運用上の最重要ルール
この型は**数値の塊で成立する**。年収・取得率・売上などは、
必ず有価証券報告書や公式採用ページなど**出典のある数字だけ**を使う。
生成時は `【　】` のプレースホルダで出力し、**本人が出典を確認して埋めてから投稿する**。
誇張した見出し（「人生変わる」等）は、中身が事実で裏づけられる範囲に留める。

## 文体・見た目のメモ
- 文章量：本文300〜400字、リプ200〜300字
- 条件は「・」で統一し、1行1条件
- 絵文字なし（↓↓ は記号として使用可）
