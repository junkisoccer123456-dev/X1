# 構文名：現象分類→提言型

## この構文が読まれやすい理由
- 冒頭が**伝聞・観測**（「〜そうです」「〜という方が多いです」）で始まる。
  自分の主張ではなく「起きている事実の報告」なので、読者が構えずに入れる。
  主張から入ると反論されるテーマでも、観測から入ると最後まで読まれる。
- 読者が**言葉にできていなかったモヤモヤに名前が付く**。
  「不確実性の苦痛」「アイデンティティの崩壊」のように名詞句で命名されると、
  読者は「これだ」と自分の状態を見つけて保存する。
- 各項目が「状態の名前」＋「**なぜそうなるかの因果**」で書かれている。
  症状の列挙ではなく、仕組みの説明なので、読み終えたときに理解した感覚が残る。
- 項目が5つ前後で、どれも**自分に当てはまるかを確認したくなる**。
  1つでも当たると、残りも読まれる。
- 締めが読者への説教ではなく、**立場をずらした提言**（「マネジメント層は〜を変える必要がありそう」）。
  だから読者は責められず、「分かってくれている人」として発信者を見る。
  同時に「自分が悪いわけではなく構造の問題」という救いになる。
- 「個人の努力の話ではない」と示すので、リポストされやすい。
  読者が上司や同僚に見せたくなる形になっている。

## 基本構造
```
①伝聞・観測のフック（「【状況】になると次のような【内面の変化】を抱えていくそうです」）
 ↓
②① 【状態の名前（名詞句）】
　　【なぜそうなるかの因果を2〜3行】
 ↓
③②〜⑤ 同じ形で残りの項目（計5つ前後）
 ↓
④構造の言い直し（「今までの【やり方・価値観】の延長で【新しい環境】に入ると、こうなる」）
 ↓
⑤立場をずらした提言（「だから【当事者ではない側】は【何】を変えていく必要がありそうですね」）
```

## 抽象テンプレート
```
【対象】が【変化・状況】になると、次のような【内面の変化】を抱えていくそうです。

① 【状態の名前】
【何が起きているか】ため、【どういう感情になるか】

② 【状態の名前】
【矛盾・ねじれの説明】という矛盾から【感情】を抱える

③ 【状態の名前】
【やるべきこと】のために【かかるコスト】が必要なのに、【周囲の期待】なので、
【ギャップ】が強くなる

④ 【状態の名前】
【自分を定義してきたもの】そのものが【奪っている主体】に奪われている感覚になる

⑤ 【状態の名前】
【これまで得ていたもの】が薄れ、【結果】が自分のものと感じられなくなる

今までの【やり方・価値観】の延長で【新しい環境】に突入していくと、
【対象】はこういった【内面の変化】を抱えてしまうので、
【当事者ではない側】は【変えるべきもの】を変えていく必要がありそうですね。
```

## 相性の良いテーマ
- **環境の変化が、人の内面に何を起こすか**を扱えるテーマ
  （AI導入、役割の変更、常駐先の変更、評価されない期間、リモート化、分業化）
- 読者が「しんどいけど、何がしんどいのか説明できない」状態にあるテーマ
- 原因が個人の努力不足ではなく**構造側にある**と言えるテーマ
  （締めの提言が成立しない＝個人の努力の話になるテーマは、この構文に向かない）
- 5つに分けたときに、項目が**感情の別の層**になるテーマ
  （不安／矛盾／負荷／アイデンティティ／意味、のように層が違うと重複しない）

## 相性の悪いテーマ
- ノウハウ・手順（「こうすれば通る」）→ 提言締めが効かない。別構文へ
- 項目が全部同じ感情になるテーマ（「つらい」が5つ並ぶと読まれない）
- 構造の問題にできないテーマ（本人の準備不足が原因のもの）

## 文体・見た目のメモ
- 文章量：全体600〜800字。1項目は見出し1行＋解説2〜3行
- 囲み数字（①②③④⑤）＋**半角スペース1つ**＋見出しの名詞句。見出しに句点は付けない
- 解説は**常体で止める**（「〜になる」「〜を抱える」）。ここをです・ます調にすると説教に寄る
- 締めの1段落だけ、です・ます調に戻して「〜ありそうですね」で柔らげる
- 見出しは「不確実性の苦痛」「意味と満足感の喪失」のように**抽象名詞**で付ける。
  「〜がつらい」のような形容詞止めにすると、名前として機能しない
- 絵文字は使わない（参考投稿にない）

## バリエーション

### A. 観測フック版（2026-10-13 / tamura）
伝聞（「〜そうです」）の代わりに、**自分の立場からの観測**で入る派生。
「【立場】してますが、面接で話を聞いていると【状態】を抱えている方が多いです」の形。
伝聞よりも権威が乗るが、「自分の主張」に近づくぶん、締めの提言を弱めて角を取る。

### B. 当事者への提言で締める版
締めの相手を第三者ではなく**読者本人**にする派生。
「だから【読者】は【何】から変えたほうがいいかと」で終える。
構造の問題にしきれないテーマで使うが、説教に寄るリスクがあるので解説側で逃げ道を残す。
