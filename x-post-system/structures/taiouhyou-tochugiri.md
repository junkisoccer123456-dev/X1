# 構文名：対応表途中切り型

## この構文が読まれやすい理由
- **行の途中で切る**のが核。最後の行の矢印の先を空白のまま終えるので、
  「続きは↓」のような言葉を一切使わずにリプを開かせられる。視覚的な未完成がそのまま引きになる。
- 1行1件のBefore▶Afterなので、読者は**自分の左側を探す読み方**になる。自分ごと化が自動で起きる。
- 説明が一切ない。読む負荷がゼロで、保存される。
- 業界・職種レベルに丸めてあるので、個人が特定されず、そのぶん当てはめやすい。
- 解説を書かないぶん、リプ欄に「自分はこうでした」が集まりやすい構造になっている。

## 基本構造
```
①見出し1行（対象と内容を確定させる。例：20代中盤の転職でキャリアアップした事例）
 ↓
②列ヘッダ【Before】【After】（全角スペースで列を揃える）
 ↓
③・Before　▶ After を1行1件で並べる（業界のかたまりで並べる。説明なし）
 ↓
④最後の行は右側を空白にして切る（・〇〇　▶ で終える）
 ↓
⑤【リプ】切った行をもう一度書き直してから、続きを並べる。締めもCTAもなし
```

## 抽象テンプレート
```
【対象】の【内容】事例

【Before列の名前】　　　　　【After列の名前】
・【項目1】 　　▶ 【結果1】
・【項目2】 　　▶ 【結果2】
・【項目3】 　　▶ 【結果3】
・【項目4】 　　▶ 【結果4】
・【項目5】 　　▶

（リプ）
・【項目5】 　　▶ 【結果5】
・【項目6】 　　▶ 【結果6】
（…続き）
```

## 相性の良いテーマ
- Before と After の対応で語れるテーマ（転職前後、職種転換、制度の言い換え）
- 読者が自分の左側を探せるテーマ
- 業界・職種レベルに丸めても価値が残るテーマ

## 相性の悪いテーマ
- 1件ごとに説明が必要なテーマ（説明を入れると型が崩れる）
- 対応が1対1にならないテーマ
- 個人が特定される粒度でしか語れないテーマ

## ⚠️ 運用上の注意
- 事例を出す型なので、**実在の個人が特定できる粒度にしない**。業界・職種レベルに丸める。
- 支援人数などの実績は、アカウントファイルに登録されている範囲だけ使う。
- 対応が「必ずそうなる」と読まれないよう、見出しで「事例」と明示する。

## 文体・見た目のメモ
- 本文は約120字、リプは約130字。短い
- 矢印は ▶。列の区切りとして見やすい
- 全角スペースで列を揃える（スマホでも崩れにくい幅に収める）
- 業界のかたまりで並べる（金融系→コンサル→商社→メーカー のように）

## バリエーション

### A. 年表2段切り型（2026-10-05 追加・参考投稿⑩）
対応表のかわりに**1人の年表**を並べ、2回に分けて切る派生。

```
①「以前、面接でお会いした〇〇歳の方。能力が低かったわけではないですが....」
 ↓
②【22歳（新卒）】状況＋年収　を3ブロック（年齢・状況・年収を毎回セットで書く）
 ↓
③【28歳】↓ ＝ 年齢だけ書いて中身を伏せる（1回目の切り）
 ↓
④【リプ1】28歳・30歳・31歳を同じ形で並べ、【32歳】↓ で2回目の切り
 ↓
⑤【リプ2】現在の状況 ＋ 面接官としての考察 ＋ 読者への問いかけで終わる
```
効いているのは3点。
- 年収を毎ブロックに必ず書く。数字がゆっくりしか動かないことが、文字だけで伝わる
- 「能力が低かったわけではない」と最初に断る。他人事にできなくなる
- 締めが断定ではなく問いかけ（今の現場で、自分の判断が入った仕事はどれくらいありますか）

**2026-10-05 追記（参考投稿⑦）**：同じ骨格で、入口と締めを差し替えた形も確認。
- 入口を**逆張りの否定**にする（「〇〇にいるから伸びない、ではない。」）。
  属性のせいにしている読者を名指しせずに引き戻せる
- 年表の各ブロックを**3〜4行の文章**にする（状況・やったこと・評価・年収）。
  1行だけの年表より「経歴書を見ている感じ」が出る
- ブロックの区切りは【年齢】のみ。新卒だけ【22歳（新卒）】、現在だけ【31歳（現在）】と注記する
- 伝聞の形を混ぜる（「〜とのこと」「〜との事」）。実在の事例を扱うときの安全弁になる
- 締めは問いかけではなく**教訓の断定**（「〇〇が不利なのではなく、△△な人が不利になる」）＋
  **非対称の事実**（「同じ2年でも、消化した人と持ち帰った人では別物になります」）
- リプは2本。1本目で中盤、2本目で現在＋考察＋教訓まで入れる

⚠️ 実在の個人の事例を扱う型なので、**特定できる粒度にしない**。
年齢・業界・職種レベルに丸め、社名は出さない。年収も実数でなく概数にする。
