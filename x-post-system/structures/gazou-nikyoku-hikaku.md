# 構文名：画像2極対比（同じ場面・行動注釈）型

## この構文が読まれやすい理由
- **同じ場面・同じ登場人物・同じ構図**を左右に並べ、変えるのは「行動」だけ。差が1秒で見える。
- 本文はたった2行。「場面でわかる【悪い側】と【良い側】」だけで、**情報は画像側に全部ある**。
  読者は本文を読まずに画像へ目が行く。
- 画像内の丸数字つき注釈が、**行動を具体的なセリフ・動作で書いている**。
  「あるある」と「自分もやってた」が同時に刺さるので、保存・引用されやすい。
- 左右どちらにも自分を当てはめられる。「自分はどっちだろう」と思った時点で反応が生まれる。
- 悪い側のタイトルが「嫌われる」、良い側が「慕われる」と**感情の結果**で言い切られていて、
  どちらに寄りたいかが明らか。
- 左右の注釈の数が揃っていて、同じ番号が同じ観点（乾杯、料理、二次会など）に対応。
  読み比べると納得感が出る。

## 基本構造
```
①本文：「【場面】でわかる／「【悪い側の呼び名】」と「【良い側の呼び名】」」（2行）
 ↓
②画像：左右分割（同じ場面・同じ人物・同じ構図）
 ↓
③左：見出し（読者の気持ちの結果を書く）＝悪い側
　　　注釈①〜⑤＋吹き出しセリフ（行動を具体的に）
 ↓
④右：見出し（読者の気持ちの結果を書く）＝良い側
　　　注釈①〜⑤＋吹き出しセリフ（左と同じ観点で、行動だけ逆）
```
※リプなし・CTAなし。1投稿で完結。

## 抽象テンプレート
### 本文
```
【場面】でわかる
「【悪い側の呼び名】」と「【良い側の呼び名】」
```

### 画像に入れる内容（左右同じ観点で番号を揃える）
```
左見出し：【相手が離れたくなる／嫌になる結果】
右見出し：【相手がまた会いたくなる／選びたくなる結果】

① 【場面の始まり】の行動　：左＝【NG行動】　右＝【OK行動】
② 【進行中】の行動　　　　：左＝【NG行動】　右＝【OK行動】
③ 【周囲への対応】　　　　：左＝【NG行動】　右＝【OK行動】
④ 【会話・振る舞い】　　　：左＝【NG行動】　右＝【OK行動】
⑤ 【終わり方】　　　　　　：左＝【NG行動】　右＝【OK行動】
吹き出し：登場人物の本音のセリフを左右1〜2個ずつ
```

## 相性の良いテーマ
- 場面が日常的で、誰でも情景を思い浮かべられるもの
- 行動の差が「見た目・セリフ」に出るもの（立ち位置、持ち物、発言、姿勢）
- 二極の軸が分かりやすいもの（嫌われる/慕われる、お金持ち/貧乏、陽キャ/陰キャ、など）
- 5〜6個の観点に分解できるもの（観点が3つ以下だと注釈が薄くなる）

## 相性の悪いテーマ
- 行動の差が見えない、考え方や内面の違いだけのテーマ
- 場面が特殊で情景が浮かびにくいテーマ
- 観点が少なく、左右で書き分けられないテーマ

## ⚠️ 運用上の注意
- **これは画像が本体の構文**。テキストだけでは成立しない。このシステムが作れるのは
  ①本文2行 ②画像内に入れる文言（見出し・番号注釈・吹き出し）の設計まで。
  画像そのもの（人物写真・構図）は別途用意する必要がある。
- 左右で**同じ番号が同じ観点**になるように揃える。揃っていないと比較にならない。
- 悪い側を単なる悪口にしない。「あるある」と思える具体的な行動を書くことで、
  見下しではなく共感・自戒になる。
- 注釈1つ1行〜2行、吹き出しは10〜20文字に収める。多いと画像が読めなくなる。
- 「【悪い側】」は限定せず、特定の人・企業を連想させない書き方にする。

## 文体・見た目のメモ
- 本文：2行のみ、1行目は「場面でわかる」、2行目は鉤括弧2つを並べる
- 見出し：「〜になる〇〇」と、読者の感情の結果で書く（例：帰りたくなる／また行きたくなる）
- 注釈：丸数字＋「行動（具体）→ 周囲の反応・結果」の1〜2文
- 吹き出し：人物の本音をセリフ化（例：「ウーロン茶でいいのに…」「ごちそうさまです！」）
- 絵文字は使わない

## バリエーション（2026-10-29 追加・参考投稿3件）

### A. 本文1行目に二極を先出しする型
```
「【悪い側】」と「【良い側】」
【場面】ですぐバレる
```
基本形は「場面→二極」の順だが、こちらは**二極を先に出して、場面を後ろに置く**。
先に二極の言葉（お金持ちと貧乏）を見せるので、スクロール中でも自分ごと化が早い。
場面は短く「〜ですぐバレる」で切る。

### B. 場面を先に置き、「〜でわかる」で二極に入る型
```
【場面】でわかる
「【悪い側の呼び名】」と「【良い側の呼び名】」
```
基本形と同じ。二極の呼び名が「育ちの悪さ／育ちの良さ」のように**性質そのもの**でもよい。
場面は「夢の国に向かう車」のように、短い名詞句でさらっと置く。

### C. 二択ガイド型（矢印ラベル型）
```
【場面】したら

←【安全側のラベル】　　　【挑戦側のラベル】→
```
人物の二極ではなく、**選択肢の二極**。画像の左右に選択肢（または結果）を置き、
本文の矢印ラベルで「どちら側か」を示す。1行目は場面だけを言い切り、次の行に左右の矢印ラベル。
※この例は画像が未確認のため、画像側の中身は推定。画像を共有してもらえれば追記する。

### 共通点（3件の本文）
- 本文は**2行以内**。説明・CTA・リプなし。
- 二極の言葉は鉤括弧、または矢印で左右に分ける。
- 「ですぐバレる」「でわかる」で、**場面と結果を直結**させている。
