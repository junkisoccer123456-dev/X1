# 構文名：カウントダウンランキング型

## この構文が読まれやすい理由
- 順位がついているだけで、人は最後まで見たくなる。**1位を知りたい欲求**が離脱を止める。
- 下位から上げていくので、読み進めるほど価値が上がる感覚が出る。
- 各順位のフォーマットが統一されているため、リズムが一定で読み疲れしない。
- **1位だけを伏せてリプへ送る**ので、リプが必ず開かれる。
- 順位は主観でよい（「伸びる人の口癖」など）。数値の根拠が要らないテーマなら、断定しても嘘にならない。
- 最後に順位の話を離れて原則へ着地させると、ランキングが「読み物」から「行動指針」に変わる。

## 基本構造
```
①「〇〇ランキング↓」の1行（権威づけの一言を添えてもよい）
 ↓
②3位：見出し＋理由2行
 ↓
③2位：見出し＋理由2行
 ↓
④「1位は…↓」で切る
 ↓
⑤【リプ1】1位：見出し＋理由2行
 ↓
⑥順位の話を離れ、原則・解釈に一般化して締める
```

## 抽象テンプレート
```
【立場・経験】から見た、【対象】の【評価軸】ランキング↓

3位「【項目】」
・【理由1】
・【理由2】

2位「【項目】」
・【理由1】
・【理由2】

1位は…↓

【リプ】
1位「【項目】」
・【理由1】
・【理由2】

【この順位から読み取れる原則】。
【読者への一段上のメッセージ】。
```

## 相性の良いテーマ
- 優劣・頻度・影響度で並べられるテーマ（口癖、行動、失敗理由、評価される姿勢）
- 主観でも成立するテーマ（数値の出典が要らない）
- 1項目を短い見出しで書けるテーマ

## 相性の悪いテーマ
- 順位をつける根拠がないのに、数値を伴うテーマ（年収ランキングなど。出典が必須）
- 項目が3つ未満のテーマ

## バリエーション

### A. 多段リプ型（5位〜1位／参考投稿⑥）
本文で3段階の格付けをしてから、リプで5位〜1位を小出しにする派生。
リプを3〜4本に分け、毎回「ここからが重要です↓↓」で引っぱる。
各順位に「意外と穴場」「安定して稼げる」などのラベルを付けると、順位に意味が乗る。
最後のリプで共通点を言語化し、個別の話を原則に変えて締める。
参考：`../references/2026-09-23-nori/06-ホワイト業界ランキング.md`

### B. 企業ランキング型（10位〜1位／参考投稿⑨）
対象を企業にして、10位から順に公開する派生。
各社を「社名 → 数値2項目 → 一言評価」で完全に統一する。2軸（年収 × 残業など）にすると納得感が増す。
本文は10位・9位のみ、8位以降を2本のリプに分ける。
⚠️ 企業ごとの数値が主役になるため、**出典のある数字だけ**を使う。
生成時は `【　】` にして、本人が有価証券報告書や公式情報で確認してから埋める。
参考：`../references/2026-09-23-nori/09-SaaS年収ランキング.md`

### C. 20位一気出し型（2026-09-23 追加・参考投稿⑥）
20位〜1位を**1投稿で一気に出す**派生。リプに分けない。

- 各項目はセリフや単語1行にする。短いので20項目でも読み切れる
- 1位だけ毛色を変える（単語ではなく「型」＋例文）と、着地に重みが出る
- 冒頭に「一瞬で」「3秒で」などの時間表現を入れると、読む価値が上がる
参考：`../references/2026-09-23-kei/06-20位ランキング.md`

## 文体・見た目のメモ
- 文章量：本文250〜350字／リプ150〜250字
- 順位の見出しはカギ括弧で囲むと目に留まる
- 理由は必ず「・」2行に揃える。3行になると崩れる
- メダル記号（金銀銅）を使う場合は順位ラベルとして機能させる。装飾では使わない
