# 構文名：バラバラ→つながり提示型

## この構文が読まれやすい理由
- 1行目がタイトル形式（「〇〇5選」）なので、中身を読む前に価値が伝わる。判断コストがゼロ。
- 「個別に勉強してたけど、後から全部つながった」という**過去の自分の状態**を出すことで、今バラバラなまま悩んでいる読者が「自分の話だ」と感じる。
- ↓ で縦に並べるだけで順番・因果が視覚化される。文章で説明されるより早く理解できる。
- 「最初は〜に見える。でも〜」の転換で、読者の現在地をいったん肯定してから引き上げるので、説教に聞こえない。
- 締めが押しつけのない方法論（「〜で覚えるのがおすすめ」）。保存されやすい。

## 基本構造
```
①タイトル形式のフック（「〇〇n選」「〇〇の順番」）
 ↓
②かつての自分の状態＋気づき（共感フック）
 ↓
③要素を↓で縦に連結（4〜6個／解説なし）
 ↓
④「最初は〇〇に見える」＝読者の現在地を言語化
 ↓
⑤「でも〜すると、急に〇〇できるようになった」＝転換点
 ↓
⑥一般化した方法論で締める
```

## 抽象テンプレート
```
【対象読者】が知ると「点と点がつながる」【領域】n選

【かつての自分の状態】。でも後から全部つながりました。

【要素1】
↓
【要素2】
↓
【要素3】
↓
【要素4】
↓
【要素5】

最初は全部バラバラに見えます。
でも【視点・道具】を見ながら考えると、急に【できるようになること】。

【領域】は単体より「【つながり】」で捉えるのがおすすめです。
```

## 相性の良いテーマ
- 順番・因果・段階があるテーマ（選考フロー、キャリアの積み上げ、年収が決まる仕組み）
- 読者がバラバラに認識していて、実は1本でつながっているテーマ
- 1要素を単語で書けるテーマ

## 相性の悪いテーマ
- 並列で優劣がないテーマ（順番がないのに↓でつなぐと嘘になる）
- 1要素に説明が必要なテーマ

## 文体・見た目のメモ
- 文章量：200〜300字。短め
- ↓ は行単体で置く。要素は単語〜短文
- 絵文字なし
- CTAなしでも成立する型（フォロー誘導を入れるならリプへ）
