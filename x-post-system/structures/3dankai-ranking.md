# 構文名：3段階格付け→本命公開型

## この構文が読まれやすい理由
- 「ダメ／無難／本命」と**格付けする姿勢**そのものが強い。読者は自分の候補がどこに入るか確認したくなる。
- 最初にNG群を出すので、「自分が狙っていたところがダメ側だった」という驚きで止まる。
- 本命だけを伏せて切るため、リプが必ず開かれる。
- リプを1項目1リプに分けてカウントダウンすると、最後まで追われる。
- 締めが個別の推薦ではなく**方法論の結論**なので、読後に行動指針が残る。

## 基本構造
```
①いま動くべき理由（タイミング）＋「〇〇↓」
 ↓
②ダメな群（ラベル＋理由）＋3項目
 ↓
③無難な群（ラベル＋理由）＋3項目
 ↓
④「本当におすすめは…↓」で切る
 ↓
⑤【リプ】本命をカウントダウンで1つずつ公開
　　　　　各項目は「概要 → 根拠となる事実 → 特徴 → 一言評価」で統一
 ↓
⑥最後に全体の結論（方法論に一般化）
```

## 抽象テンプレート
```
【いま動くべき理由】、【行動】の一番いいタイミング↓

【ダメ群のラベル】（【理由】）
・【項目1】 ・【項目2】 ・【項目3】
【無難群のラベル】（【理由】）
・【項目4】 ・【項目5】 ・【項目6】
本当におすすめは…↓

【リプ】本当のおすすめ Best【n】
【n】【項目名】
【概要】。【出典のある事実・数値】。【特徴】。
【一言評価（ただし短所も添える）】

（…①まで1リプずつ）

【立場】として断言できるのは、【方法論の結論】ということ。
```

## 相性の良いテーマ
- 選択肢が多く、優劣や難易度に差があるテーマ
- 「みんなが狙うところ」と「実は狙い目」のギャップがあるテーマ

## 相性の悪いテーマ
- 優劣をつけると角が立つテーマ
- 根拠が出せないテーマ（格付けは根拠がないと悪口になる）

## バリエーション

### A. ランク分け型（条件で格付けする・参考投稿⑩）
格付けの対象を**企業名ではなく条件**にする派生。社名を出さずに成立するので、事実確認の負担が軽い。
`入っても伸びない／そこそこ伸びる／一気に伸びる` のように3層へ分け、最上位だけリプで公開する。
リプ1の最後に「共通点は…」ともう一度引っぱり、リプ2で回収する**二段引き**が効く。
参考：`../references/2026-09-23/11-伸びるSaaS見分け方.md`

### B. 2段階版（2026-09-23 追加・参考投稿⑤）
「やめとけ」を省き、**穴場（銀）と本命（金）の2段階だけ**にする派生。
否定する対象がないので、企業名を出しても角が立たない。実名リストを使いたいときはこちらが安全。
リプの解説は個別の推薦ではなく、**構造の説明**（「倍率は良し悪しではなく知名度と応募数で決まる」）にすると納得感が出る。
参考：`../references/2026-09-23-nori/05-BtoB2段階.md`

### C. 2段階・社名のみ型（難易度ラベル／2026-09-30 追加・参考投稿①）
バリエーションBをさらに削ぎ落とし、**解説を完全に無くして社名だけ**を並べる派生。
格付けのラベルを「難易度」にするので、企業の良し悪しではなく**入りやすさ**の話になり、角が立たない。

```
①見出し1行（「中途入社しやすい【カテゴリ】」だけ。前置き・権威づけなし）
 ↓
②【カテゴリn社（難易度高）】＋社名を2列で圧縮して並べる
 ↓
③【カテゴリn社（難易度中）】↓ ＝ 群のラベルだけ出して中身を伏せる
 ↓
④【リプ】同じラベルを見出しに繰り返し、社名を1列で縦に並べる。締めもCTAもなし
```

効いているのは次の3点。
- グループ名に**社数と難易度をセットで入れる**（全部見たい＋自分はどっちを狙うべきか、が同時に立つ）
- 難易度が高→中に下がる順。手が届かない側を見せた後に、届く側をリプで出す
- 本文は2列で圧縮、リプは1列で開く。同じリストでも並べ方を変える

社名は正式名称で書く（略称だと検索されない）。社数はテーマごとに変えてよく、
**確実に挙げられる社数に合わせてラベルの数字を書く**のが安全。
ラベルは難易度のほか、**メダル絵文字**（🥈部署・職種次第で可能／🥇比率が非常に高い）でもよい。
実在企業の制度を扱うときは、断定せず**相対表現に留める**（〜次第で可能／〜比率が高い）。
「友達が勤務してる」のように情報の出どころを体験に寄せると、断定の責任を負わずに社名を出せる。
参考：`../references/2026-09-30-tamura/01-2段階社名リスト.md`
　　　`../references/2026-10-01-nori/02-メダル2段階社名.md`

### D. メダル格付け＋多段リプ型（2026-10-01 追加・参考投稿①）
格付けラベルを**メダル絵文字**（🥉やめとけ／🥈無難／🥇いちばん確実）にし、
リプを4本つないで引きを4回作る派生。

```
①読者の属性で名指し＋常識の順番を入れ替える提案（命令形）
 ↓
②🥉やめとけ ＋1項目（あえて薄く）
 ↓
③🥈無難 ＋1項目（あえて薄く）
 ↓
④🥇いちばん確実なのは↓ でラベルだけ出して切る
 ↓
⑤【リプ1】🥇の中身＋根拠3項目 →「その他も含めて解説します↓」で範囲を広げて引き直す
 ↓
⑥【リプ2】ランキング5位〜3位。各順位に状態のラベルを付ける →「ここからが重要です↓」
 ↓
⑦【リプ3】2位・1位 →「解説↓」で理屈を伏せる
 ↓
⑧【リプ4】原理の回収（〇〇は、Aではなく B で決まります）＋確認方法＋言い切りの締め
```

引きの言葉を毎回変えるのが核心。本命を出し切ったあとにもう一度引けるのは、
リプ1で「その他も含めて」と**範囲を広げる宣言**をしているため。
各順位に「条件つき」「ほぼ動かない」「構造的に動かない」のような**状態のラベル**を付けると、
順位の差に納得感が出る。1順位あたり2項目に抑える。
参考：`../references/2026-10-01-nori/01-メダル格付け多段リプ.md`

### E. リプ1本に長文解説型（2026-10-05 追加・参考投稿⑦）
🥉🥈🥇で格付けしたあと、**リプを1本だけにして長文の解説を全部入れる**派生。
Best7のように1項目1リプに分けないので、連投を組まなくていい。

```
①「〇〇するなら」の1行
 ↓
②🥉危険 ＋2項目（意味も添える）
 ↓
③🥈普通 ＋2項目
 ↓
④🥇本当のオススメは⇩ で切る
 ↓
⑤【リプ】🥇の中身を3つ並べ、「〇〇回路」のような名前をつける
 ↓
⑥「なぜ〇〇ばかり使うと損をするのか？」＝読者の疑問を代弁
 ↓
⑦❶❷❸で3ステップの解説（各150〜250字）
 ↓
⑧3つを再掲して圧縮 ＋ 一般化した締め ＋ CTA
```
🥉🥈の項目にカッコで意味を添えるのがこの派生の特徴。
格付けの段階で既に情報として成立しているので、リプを開かない人にも価値が残る。

## ⚠️ 運用上の注意
- 実在の企業を「やめとけ」側に置くと、事実ではなく評価が断定として広まる。
  **企業名で格付けする場合は、必ず出典のある事実に限り、評価は「未経験の枠が少ない」など条件の話に留める。**
  迷う場合はバリエーションA（条件で格付け）を使う。
- 数値を入れる場合は有報・公式情報など出典のあるものだけ。生成時は `【　】` にする。

## 文体・見た目のメモ
- 文章量：本文200〜300字／リプ各150〜250字
- 絵文字は使わない（haruは記号のみ）
- ラベルは短く。理由をカッコ書きで添える

### F. メダル→本命先出し→多段リプランキング型（2026-10-05 追加・参考投稿①）
本文はメダル3段階だが、🥉と🥈は**各1項目だけ**に絞って短くする。
【リプ1】で🥇の中身を先に出し、根拠を3点添えてから「その他も含めて解説します↓」で
もう一度引っぱる。【リプ2】以降でランキングを5位から下から順に並べ直す。
ランキングの各順位には**群のラベル**（意外と穴場／安定して稼げる／ホワイト率高め など）を付け、
項目は2つずつ。最後のリプで「共通点は〇〇」と原則に一般化して締める。

```
【権威づけ】、【テーマ】はここです

🥉やめとけ
・【1項目】

🥈無難
・【1項目】

🥇本当の【穴場】は↓

【リプ1】
🥇本当の【穴場】
・【本命】

・【根拠1】
・【根拠2】
・【根拠3】

その他も含めて解説します↓

【リプ2】
【テーマ】ランキング

5位：【群ラベル】
・【項目】
・【項目】

4位：【群ラベル】
・【項目】
・【項目】

3位：【群ラベル】
・【項目】
・【項目】

ここからが重要です↓

【リプ3】
2位：【群ラベル】
・【項目】
・【項目】

1位：【群ラベル】
・【項目】
・【項目】
・【項目】

解説↓

【リプ4】
共通点は「【共通点1】」「【共通点2】」「【共通点3】」ことです。

【なぜそうなるかの説明を2〜3行】

【逆張りの一言で締める】
```

ポイントは**本命を2回出す**こと。リプ1で先出しして、リプ3の1位でもう一度出す。
途中から読んだ人にも結論が届くので、多段リプでも離脱しにくい。
