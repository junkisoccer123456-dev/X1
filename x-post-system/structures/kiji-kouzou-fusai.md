# 構文名：長文記事構文（不安提示→構造説明→処方箋）

## この構文が読まれやすい理由
- 冒頭が**比喩による不安の言語化**（「静かに負債化します」）。まだ起きていない痛みを先に見せるので、他人事にできない。
- 「今は問題なく見える」→「でも将来こうなる」という時間差の構造が、危機感を作る。
- 各セクションが「■見出し → 箇条書き → 一文の断定」で統一されていて、長文でもリズムが崩れない。
- 中盤に「では、もう終わりなのか？」と**読者の反論を先回り**して置く。ここで救いが見えるので離脱しない。
- 処方箋が10個。数が多いほど「まだやれることがある」という安心になる。
- 締めは行動1つに絞る。長い記事の最後に、やることが1つだけ残る設計。

## 基本構造
```
①比喩で不安を言語化（〇〇すると、未来は△△になります）
 ↓
②今は問題なく見える状態を箇条書き（5つ）
 ↓
③「でも〇年後、これが牙を剥きます」と時間差を提示
 ↓
④■セクション1：なぜそうなるのか（特徴の箇条書き → 一言の結論）
 ↓
⑤■セクション2：相手（企業・市場）が求めるもの（質問や基準の箇条書き）
 ↓
⑥■セクション3：放置するとどうなるか（起きることの箇条書き）
 ↓
⑦■「では、もう終わりなのか？」＝読者の反論を先回り（完全に終わりではない、ただし）
 ↓
⑧▼処方箋10（各：行動＋一言の理由）
 ↓
⑨■結論（まだ間に合う → 書き換えられる → 今日やること1つ）
```

## 抽象テンプレート
```
【対象読者】が【楽な選択】をすると、未来は【比喩】します。

・【今は良く見える状態1〜5】

【今の評価】。でも【時期】に入った瞬間、これが牙を剥きます。

■ 【なぜそうなるのか】
・【特徴1〜6】
この状態で【時期】に突入すると、【一言の結論】

■ 【相手が求めるもの】
・【問われること1〜5】
ここで語れない人は、【どう扱われるか】

■ 【放置するとどうなるか】
・【起きること1〜5】

■ では、【対象読者】はもう終わりなのか？
完全に終わりではありません。ただし【条件】。

▼【今日からの10の行動】
① 【行動】
　【一言の理由】
（…⑩まで）

■ 結論
【まだ間に合う】。【書き換えられる】。
【未来を変える唯一の方法】は、今日、【具体的な一歩】をすることです。
```

## 相性の良いテーマ
- 今は問題ないが、放置すると後で効いてくるテーマ（キャリア、スキル、健康、人間関係）
- 読者が薄々気づいているが、直視していないテーマ
- 処方箋を10個出せるテーマ

## 相性の悪いテーマ
- 短期で結果が出るテーマ（時間差の構造が作れない）
- 不安を煽るだけで解決策が出せないテーマ

## ⚠️ 運用上の注意
不安を起点にする型なので、**煽りっぱなしにしない**こと。
必ず「まだ間に合う」と処方箋をセットにする。
断定が強い型だが、事実ではなく判断であることが分かる書き方にする
（「〇割決まります」のような数字は、根拠がない場合は避けるか、肌感と分かる形にする）。

## 文体・見た目のメモ
- 文章量：2,000〜3,000字
- セクション見出しは ■、処方箋は ▼ と①〜⑩
- 1文を短く。改行を多めに入れて、スマホで読めるリズムにする
- 絵文字なし
