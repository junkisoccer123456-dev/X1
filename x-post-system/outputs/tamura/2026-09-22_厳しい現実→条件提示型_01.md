# 使用した構文：厳しい現実→条件提示型（参考投稿③）

①一度肯定 → ②必要条件を誇張して列挙 → ③不利な事実を1行 → ④通る人の条件①②③ → ⑤言い切って終わる

# 選定した10テーマ

1. 30代からのマネジメント転向
2. 実務1年での自社開発転職
3. 資格で転職を有利にする
4. 年収100万アップの転職
5. 40代で初めての転職
6. フルリモート専業への転職
7. ブランク1年からの復帰
8. 副業・個人開発の実績だけでの転職
9. SESから大手事業会社への一発転職
10. 転職回数が多い状態からの立て直し

━━━━━━━━━━━━━━━━━━
投稿01｜30代からのマネジメント転向
━━━━━━━━━━━━━━━━━━
30代からマネジメント側に回るのは不可能ではないですが「技術で一目置かれてる・人の話を最後まで聞ける・数字の責任から逃げない」を全部持った聖人みたいな人ならいけます。さらにポストの数自体が少ない。

転向で通るのは ①現職でリーダー経験がある ②育成した人の名前が出せる ③プレイヤーに戻る覚悟もある これが揃わないと厳しいかと。

━━━━━━━━━━━━━━━━━━
投稿02｜実務1年での自社開発転職
━━━━━━━━━━━━━━━━━━
実務1年で自社開発に移るのは不可能ではないですが「設計の意図を自分の言葉で話せる・個人開発でも運用まで回してる・現職の粗さを他人のせいにしない」が揃った人ならいけます。しかも同じ枠に3年組が並びます。

1年で通るのは ①任された範囲が明確 ②コードを見せられる ③入社後に学ぶ順番を説明できる ここが弱いと、経験年数だけで比較されて終わります。

━━━━━━━━━━━━━━━━━━
投稿03｜資格で転職を有利にする
━━━━━━━━━━━━━━━━━━
資格で有利になるのは不可能ではないですが「業務で使った文脈が語れる・取得後に手を動かしてる・資格の話を最後まで引っぱらない」人に限ります。正直、僕は資格欄より直近の担当範囲を先に見ます。

資格が効くのは ①未経験に近い領域への挑戦 ②入札や認定で会社側に必要 ③学習を継続できる証明 この3つ以外では、決め手にはならないかと。

━━━━━━━━━━━━━━━━━━
投稿04｜年収100万アップの転職
━━━━━━━━━━━━━━━━━━
一度の転職で年収100万上げるのは不可能ではないですが「今が明らかに相場割れ・任せられる範囲が一段広い・複数内定を並べられる」の条件が要ります。1社だけ受けて交渉、はほぼ通りません。

100万上がるのは ①現職の評価と市場がズレている ②即戦力として配属先が決まっている ③他社の評価が材料としてある このどれかが必要です。気合いでは動かないです。

━━━━━━━━━━━━━━━━━━
投稿05｜40代で初めての転職
━━━━━━━━━━━━━━━━━━
40代で初めて動くのは不可能ではないですが「一人で完結できる・若手を見られる・過去のやり方に固執しない」が揃った人ならいけます。求人数は確実に減ります。

40代で通るのは ①今の会社の名前ではなく自分の実績を語れる ②年下の上司でも普通に働ける ③年収を一度横ばいにする選択肢も持っている ここが全てかと。

━━━━━━━━━━━━━━━━━━
投稿06｜フルリモート専業への転職
━━━━━━━━━━━━━━━━━━
フルリモート一本に絞るのは不可能ではないですが「自走できる・テキストで過不足なく説明できる・進捗を自分から出せる」が揃った人ならいけます。そのうえ倍率は体感でかなり上がります。

リモート前提で通るのは ①一人で完結した実績がある ②非同期のやり取りに慣れている ③週1出社までは許容できる 最後の1つを外すと、母数が一気に減ります。

━━━━━━━━━━━━━━━━━━
投稿07｜ブランク1年からの復帰
━━━━━━━━━━━━━━━━━━
ブランク1年からの復帰は不可能ではないですが「空白の理由を一言で説明できる・手を動かし続けてた証拠がある・条件を一度譲れる」人ならいけます。理由を濁すのがいちばん損です。

復帰で通るのは ①ブランクの理由が説明できる ②直近で触った技術がある ③最初の半年は評価を取りにいく姿勢がある 隠すより、先に出したほうが早いかと。

━━━━━━━━━━━━━━━━━━
投稿08｜副業・個人開発の実績だけでの転職
━━━━━━━━━━━━━━━━━━
個人開発の実績だけで転職するのは不可能ではないですが「継続的に運用してる・他人が使ってる・障害対応の経験もある」レベルならいけます。動くものを作った、だけだと弱いです。

個人開発が効くのは ①運用まで回している ②ユーザーがいる ③技術選定の理由を説明できる ここまでいくと、実務経験の不足を補えるかと。

━━━━━━━━━━━━━━━━━━
投稿09｜SESから大手事業会社への一発転職
━━━━━━━━━━━━━━━━━━
SESから大手事業会社に一発で入るのは不可能ではないですが「参画案件で自分の判断を語れる・上流の経験がある・面接で現場の愚痴が出ない」人ならいけます。書類の時点で構成が問われます。

一発で通るのは ①案件ではなく役割で経歴を書けている ②設計かレビューの経験がある ③受け皿になる中堅企業も並行して受けている 順番を作れる人が結局いちばん早いです。

━━━━━━━━━━━━━━━━━━
投稿10｜転職回数が多い状態からの立て直し
━━━━━━━━━━━━━━━━━━
回数が多い状態からの立て直しは不可能ではないですが「各社で何を得たか言える・辞めた理由に一貫性がある・次で腰を据える理由がある」人ならいけます。回数そのものより、説明のほうが重いです。

多い状態で通るのは ①直近の在籍が一定以上 ②辞めた理由が他責になっていない ③今回の条件確認が具体的 ここが揃えば、回数は決定打にならないかと。
