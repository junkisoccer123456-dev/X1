# 使用した構文：n選＋リプ個別深掘り型（参考投稿②／既存構文をそのまま流用）

【〇〇❺選】の見出し → 誰向けか1行 → ❶〜❺（項目名＋1行の価値説明）
→ 価値を一度下げる（「〇〇は△△の代わりにはならないです」）→「が、〜を一段押し上げます↓↓」で切る
→【リプ❶〜❺】同じ項目名で再登場し、概要 →「採用側として正直に言うと」→ 選考でどう効くか

【書類で落ちたあとにやると次が変わること❺選】

同じ経歴書で出し続けている人が、通過率を一段上げるならこれかと。

❶落ちた求人の必須要件を線で引く
どの行に自分の経歴が当たっていないかを可視化する。原因が経歴書ではないこともあります。

❷冒頭3行を応募先ごとに書き替える
読まれるのは上から3行です。ここだけ差し替えるのが一番効きます。

❸同じ会社の別ポジションを見る
落ちたのは経歴ではなく枠違いのことが多いです。
❹書いていない実務を棚卸しする

社内では当たり前にやっていた作業が、外では実績になります。

❺3社分まとめて出すのをやめる
1社ずつ要件を読んでから出す。通過率は出す数より読む時間で動きます。

落ちた理由を推測しても当たらないです。が「どの行で外れたか」を特定する作業は、次の書類を一段押し上げます↓↓

【リプ❶】
❶落ちた求人の必須要件を線で引く
募集要項の必須欄を1行ずつ読み、自分の経歴書に対応する記述があるかを確認する作業です。
採用側として正直に言うと、書類で落ちる方の多くは経歴が弱いのではなく、必須の1行が埋まっていないだけなんですよね。埋まっていないのが「経験年数」なら今は打つ手がない。でも「書いていなかっただけ」なら今日直せます。

【リプ❷】
❷冒頭3行を応募先ごとに書き替える
職務経歴書の一番上に、応募先の要件に最も近い経験を置き直す作業です。
採用の現場で見ていると、1枚目の上から3行で読む深さが決まります。ここが「所属と担当範囲」で埋まっている方と、「何を任されて何を動かしたか」で埋まっている方で、読まれる量が変わるんですよね。

【リプ❸】
❸同じ会社の別ポジションを見る
落ちた会社の他の求人を確認し、工程や領域が自分に近いものがないかを探す作業です。
採用側の本音を言うと、同じ方を別ポジションで通すことは普通にあります。枠が埋まっていた、求める工程が違っただけ。会社ごと諦める必要はまったくないです。

【リプ❹】
❹書いていない実務を棚卸しする
手順書の整備、問い合わせ対応、ライブラリの更新など、書かずに済ませていた作業を洗い出す工程です。
採用の視点だと、ここが一番もったいない。社内で当たり前だった作業が、応募先では「それをやってくれる人がいなかった」仕事だったりします。思い出す作業に1時間使う価値はあるかと。

【リプ❺】
❺3社分まとめて出すのをやめる
同じ経歴書を複数社に同時送信するのをやめ、1社ずつ要件を読んでから出す形に変える話です。
採用側として、まとめて出された書類は読めば分かります。弊社の要件に触れた記述が1つもないので。数を減らしても通過数は落ちないことが多いです。

【選考を並行させるときの組み方❺選】

1社ずつ受けて疲れてしまう人が、進め方を一段整えるならこれかと。

❶本命は3社目以降に置く
最初に受けた会社で面接の精度が上がります。本命を1社目にしないのが基本です。

❷書類は週単位でまとめて出す
内定の時期が揃うので、比べて決められます。ばらけると比較ができません。

❸練習枠を2社だけ入れる
受けないと決めている会社を無理に入れる必要はないです。
❹1社あたりの準備時間を決めておく

無限にかけると他が止まります。3時間までと決めるだけで回ります。

❺辞退の連絡文を先に用意する
断る工程が重いと、進めるのが怖くなります。文面があるだけで動けます。

受ける数を増やしても確率は上がらないです。が「順番と時期を設計する」ことは、最後の判断を一段押し上げます↓↓

【リプ❶】
❶本命は3社目以降に置く
応募の順番を決めるときに、一番行きたい会社を最初に受けないようにする組み方です。
採用側として正直に言うと、同じ方でも1社目と3社目では受け答えの精度が明らかに違います。志望度が高い会社で練習することになるのは、普通に損だと思います。

【リプ❷】
❷書類は週単位でまとめて出す
応募を同じ週に固めて、選考の進み方をできるだけ揃える組み方です。
採用の現場で見ていると、内定の時期がばらけた方は決断を急かされます。1社だけ先に出ると、他を待てないんですよね。揃えておくと、比べてから選べます。

【リプ❸】
❸練習枠を2社だけ入れる
面接の場数を確保するために、受けてもいいと思える会社を数社だけ入れておく話です。
採用側の本音を言うと、行く気のない会社を大量に受けるのは誰も得しません。ただ2社だけなら、聞かれ方の癖を知る目的として機能します。

【リプ❹】
❹1社あたりの準備時間を決めておく
企業研究と想定質問の準備にかける上限時間を、あらかじめ決めておく話です。
採用の視点だと、準備量と評価は比例しません。ある水準を超えると差が出なくなる。そこを超えて使った時間は、他社の準備に回したほうが結果が出ます。

【リプ❺】
❺辞退の連絡文を先に用意する
断るときの文面を、選考を始める前に用意しておく準備です。
採用側として、辞退の連絡は普通に来るものなので、気にしなくていいです。ただ本人側は、断る工程が重いと応募そのものを絞ってしまう。先に書いておくと、選択肢を減らさずに進められます。

投稿03｜エージェントに最初に伝えておくこと❺選
━━━━━━━━━━━━━━━━━━
【エージェントに最初に伝えておくこと❺選】

来る求人がずれていると感じている人が、精度を一段上げるならこれかと。

❶受けない条件を3つ先に言う
希望より先にこれです。除外条件がないと、全部送られてきます。

❷今の選考状況を正直に出す
他社の進み具合で、紹介の順番が変わります。隠すと損します。

❸年収は下限だけ決めて伝える
上限を言うとそこで止まります。下限だけ出すのが基本です。
❹連絡してほしい時間帯を指定する

在職中なら必須です。日中に電話が来ると選考が進みません。

❺技術の経験は年数ではなく範囲で伝える
「3年」より「どこまで任されたか」です。紹介先の精度が変わります。

担当者を増やしても紹介の質は上がらないです。が「最初の面談で条件を絞る」ことは、来る求人の精度を一段押し上げます↓↓

【リプ❶】
❶受けない条件を3つ先に言う
勤務地、開発形態、担当工程などで、絶対に受けないものを最初に伝えておく話です。
採用側として正直に言うと、エージェント経由で来る応募は、本人の希望とずれていることが普通にあります。除外条件が共有されていないからです。希望を語るより、こちらのほうが効きます。

【リプ❷】
❷今の選考状況を正直に出す
他社の選考がどこまで進んでいるかを、隠さずに伝えておく話です。
採用の現場で見ていると、他社の進度が共有されている方は選考が速く組まれます。こちらも日程を寄せられるので。隠しても有利にはならないです。

【リプ❸】
❸年収は下限だけ決めて伝える
希望年収を幅で言わず、「これ以下は受けない」の線だけを伝えておく話です。
採用側の本音を言うと、提示額は希望の上限を見て決めることがあります。上限を先に言う必要はまったくない。下限だけなら、紹介の絞り込みにも使えます。

【リプ❹】
❹連絡してほしい時間帯を指定する
電話とメールの受け取り方、連絡可能な時間を最初に決めておく話です。
採用の視点だと、連絡がつかない方は選考がそのまま止まります。日程調整が1往復遅れるだけで、枠が埋まることも普通にあるので。

【リプ❺】
❺技術の経験は年数ではなく範囲で伝える
「Javaを3年」ではなく、「設計から運用のどこまで任されたか」で伝える話です。
採用側として、年数だけでは判断できません。同じ3年でも、仕様を決めた人と実装だけの人では別物なので。範囲で伝わっている方は、紹介される求人の工程が合ってきます。

投稿04｜オファー面談で確認しておく条件❺選

【オファー面談で確認しておく条件❺選】

内定が出てから聞きにくくなる人が、入社後の誤算を一段減らすならこれかと。

❶提示年収の内訳
固定残業が何時間分入っているか。ここで実質の時給が変わります。

❷入社時の等級と、次の等級の要件
上がる条件が言葉になっていない会社は、上がらないです。

❸配属チームとプロダクト名
「調整中」のまま入ると、入社後に決まります。
❹評価のタイミングと初回の時期

入社月によっては、最初の評価が1年後になることがあります。

❺オンコールと休日対応の有無
制度ではなく実績で聞く。「直近3か月で何回あったか」が効きます。

条件を聞くと印象が悪くなる、はないです。が「書面に書かれていないものを確認する」ことは、入社後の納得を一段押し上げます↓↓

【リプ❶】
❶提示年収の内訳
提示された金額のうち、基本給と固定残業代、賞与の見込みがそれぞれいくらかを確認する話です。
採用側として正直に言うと、同じ年収額でも内訳は会社ごとに全然違います。固定残業が40時間分入っていれば、実質の単価は下がる。ここを聞く方は、冷静に比べられる方だと受け取ります。

【リプ❷】
❷入社時の等級と、次の等級の要件
どの等級で入るのか、1つ上がるために何が求められるのかを確認する話です。
採用の現場で見ていると、入社時の等級は後から動かしにくいです。交渉できるのはこのタイミングだけ。要件が文書になっていない会社は、正直に言うと上がる根拠が人によって変わります。

【リプ❸】
❸配属チームとプロダクト名
どのチームの、どのプロダクトを担当するのかを、名前で確認する話です。
採用側の本音を言うと、「入社後に適性を見て決定」のまま入った方は、人が足りない場所に入ることが多いです。決まっていないなら、いつ決まるのかまで聞いていいかと。

【リプ❹】
❹評価のタイミングと初回の時期
評価が年に何回あり、自分の初回がいつになるかを確認する話です。
採用の視点だと、入社月によって最初の評価が半年後にも1年後にもなります。ここを知らずに入ると、上がらない期間を実力のせいだと思ってしまうんですよね。

【リプ❺】
❺オンコールと休日対応の有無
夜間・休日の呼び出しが、直近3か月で実際に何回あったかを確認する話です。
採用側として、制度の説明なら誰でもできます。実績の回数を答えられる会社は、運用の実態を把握している会社です。答えが出てこないときは、そこが答えだと思っていいかと。

投稿05｜技術選定を語るときに使える材料❺選

【技術選定を語るときに使える材料❺選】

「選定は上が決めてました」で終わってしまう人が、話せる範囲を一段広げるならこれかと。

❶選ばなかった候補の名前
比較した跡があるかどうかで、判断の有無が伝わります。

❷選定の前提にあった制約
期限、人数、既存の資産。制約を言える人は現実的に見られます。

❸決めたあとに起きた誤算
うまくいった話より、ここが評価されます。
❹やめた技術と、やめた理由

入れる判断より、外す判断のほうが希少です。

❺同じ場面で今なら何を選ぶか
当時の判断を今の知識で評価できると、成長が伝わります。

決定権がなかったことは不利にならないです。が「判断の材料を持っている」ことは、面接での深掘りを一段押し上げます↓↓

【リプ❶】
❶選ばなかった候補の名前
採用した技術のほかに、検討対象に挙がっていたものを名前で挙げられるかという話です。
採用側として正直に言うと、ここが出てくるかどうかで会話の深さが変わります。候補が1つしかなかった話は、選定ではなく既定路線なので。決めた人でなくても、横で見ていれば答えられます。

【リプ❷】
❷選定の前提にあった制約
納期、メンバーの人数とスキル、既存システムとの接続など、選択を縛っていた条件の話です。
採用の現場で見ていると、制約を語れる方は信頼されます。技術の良し悪しではなく、その現場で成立する選択を考えた跡が見えるので。理想論だけの回答とは、明確に差が出ます。

【リプ❸】
❸決めたあとに起きた誤算
選んだ結果、想定と違った部分がどこだったかを話せるかという話です。
採用側の本音を言うと、成功談より誤算の話を聞きたいです。運用してみないと分からない部分を知っている方は、次の選定でも同じ失敗をしないので。

【リプ❹】
❹やめた技術と、やめた理由
導入していたものを外す判断に関わった経験の話です。
採用の視点だと、ここを経験している方は本当に少ないです。入れるのは誰でも提案できますが、外すのは移行コストを負う判断なので。1件でもあれば、面接では強い材料になります。

【リプ❺】
❺同じ場面で今なら何を選ぶか
当時の判断を、今の知識で振り返って評価できるかという話です。
採用側として、この質問は意図的に聞いています。当時のまま肯定する方と、条件が変わったから別を選ぶと答える方で、技術の追い方が分かるので。

投稿06｜障害対応の経験を評価に変える話し方❺選
━━━━━━━━━━━━━━━━━━
【障害対応の経験を評価に変える話し方❺選】

「障害対応もやってました」で止まってしまう人が、評価を一段上げるならこれかと。

❶検知までにかかった時間
気づくのが遅い仕組みだったなら、それ自体が課題として語れます。

❷切り分けの順番
どこから見たかを順番で言えると、再現性があると伝わります。

❸暫定対応と恒久対応を分ける
止めた話と直した話は別です。両方あると厚みが出ます。
❹再発したかどうか

再発していないなら、そこが一番強い実績になります。

❺対応後に残したもの
手順書、監視、アラートの条件。残したものが次の人を助けます。

件数を並べても評価は動かないです。が「1件を工程で分解して話す」ことは、経験の見え方を一段押し上げます↓↓

【リプ❶】
❶検知までにかかった時間
障害が起きてから気づくまでに何分かかったか、何をきっかけに気づいたかの話です。
採用側として正直に言うと、ここから入る方は少ないです。ユーザーからの連絡で気づいたなら、監視が足りていなかったという課題が語れる。自分の落ち度の話ではなく、仕組みの話になります。

【リプ❷】
❷切り分けの順番
どのログを見て、どこを疑って、何で確かめたかを順番で説明できるかという話です。
採用の現場で見ていると、順番で話せる方は次の現場でも同じことができます。たまたま直せた話と区別がつくので。面接では、ここが一番深掘りしたくなるところです。

【リプ❸】
❸暫定対応と恒久対応を分ける
その場で止めた対応と、原因を潰した対応を分けて話せるかという話です。
採用側の本音を言うと、暫定で止めた話しかない方は多いです。恒久対応まで入っていると、「設計まで触れる人」として読めます。両方あるなら、必ず分けて話してください。

【リプ❹】
❹再発したかどうか
対応した障害が、その後また起きたかどうかを言えるかという話です。
