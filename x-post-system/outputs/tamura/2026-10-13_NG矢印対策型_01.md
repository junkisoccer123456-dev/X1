# 使用した構文：矢印一行解説型 バリエーションE（参考投稿①）

見出し1行（視点＋「〜5選」）→ ・NGの状態／→ 対策1行 を5つ（空行なし）→ 締めなし

※この構文（yajirushi-ichigyou.md）は 2026-09-25（tamura・A/B）、
　2026-10-05・2026-10-12（nori・C／tamura・D）にも使用済み。
　過去60テーマ（職務経歴書にあると読む速度が上がる項目／説明できないと痛い用語10種／
　各種サイン10種／求人票の見分け方20種 ほか）は全件除外した。
　今回は「指摘される側・直す側」の視点で、選考の各場面（書類・冒頭30秒・技術説明・
　転職理由・カジュアル面談・逆質問・ポートフォリオ・スカウト・内定後・退職）に軸を置いている。
　参考投稿のテーマ（コードレビューでの指摘）そのものは使っていない。

投稿01｜書類で落ちる原因になりやすい書き方
━━━━━━━━━━━━━━━━━━
採用側から見て、書類で落ちる原因になりやすい書き方5選
・担当業務の羅列だけ
→ 自分が決めたことを1行足す
・「など」で終わっている
→ 範囲を狭めて言い切る
・数字がどこにもない
→ 人数、期間、件数のどれかを入れる
・技術名の列が長い
→ 実務で使ったものだけ残す
・自己PRが抽象語で埋まる
→ 場面を1つ書いて代わりにする

━━━━━━━━━━━━━━━━━━
投稿02｜面接の冒頭30秒でやりがちなこと
━━━━━━━━━━━━━━━━━━
面接官として見ていて、冒頭30秒でやりがちなこと5選
・新卒から順に話し始める
→ 直近の2年だけに絞る
・会社名から入る
→ 領域と年数を先に言う
・役割が「開発です」で終わる
→ 担当範囲を一段細かく言う
・書類の内容を読み上げる
→ 書いていない判断の話を入れる
・志望理由まで詰め込む
→ 聞かれるまで置いておく

━━━━━━━━━━━━━━━━━━
投稿03｜技術の説明でつまずきやすいところ
━━━━━━━━━━━━━━━━━━
面接で技術の話を聞いていて、つまずきやすいところ5選
・構成の説明で終わる
→ なぜその構成にしたかまで言う
・採用した技術しか出てこない
→ 比べて落とした案も出す
・規模の話がない
→ 台数、件数、利用者数のどれかを添える
・担当範囲が曖昧
→ どこまで手を入れたかを区切る
・うまくいった話だけになる
→ 想定と違った点を1つ出す

━━━━━━━━━━━━━━━━━━
投稿04｜転職理由の伝え方で直したほうがいいこと
━━━━━━━━━━━━━━━━━━
採用側として聞いていて、転職理由で直したほうがいいこと5選
・現職の不満から始まる
→ やりたいことから先に言う
・「成長したい」で止まる
→ 何を伸ばすかを1つに絞る
・会社の規模の話になる
→ 仕事の中身の違いで話す
・前職を下げて説明する
→ 学んだことを一言入れる
・どこでも言える理由になっている
→ 応募先の事業に接続する

━━━━━━━━━━━━━━━━━━
投稿05｜カジュアル面談でやりがちなこと
━━━━━━━━━━━━━━━━━━
面談を設定する側から見て、カジュアル面談でやりがちなこと5選
・準備なしで来る
→ 30秒の経歴だけ用意する
・聞きたいことを決めていない
→ 配属と1日の流れを3つに絞る
・会社説明を聞いて終わる
→ 自分の経験との接点を1つ確かめる
・現職の不満を話す
→ 構造の説明に言い換える
・その場で応募を決める
→ 持ち帰って週内に返す

━━━━━━━━━━━━━━━━━━
投稿06｜逆質問でもったいない聞き方
━━━━━━━━━━━━━━━━━━
面接官として聞いていて、逆質問でもったいない聞き方5選
・調べれば分かることを聞く
→ 調べた前提を添えてから聞く
・例文をそのまま使う
→ 自分が判断に使う情報に変える
・条件だけを3つ聞く
→ 仕事の中身を2つ、条件を1つ
・質問を5個以上並べる
→ 3つに絞って1つ重ねる
・「特にありません」で終える
→ 当日の話の確認に変える

投稿07｜ポートフォリオでよく指摘すること
━━━━━━━━━━━━━━━━━━
採用側として見ていて、ポートフォリオでよく指摘すること5選
・作ったものの説明だけ
→ 誰の何が楽になったかを書く
・技術スタックの羅列で終わる
→ 選んだ理由を1行添える
・動くものが置かれていない
→ 公開先か動画を用意する
・説明書きが見出しだけ
→ 起動手順と設計の意図を書く
・コミットが1回しかない
→ 作っていく過程を残す

→ どこに興味を持ったかを1行

→ 応募前提か情報収集かを書く

→ 候補の枠を2つ出す
・条件の希望を伏せる
→ 譲れない条件を1つだけ先に出す
・1週間後に返す
→ 48時間以内に一次返信する

→ 書面に入っているかを確かめる
・返答期限をそのまま飲む
→ 日付を切って延長を相談する

投稿10｜退職の伝え方で失敗しやすいこと
