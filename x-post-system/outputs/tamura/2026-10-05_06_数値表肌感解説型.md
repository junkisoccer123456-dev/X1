# 使用した構文：数値表＋肌感解説型（参考投稿⑥／新規作成）

【〇〇、実は"△△"で□□が変わる】の見出し → 2要素のかけ合わせ×評価を5行の表（全角スペースで右列を揃える）→
「僕が見てきた肌感だと」＋表の読み方 → よくある誤解の指摘 → 行動の優先順位で締める

## ⚠️ 数字についての判断（重要）

参考投稿は表の右列を「68% / 52% / 33% / 21% / 12%」とパーセンテージで出していますが、
これは投稿者自身の肌感であって出典のある統計ではありません。
tamuraのカード（8・13）が「根拠のない数字」を禁止しているため、
**右列はパーセンテージではなく段階表現**（いちばん通る／よく通る／半分くらい／かなり厳しい／まず通らない）にしました。

実数を出したい場合は、ご自身の肌感の数字に差し替えて投稿してください。
表の形は崩れないので、右列を数字に置き換えるだけで参考投稿と同じ見た目になります。

※左列は上から下へ「近い → 遠い」の順に並べています。読者が自分の行を下に探すほど不安になる設計です。

# 選定した10テーマ
1. 年齢×実務年数で見た書類の通りやすさ
2. 応募経路×書類の作り込み
3. 現年収×希望年収の上げ幅
4. 在籍年数×転職回数
5. 企業規模×求められる即戦力度
6. 使用技術の一致×設計経験の有無
7. 資格の有無×実務年数
8. 応募タイミング×ポジションの空き
9. 面接の受け答えの具体度×評価
10. ポートフォリオの有無×実務経験

投稿01｜年齢×実務年数で見た書類の通りやすさ
━━━━━━━━━━━━━━━━━━
【エンジニアの書類、実は"年齢と年数の釣り合い"で通過率が変わる】

28歳×実務6年　　　　　　いちばん通る
32歳×実務9年　　　　　　よく通る
35歳×実務5年　　　　　　半分くらい
38歳×実務3年　　　　　　かなり厳しい
42歳×実務2年　　　　　　まず通らない

僕が書類を見てきた肌感だと、通過率ってスキルの高さより"年齢に対して年数が足りているか"で動くものです。
振り返ると、落ちてる人の多くは技術が弱いんじゃなくて、年齢の割に年数が短いだけなんですよね
結局、書類を盛るより「年齢に合うポジションを選ぶ」が先。そこに尽きるかと思います。

結局、額を下げるより「実績を数字で3つ用意する」が先。そこに尽きるかと思います。
