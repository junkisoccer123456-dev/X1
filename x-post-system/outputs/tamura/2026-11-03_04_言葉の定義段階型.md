# 使用した構文：言葉の定義段階型（参考投稿④／既存構文をそのまま流用）

現場でよく使われる一言をカギ括弧で置く →「この一言、人によって意味が全然違うんですよね」
→ ・段階1（いちばん浅い定義）→ ・上記に加えて、段階2 → ・上記を満たしたうえで、段階3〜5
→「面接でも〜の"〇〇"がどの段階を指すかで、評価はガラッと変わります」

※この構文は 2026-10-05_04・2026-10-12_04・2026-10-28_04 にも使用済み（計30セリフ）。
CLAUDE.md 6.5 に従い全件除外し、軸を**「成果と範囲を指す言葉」**に移しました。
