# 使用した構文：NG連打→OK提示型 バリエーションF（参考投稿⑤／既存構文をそのまま流用）

「〇〇が書類で損してるNG項目。」→「変えるべきは「〜をやめる」こと。」→ NG（1文）→ OK（2行）
→「「担当した」と「〇〇した」は天と地の差があります。」→「僕が見てるのは、〜より、〜です。」
→「職務経歴書を直すなら動詞を「担当した」から「〇〇した」…に書き換えるだけでいいです。」

※この構文は 2026-10-05_05・2026-10-12_05・2026-10-28_05 にも使用済み（計30テーマ）。
他アカウントのバリエーションA〜Eも確認済み。CLAUDE.md 6.5 に従い全件除外し、
軸を**「経歴の中の説明しにくい場面」**に移しました。

投稿01｜転職回数が多い経歴の書き方

転職回数が多い方が書類で損してるNG項目。
変えるべきは「在籍期間の"羅列"をやめる」こと。

NG
A社2年、B社2年、C社2年で開発を担当した。

OK
3社すべてで既存システムの改修から入り、
立ち上がりまでの期間を2か月→3週間に短縮した。

「担当した」と「短縮した」は天と地の差があります。
僕が見てるのは、何社いたかより、社をまたいで何が積み上がったかです。
職務経歴書を直すなら動詞を「担当した」から「短縮した」「持ち込んだ」「共通化した」に書き換えるだけでいいです。
