# 使用した構文：カウントダウンランキング型（参考投稿③⑥⑨・新規）

3位→2位（見出し＋理由2行）→「1位は…↓」で切る →【リプ】1位＋原則に一般化して締め

# 選定した10テーマ

1. 上司に信頼される報告の仕方
2. 20代がやりがちな転職の失敗
3. 面接で落ちる本当の理由
4. 職務経歴書で損している書き方
5. 転職して後悔する理由
6. 20代のうちに身につけたい力
7. 辞めたい理由で多いもの
8. 転職活動で時間を溶かす行動
9. 第二新卒が評価される条件
10. 上司が評価する仕事の進め方

━━━━━━━━━━━━━━━━━━
投稿01｜上司に信頼される報告の仕方
━━━━━━━━━━━━━━━━━━
マイナビで2万人以上の転職支援をしてきましたが、上司に信頼される報告の仕方には順番があります↓

3位「結論から言う」
・聞く側の負担が一気に減る
・時間を奪わない人だと伝わる

2位「悪い報告を先に出す」
・手を打つ時間が残る
・隠さない人だと分かる

1位は…↓

【リプ】
1位「事実と意見を分ける」
・判断材料が濁らない
・上司が自分で考えられる

報告が上手い人は、話し方を変えてるんじゃないです。相手が何を判断したいかを先に考えてるだけ。

20代のみなさん、ここは才能ではなく順番かと。

━━━━━━━━━━━━━━━━━━
投稿02｜20代がやりがちな転職の失敗
━━━━━━━━━━━━━━━━━━
マイナビで転職支援してましたが、20代の失敗はだいたい同じところで起きます↓

3位「勢いで辞めてから探す」
・選択肢が減って足元を見られる
・焦りが条件の妥協につながる

2位「求人票を読まずに応募する」
・必須要件を外して書類落ち
・落ちた理由が自分で分からない

1位は…↓

【リプ】
1位「不満を条件に翻訳しないまま動く」
・同じ理由でまた辞めることになる
・面接でも軸がぶれて見える

辞めたい理由の裏返しが、そのまま次の条件です。

ここを言葉にしてから動いた人は、ぶっちゃけ結果が全然違うかと。

━━━━━━━━━━━━━━━━━━
投稿03｜面接で落ちる本当の理由
━━━━━━━━━━━━━━━━━━
面接で落ちる理由、能力不足だと思われがちですが実際は違います↓

3位「話が長い」
・要点が拾えず印象に残らない
・打ち合わせでも同じだと想像される

2位「志望動機が他社でも通る」
・調べてきた感が出ない
・志望度が低いと判断される

1位は…↓

【リプ】
1位「退職理由と志望動機がつながっていない」
・またすぐ辞めると思われる
・一貫性がないと話が信用されない

面接官がいちばん恐れているのは早期離職です。

不安を消しにいくほうが、アピールより先かと。

━━━━━━━━━━━━━━━━━━
投稿04｜職務経歴書で損している書き方
━━━━━━━━━━━━━━━━━━
マイナビ時代、惜しい経歴書を山ほど見てきました↓

3位「業務を時系列で並べただけ」
・何ができる人か残らない
・読み終わっても印象がゼロ

2位「主語がチームのまま」
・自分の担当範囲が見えない
・配属先を想像してもらえない

1位は…↓

【リプ】
1位「数字が一つも入っていない」
・規模感が伝わらない
・比較のしようがなく後回しにされる

売上じゃなくていいです。件数でも人数でも期間でも大丈夫。

20代のみなさん、経歴を盛るより先に、数字を1つ入れてみてください。

━━━━━━━━━━━━━━━━━━
投稿05｜転職して後悔する理由
━━━━━━━━━━━━━━━━━━
転職後に「失敗した」と感じる理由、上位はこれです↓

3位「年収だけで決めた」
・残業前提かどうかで実態が変わる
・時給に直すと下がっていることもある

2位「配属を確認しなかった」
・同じ会社でも部署で別世界
・希望と違う仕事が始まる

1位は…↓

【リプ】
1位「人間関係を運任せにした」
・上司との相性で働きやすさが決まる
・制度より毎日話す相手の影響が大きい

二次面接に出てくる人が、入社後の上司であることは多いです。

会社を見るついでに、その人も見ておくといいかと。

━━━━━━━━━━━━━━━━━━
投稿06｜20代のうちに身につけたい力
━━━━━━━━━━━━━━━━━━
転職市場で評価される20代には共通点があります↓

3位「段取りを組む力」
・任せても不安がない
・一人で完結できる人と見られる

2位「言語化する力」
・やったことを説明できる
・経験が評価に変換される

1位は…↓

【リプ】
1位「自分で判断した経験」
・再現性があると判断される
・どの会社でも通用する

やったことより、決めたこと。

経歴書に「自分が決めた場面」を1つ書けるかどうかで、見え方が変わるかと。

━━━━━━━━━━━━━━━━━━
投稿07｜辞めたい理由で多いもの
━━━━━━━━━━━━━━━━━━
マイナビで面談していて、20代から出てくる理由はだいたいこの3つでした↓

3位「給与が上がらない」
・評価基準が見えないことが多い
・頑張りどころが分からなくなる

2位「人間関係がしんどい」
・逃げ場がないと消耗が早い
・能力とは関係なく削られる

1位は…↓

【リプ】
1位「このままでいいのか不安」
・成長している実感が持てない
・同期や友人と比べて焦る

1位だけ、実は転職以外でも解決することがあります。

異動や担当変更で景色が変わる人もいるので、先に社内を確認してからでも遅くないかと。

━━━━━━━━━━━━━━━━━━
投稿08｜転職活動で時間を溶かす行動
━━━━━━━━━━━━━━━━━━
転職活動が半年以上かかる人、行動のクセが似ています↓

3位「1社ずつ受ける」
・1周に1ヶ月かかる
・比較ができず判断がぶれる

2位「完璧な求人を待つ」
・条件を全部満たす求人はほぼない
・探す時間だけが積み上がる

1位は…↓

【リプ】
1位「同じ書類で出し続ける」
・5社落ちたら原因は運ではない
・20社出しても結果は同じ

1回止まって直すほうが、結果的に早いです。

書類は作り直すたびに使い回せるので、ここへの投資はいちばん効率がいいかと。

━━━━━━━━━━━━━━━━━━
投稿09｜第二新卒が評価される条件
━━━━━━━━━━━━━━━━━━
第二新卒は不利だと思われがちですが、評価されるポイントがあります↓

3位「辞めた理由を他責にしない」
・同じことを繰り返さないと思える
・一緒に働く画が浮かぶ

2位「短い期間でも得たものを言える」
・吸収する力があると伝わる
・次でも同じように伸びると想像される

1位は…↓

【リプ】
1位「社会人の基礎ができている」
・連絡が返る、期日を守る、報告する
・教える側の負担が一気に減る

派手な実績はいりません。

新卒より少し慣れていて、まだ素直。ここが第二新卒の強みかと。

━━━━━━━━━━━━━━━━━━
投稿10｜上司が評価する仕事の進め方
━━━━━━━━━━━━━━━━━━
同じ仕事量でも評価が分かれる人、進め方が違います↓

3位「着手前に認識を合わせる」
・手戻りが消える
・確認の手間が減る

2位「途中経過を自分から出す」
・放置されている不安がなくなる
・軌道修正が早い

1位は…↓

【リプ】
1位「終わったあとに改善案を出す」
・次に活かす前提で動いている
・任せる範囲を広げたくなる

評価は成果だけで決まっていないです。

進め方を変えるだけで見え方が変わるので、20代のみなさんはここから試してみてください。
