# 使用した構文：帯分け全リスト型（バリエーションG／参考投稿❶）

「【テーマ】、評価が上がる順」1行 → 🥉評価が下がる → 🥈まあまあ → 🥇【相手】が一番うれしいのはこれ↓ で切る
→ 【リプ1】🥇の中身を1つ（セリフ）＋効く理由を箇条書き4つ＋1行
→ 【リプ2】👇全20個👇／※【立場】としての主観です／S・A・B・C の帯で5項目ずつ／締め1行＋CTA

※既存の `3dankai-ranking.md` と骨格が一致。リプ2で20個を評価帯に分ける形が新しいため、
　バリエーションG として追記して使用した（新規構文は作っていない）。

※CLAUDE.md 6.5 に従い、この構文の過去100テーマを全件除外。
　とくに nori 分で使用済みの「面接の逆質問の選び方」（2026-10-01）があるため、
　参考投稿と同じ逆質問のテーマは二重に除外し、今回は
　書類 → カジュアル面談 → 面接 → 課題 → 資料 → リファレンス → 引き継ぎ → 初日 → 1on1 と
　**選考から入社後までの場面**で10テーマを散らした。

## 絵文字について
参考投稿の 🥉🥈🥇👇 をそのまま再現している（CLAUDE.md 7 がカルテの頻度指定より優先）。

## CTA について
参考投稿にCTAがあるため、カルテ10 に登録された定型文をリプ2の最後に置いた。
