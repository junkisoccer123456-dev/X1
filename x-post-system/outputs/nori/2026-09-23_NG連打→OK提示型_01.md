# 使用した構文：NG連打→OK提示型（バリエーションB／参考投稿⑦）

権威づけの一言 → 質問提示 → NG4連打（各NGの直後に一言斬り）→ 本文内で模範解答を見せきる

━━━━━━━━━━━━━━━━━━
投稿01｜転職理由
━━━━━━━━━━━━━━━━━━
マイナビで転職支援してましたが、この質問でつまずく人が本当に多いです。

面接官
「転職を考えた理由を教えてください」

お見送りの人1
「人間関係が合わなくて」
→ 他責に聞こえる。うちでも同じと思われる。

お見送りの人2
「残業が多くて体力的に厳しくて」
→ 環境の話だけ。何がしたいかが出てこない。

お見送りの人3
「評価されなかったからです」
→ 基準を確認していない人と見られる。

お見送りの人4
「スキルアップしたくて」
→ 抽象的すぎて志望動機につながらない。

内定とる人
「現職では既存顧客の対応を中心に担当してきました。継続率を上げる工夫を続ける中で、提案の設計から関わりたい気持ちが強くなりました。現職では担当範囲が決まっているため機会が限られます。御社は入社後すぐに提案から任せていただける環境だとうかがい、志望しました」

━━━━━━━━━━━━━━━━━━
投稿02｜志望動機
━━━━━━━━━━━━━━━━━━
志望動機、調べた内容をそのまま話すと逆効果です。

面接官
「なぜ当社を志望されたのですか」

お見送りの人1
「成長している業界だからです」
→ 業界の話。会社の話になっていない。

お見送りの人2
「理念に共感しました」
→ 誰でも言える。調べた証拠にならない。

お見送りの人3
「風通しの良さに惹かれました」
→ 社風は入社前に分からないはず。

お見送りの人4
「福利厚生が充実しているので」
→ 条件が目的だと受け取られる。

内定とる人
「前職で紙とExcelでの管理に限界を感じていました。御社のサービスを実際に使ってみたところ、まさにその工程が消える設計になっていて、自分が困っていた側だからこそ伝えられると感じています。導入後の運用まで一緒に考える姿勢にも共感し、志望しました」

━━━━━━━━━━━━━━━━━━
投稿03｜自己PR
━━━━━━━━━━━━━━━━━━
自己PR、頑張ったことを話す場ではないです。

面接官
「ご自身の強みを教えてください」

お見送りの人1
「コミュニケーション能力です」
→ 定義が人によって違う。判断できない。

お見送りの人2
「責任感があります」
→ 全員が言う。差がつかない。

お見送りの人3
「粘り強さです」
→ 根拠の場面がないと伝わらない。

お見送りの人4
「何でも一生懸命やります」
→ 何ができるかが出てこない。

内定とる人
「初めて会う相手から情報を引き出すのが得意です。前職では問い合わせ対応を担当し、要望をそのまま受けるのではなく、背景を確認してから提案する形に変えました。結果として差し戻しが減り、対応件数も増やせています。御社でも顧客の課題を整理する場面で活かせると考えています」

━━━━━━━━━━━━━━━━━━
投稿04｜なぜうちなのか
━━━━━━━━━━━━━━━━━━
この質問、答えられない人が本当に多いです。

面接官
「同業他社ではなく、なぜ当社なのですか」

お見送りの人1
「業界最大手だからです」
→ 規模の話。他社でも言える。

お見送りの人2
「一番早く選考が進んだので」
→ 正直すぎる。志望度が低く見える。

お見送りの人3
「説明会の雰囲気が良かったので」
→ 印象だけ。中身の話がない。

お見送りの人4
「特に理由はないのですが興味があって」
→ 準備していないと判断される。

内定とる人
「他社も同じ領域を扱っていますが、御社は導入後の支援まで自社で持っている点が違うと感じました。前職で導入後に放置された経験があり、そこを自分で埋める仕事がしたいと思っています。売って終わりにしない体制があるからこそ、御社を志望しました」

━━━━━━━━━━━━━━━━━━
投稿05｜強みと弱み
━━━━━━━━━━━━━━━━━━
弱みの答え方で、評価が地味に動きます。

面接官
「ご自身の弱みを教えてください」

お見送りの人1
「特にありません」
→ 自己認識がないと見られる。

お見送りの人2
「心配性なところです（以上）」
→ 対策が出てこないと欠点のまま。

お見送りの人3
「完璧主義なので抱え込みます」
→ 強みの言い換えに聞こえる。

お見送りの人4
「飽きっぽいところです」
→ 早期離職を連想させる。

内定とる人
「一人で抱えてしまうところです。前職で納期直前に相談して迷惑をかけた経験があり、それ以来、着手前に想定工数を共有し、遅れそうなら半分の時点で相談するようにしています。今も意識して続けている部分です」

━━━━━━━━━━━━━━━━━━
投稿06｜キャリアプラン
━━━━━━━━━━━━━━━━━━
5年後を聞かれて固まる人、かなり多いです。

面接官
「5年後はどうなっていたいですか」

お見送りの人1
「まだ考えていません」
→ 続ける気があるか不安になる。

お見送りの人2
「管理職になりたいです（以上）」
→ そこまでの道筋が出てこない。

お見送りの人3
「独立を考えています」
→ 期間限定の在籍と受け取られる。

お見送りの人4
「御社で頑張りたいです」
→ 中身がなく、答えになっていない。

内定とる人
「まずは1年で担当を一人で回せる状態になりたいです。3年目までに後輩に教えられる範囲を作り、5年後は提案の設計から関われるようになっていたいと考えています。現時点で管理職を目指すかは決めていませんが、任せてもらえる範囲を広げていきたいです」

━━━━━━━━━━━━━━━━━━
投稿07｜退職の切り出し方
━━━━━━━━━━━━━━━━━━
退職を伝えるとき、言い方で揉めるかどうかが決まります。

上司
「話ってなに？」

揉める人1
「今の職場が合わないので辞めます」
→ 否定から入ると引き止めが感情的になる。

揉める人2
「まだ決めてないんですが転職を考えてて」
→ 相談に見える。引き止めの余地を残す。

揉める人3
「次はもっと良い条件のところなので」
→ 比較されたと受け取られる。

揉める人4
（メールやチャットで一方的に）
→ 手続き以前に信頼を失う。

円満に進む人
「お時間よろしいでしょうか。私事で恐縮ですが、〇月末で退職させていただきたく、ご相談に参りました。すでに意思は固まっております。引き継ぎは〇月中に一通り終えられるよう計画を作りました。ご迷惑を最小限にしたいので、進め方をご相談させてください」

━━━━━━━━━━━━━━━━━━
投稿08｜逆質問
━━━━━━━━━━━━━━━━━━
最後の逆質問、ここで印象が変わります。

面接官
「何か質問はありますか」

お見送りの人1
「特にありません」
→ 興味がないと受け取られる。

お見送りの人2
「御社の事業内容を教えてください」
→ 調べていないことが伝わる。

お見送りの人3
「残業はどれくらいですか（それだけ）」
→ 条件しか見ていないと思われる。

お見送りの人4
「御社の強みはなんですか」
→ 答えにくく、会話が広がらない。

評価が上がる人
「入社後すぐに担当するのは、どのあたりの業務になりそうでしょうか。あわせて、3ヶ月目までに期待される状態があれば教えてください。前職で立ち上がりに時間をかけてしまった反省があり、入社前に準備しておきたいと考えています」

━━━━━━━━━━━━━━━━━━
投稿09｜内定辞退の伝え方
━━━━━━━━━━━━━━━━━━
辞退の連絡、雑にすると後々効いてきます。

企業
「ご検討いかがでしょうか」

印象が悪い人1
（連絡せずフェードアウト）
→ 同じ業界なら、どこかで必ず繋がる。

印象が悪い人2
「他社のほうが条件が良かったので」
→ 比較の結果だけを伝えると角が立つ。

印象が悪い人3
「家族に反対されまして」
→ 本当でも、自分で決めていない印象に。

印象が悪い人4
（メールのみで即日辞退）
→ 選考に関わった人数を考えると不足。

丁寧な人
「このたびは内定をいただき、ありがとうございました。大変迷いましたが、選考を通じて自分が優先したい条件がはっきりし、別の企業でお世話になることにいたしました。お時間をいただいたにもかかわらず申し訳ありません。改めて御礼申し上げます」

━━━━━━━━━━━━━━━━━━
投稿10｜前職の不満の伝え方
━━━━━━━━━━━━━━━━━━
不満を聞かれたとき、正直に言うだけだと損します。

面接官
「現職で課題に感じていることは」

お見送りの人1
「上司がコードも書けない人で」
→ 人の批判はそのまま自分に返る。

お見送りの人2
「給料が低すぎます」
→ 条件だけが目的に聞こえる。

お見送りの人3
「体制がぐちゃぐちゃで無理でした」
→ 改善しようとしたかが出てこない。

お見送りの人4
「特に不満はありません」
→ 転職理由と矛盾する。

内定とる人
「引き継ぎの資料が個人のメモに依存していて、担当が変わるたびに時間がかかっていました。自分の範囲では手順書を作って共有しましたが、全体の運用までは変えられませんでした。仕組みから整えられる環境で働きたいと考えたのが、転職を考えたきっかけです」
