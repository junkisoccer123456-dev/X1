# 使用した構文：対象名指し→命令形の羅列型（バリエーションF／参考投稿❺）

「【年齢・属性】へ」の1行 → ・の命令形を12〜15行 → 最後の1行に `←new`
矢印も解説も締めもなし。理由は1行も書かない。全体200〜260字。

※既存の `yajirushi-ichigyou.md` バリエーションC（解説なし・サイン列挙型）をさらに削った形。
　差分（矢印も締めもない／命令形で統一／最後に `←new`）をバリエーションF として追記して使用した。

※CLAUDE.md 6.5 に従い、この構文の過去70テーマを全件除外。
　過去は「〜のサイン」「〜を見分ける」が中心だったため、今回は**対象を名指しする形**に全部ずらし、
　読者の状況（年次・立場・時期）で10通りに分けた。

## 文体について
参考投稿は命令形で統一されていて、です・ます調も一人称も出てきません。
この型は**命令形で揃えることが核**なので、カルテ6の「です・ます調」「一人称はぼく」は
この構文では出していません（CLAUDE.md 2「構造を盗む」の範囲での判断）。
ただし参考投稿にあった身体への強い煽り（「死ぬ気でやれ」など）は使っていません。

## 絵文字について
参考投稿に絵文字がないため、絵文字なしで出力している（CLAUDE.md 7）。
