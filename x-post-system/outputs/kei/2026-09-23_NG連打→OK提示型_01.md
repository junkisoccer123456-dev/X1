# 使用した構文：Q&A一問一答型（バリエーションC／参考投稿②）

方法論のラベル → Q.質問 → NG（一行） → OK（そのまま使える長めのセリフ）

# 選定した10テーマ

1. 転職理由
2. 志望動機
3. 自己紹介
4. 強み
5. 弱み
6. 希望年収
7. なぜ弊社か
8. 失敗した経験
9. 残業への考え方
10. 転職回数

━━━━━━━━━━━━━━━━━━
投稿01｜転職理由
━━━━━━━━━━━━━━━━━━
転職理由は「不満」ではなく「できないこと」で話すと通ります↓

Q.転職を考えた理由を教えてください。

NG：上司と合わず、評価もされなかったからです

OK：「現職では既存顧客の対応を中心に担当してきました。継続率を上げる工夫を重ねる中で、提案の設計から関わりたい気持ちが強くなっています。ただ現職では担当範囲が決まっており、その機会が限られるため、転職を考えました」

━━━━━━━━━━━━━━━━━━
投稿02｜志望動機
━━━━━━━━━━━━━━━━━━
志望動機は「前職の課題」と接続すると一気に通ります↓

Q.なぜ当社を志望されたのですか。

NG：成長している業界で、御社の理念にも共感したからです

OK：「前職で紙とExcelでの管理に限界を感じていました。御社のサービスを実際に使ってみたところ、まさにその工程が消える設計になっていて、自分が困っていた側だからこそ伝えられると考えています」

━━━━━━━━━━━━━━━━━━
投稿03｜自己紹介
━━━━━━━━━━━━━━━━━━
自己紹介は経歴の朗読ではなく、1分の設計です↓

Q.簡単に自己紹介をお願いします。

NG：〇〇大学を卒業し、新卒で〇〇に入社しまして、その後は…（3分）

OK：「〇〇業界で法人営業を3年、直近は既存顧客の拡大を担当しています。担当は〇社で、うち〇社は自分で立ち上げました。本日は、その経験が御社のどこで活きるかをお話しできればと思っています」

━━━━━━━━━━━━━━━━━━
投稿04｜強み
━━━━━━━━━━━━━━━━━━
強みは、形容詞ではなく場面で語ると伝わります↓

Q.ご自身の強みを教えてください。

NG：コミュニケーション能力と責任感です

OK：「初対面の相手から情報を引き出すのが得意です。前職では問い合わせ対応を担当し、要望をそのまま受けるのではなく背景を確認してから提案する形に変えました。結果として差し戻しが減り、対応件数も増やせています」

━━━━━━━━━━━━━━━━━━
投稿05｜弱み
━━━━━━━━━━━━━━━━━━
弱みは「事実＋いま続けている対策」で答えると評価が上がります↓

Q.ご自身の弱みを教えてください。

NG：完璧主義なところです（以上）

OK：「一人で抱えてしまうところです。前職で納期直前に相談して迷惑をかけた経験があり、それ以来、着手前に想定工数を共有し、遅れそうなら半分の時点で相談するようにしています。今も意識して続けている部分です」

━━━━━━━━━━━━━━━━━━
投稿06｜希望年収
━━━━━━━━━━━━━━━━━━
大手メーカーで人事部長してますが、
希望年収は遠慮すると本当に損します↓

Q.希望年収はいくらですか。

NG：御社の規定に従います

OK：「現在〇〇万円をいただいております。前職では〇〇まで任されていたため、同等の範囲であれば〇〇万円を目安に考えています。ただ役割によって適正は変わると認識していますので、期待値とあわせてご相談できればと思います」

━━━━━━━━━━━━━━━━━━
投稿07｜なぜ弊社か
━━━━━━━━━━━━━━━━━━
「なぜうちか」は、他社では言えない理由にするのが答えです↓

Q.同業他社ではなく、なぜ当社なのですか。

NG：業界最大手で、安定していると思ったからです

OK：「他社も同じ領域を扱っていますが、御社は導入後の支援まで自社で持っている点が違うと感じました。前職で導入後に放置された経験があり、そこを自分で埋める仕事がしたいと考えています」

━━━━━━━━━━━━━━━━━━
投稿08｜失敗した経験
━━━━━━━━━━━━━━━━━━
失敗談は「事実→打ち手→今の運用」まで話すと強みになります↓

Q.これまでの失敗経験を教えてください。

NG：案件が炎上して、精神的にきつかったです

OK：「受注が3ヶ月ゼロだったことがあります。失注理由を並べたところ、決裁者に会えていないことが原因でした。以来、初回の商談で決裁フローを確認するようにしており、今もその形で進めています」

━━━━━━━━━━━━━━━━━━
投稿09｜残業への考え方
━━━━━━━━━━━━━━━━━━
残業の質問は、姿勢と効率の両方を見られています↓

Q.残業についてどうお考えですか。

NG：できるだけ残業は避けたいです

OK：「必要な場面では対応します。ただ前職では、属人化していた資料作成を型にして、月の作業時間を減らした経験があります。時間をかけること自体が目的にならないよう意識しています」

━━━━━━━━━━━━━━━━━━
投稿10｜転職回数
━━━━━━━━━━━━━━━━━━
転職回数は、回数ではなく一貫性で見られています↓

Q.転職回数が多いようですが、理由を教えてください。

NG：どこも合わなくて、たまたま続かなかっただけです

OK：「3社とも顧客は同じ業界です。担当範囲を広げるために動いてきました。2社目は事業撤退により担当が変わったことが理由です。今回は評価者とレビュー体制を必ず確認しており、腰を据えたいと考えています」
