# 記事誘導リプの共通設計（前回の改善を反映）
1. 社名や答えは短く出す（会社説明は書かない）
2. 記事でしか解決しない「次の疑問」を1つ残す（受かる方法／ルート／面接官の本音）
3. 読む理由を具体名詞で2〜3個示す（職種・面接・自己応募）
4. CTAは「↓ 記事URL」の1つだけ
5. 記事の本文に出てくる内容（IS/CS、グロース期、The Model、自己応募の弱点）とだけ接続する

# 注意（公開前に必ず確認）
- 数字は一切使っていません。平均年収・残業時間などの統計は出典確認ができないため
  （account/haru.md 禁止事項）。数字を入れたい場合は、各社の有価証券報告書の実数をいただければ差し込みます。
- 社名を出す投稿は、募集状況・職種が変わるため断定していません。投稿前に各社の採用ページを確認してください。
- 「ホワイト」は主観なので、「働きやすさで名前が挙がる」「ホワイトが多い構造」の言い方にしています。
- リプの【記事URL】は実URLに差し替えてください。記事はPR表記（冒頭推奨）を忘れずに。
