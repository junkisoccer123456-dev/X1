# data/（成績管理・将来拡張用）

今はまだ「空の器」です。投稿生成には使いません。
将来、投稿の成績を記録してこう使う想定です。

- 投稿ごとのインプレッション／いいね／保存／リポスト／プロフィール遷移数の記録
- 構文別・テーマ別の平均成績
- アカウント別の勝ちパターン抽出
- 伸びた構文のランキング
- Googleスプレッドシート連携、X API連携、投稿ストック管理

## ファイル

| ファイル | 役割 |
|---|---|
| `metrics.csv` | 投稿1本＝1行の成績記録（列だけ用意済み） |
| `SCHEMA.md` | 列の意味と入力ルール |
