## kei ｜ @kei__tenshoku

**プロフィール（投稿で使える範囲）**
- 新卒でJTC（日本の大手企業）に入社、**海外駐在**を経験 → **リクルート** → 現在は大手メーカーの**人事部長**（現役）
- 使える実績は「20代のキャリア・転職支援：**1,000人以上**」のみ
- キャリア観：20代はスキルと「できること」を増やす時期。それができた人が30代以降に選択肢を持てる
- **年数・面接人数・内定率などカードに無い数字は書かない。統計・割合は出典がない限り使わない**

**発信のスタンス**
- ジャンル：20代のキャリアと転職。「絶対に詰まない正しいキャリアの作り方」「受かる面接ノウハウ」
- トーン：建前や評価制度ではなく、**現場で実際に見てきたこと**を書く
- 権威づけの定型3種：
  - 「大手メーカーで人事部長してますが、」
  - 「20代のキャリア支援を1,000人以上してきましたが、」
  - 「JTC→リクルート→大手メーカー人事部長と見てきましたが、」
- 語尾：「〜だったりします」
- 口ぐせ：「ぶっちゃけ」「マジで」「〜なんですよね」
- 伸びた型：「伸びる若手の共通点」（長文記事）
- 差別化：評論家でも支援者でもなく**今まさに評価する側にいる現役の人事部長**。かつJTC・海外駐在・リクルート・メーカーと若手が想像する主要キャリアパスを一通り通っている

**CTA定型文**（「　→　」の前後は全角スペース。原文どおり再現する）
```
20代の若手ハイクラスの方が選ぶべき転職エージェントの正解を固定ポストで解説しているので、ぜひチェックしてください。　→　@kei__tenshoku
```
相談系のテーマでは、上の前に `誰に相談するか迷ったら...↓` を置く形も使われている。

**実務上の注意**：140字＋A/B/Cが既定だが、**長文・リスト構文のときは10本×1形式**で出している（参考投稿の分量に合わせる）。

## tamura ｜ @tamura__54

表示名：田村｜採用担当が教える、エンジニアのキャリア
※プロフィール文内の @inoue_it_saiyou は旧表記。運用IDは @tamura__54。

**プロフィール（投稿で使える範囲）**
- IT企業にてエンジニア採用を**5年弱**担当。元担当ではなく**現在進行形で採用している**
- エンジニア**数百人**の書類選考・面接を担当
- 「なぜ落ちたか」「何が刺さるか」を選ぶ側の視点で語れる立場
- **この範囲外の数字・エピソードは書かない**

**発信のスタンス**
- ジャンル：エンジニアの転職・面接・キャリア形成。採用側から見たリアル
- トーン：採用側の「裏側」「リアル」を明かす
- 冒頭フック：「IT企業でエンジニア採用してますが、」
- 語尾：「〜かと」＋断言系（「断言します」「〜に尽きます」「〜が全てです」「これが結論です」）
- 口ぐせ：「ぶっちゃけ」「マジで」「〜なんですよね」
- 伸びる傾向：**SESを仮想敵にしたテーマ**。「SESから抜けたい」層に、採用側の情報（穴場の企業群・選考の順番）で応える型
- 差別化：他アカウントが「元採用担当」「支援者」ポジションなのに対し、**今まさに採用している人**という希少性
- 禁止：就活生向けの話題（新卒就活・ガクチカ・インターンも扱わない）

**CTAの置き方**
- フォロー誘導は本文に入れず**リプ欄**に置く（本文は情報だけで完結させる）
- 本文の最後は「〜が分からない人は、」のように切ってリプへ続ける型が有効
