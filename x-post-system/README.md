# X投稿生成システム（使い方ガイド）

プログラミングの知識は不要です。Claude Codeに話しかけるだけで使えます。

---

## 1. 最初に1回だけやること：アカウント情報を埋める

`accounts/` の中に4つのファイルがあります（kouta / tamura / imai / haru）。
中身はまだ `（未記入）` の空テンプレートです。

**おすすめの方法（自分で書かなくてOK）**

```
/x-account kouta
```

と打つと、Claudeが1問ずつ質問してくれます。答えるだけでファイルが埋まります。

**自分で書きたい場合**
`accounts/kouta.md` をメモ帳などで開き、`（未記入）` を書き換えてください。

> 最低限これだけは必要です：発信ジャンル／ターゲット／発信者プロフィール／文体

---

## 2. 毎回やること：投稿を作る

```
/x-post kouta
```

と打ち、続けて **参考にしたいX投稿の本文をそのまま貼り付け** ます。

（1行で書いてもOKです）

```
/x-post kouta
ここに伸びている参考投稿を貼り付ける
（改行そのままでOK）
```

これだけで、Claudeが自動で

1. 参考投稿の構文を分析
2. 構文を `structures/` に保存（似た構文があれば使い回す）
3. `accounts/kouta.md` を読み込む
4. 内部でテーマ候補を30個出す
5. 相性の良い10テーマに絞る
6. 投稿を10本作る
7. `outputs/kouta/` に保存

まで一気にやります。

---

## 3. 作り直したいとき

そのまま日本語で伝えてください。

- 「投稿3をもっと具体的にして」
- 「テーマ7を別の切り口に変えて」
- 「全体的にもう少し短くして」

---

## 4. 構文だけ貯めておきたいとき

```
/x-structure
ここに参考投稿を貼り付け
```

投稿は作らず、構文の分析と保存だけを行います。
良い投稿を見つけたら、このコマンドでストックしておくと後で使い回せます。

---

## フォルダの意味

| フォルダ | 中身 |
|---|---|
| `CLAUDE.md` | Claudeへの指示書（システムの頭脳。基本さわらなくてOK） |
| `accounts/` | アカウントのカルテ（あなたが埋める） |
| `references/` | 参考投稿の原文の保管庫（自動保存） |
| `structures/` | 分析した構文のライブラリ（自動保存） |
| `outputs/` | 完成した投稿（アカウント別・自動保存） |
| `data/` | 成績管理用。今は空（将来のインプレッション記録用） |

## よくある質問

**Q. `/x-post` と打っても反応しない**
A. Claude Codeで `/` を打つとコマンド一覧が出ます。そこに `x-post` があるか確認してください。
無い場合は、このリポジトリのフォルダ（`X1` または `x-post-system`）を開いているか確認してください。

**Q. 投稿は自動でXに投稿される？**
A. されません。ファイルに保存されるだけです。投稿はご自身でコピーして行ってください。

**Q. 投稿したあとの数字は記録できる？**
A. 今は未対応です。`data/metrics.csv` に記録する枠だけ用意してあります（将来対応予定）。
