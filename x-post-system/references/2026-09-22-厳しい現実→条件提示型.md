# 参考投稿（原文）

```
30代未経験からエンジニアは不可能ではないですが「地頭は新卒トップ層・体力は20代・現場で一切ふてくされない素直さ」を全部積んだ三刀流みたいな人ならいけます。さらに若手優先の枠も多い。

中途・未経験で通るのは ①前職で何か結果を出してる ②学習速度が即戦力級 ③年齢を言い訳にしない これが揃わないと厳しいです。
```

## 気づいたこと（メモ）
- 「不可能ではないですが」と一度肯定してから、条件で現実を突きつける
- 条件の列挙が誇張気味（三刀流）で、否定でありながら笑いとして読める
- 短い。2段落だけ。長文と混ぜると投稿のリズムが変わる
- 最後に通過条件を①②③で提示し、ただの否定で終わらせていない
- 厳しいことを言い切れるのは「現役で選ぶ側」だから。立場と内容が一致している
