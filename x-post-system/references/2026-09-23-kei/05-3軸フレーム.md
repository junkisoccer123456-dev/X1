# 原文
```
面接で99%聞かれるキャリアプランは、3つの軸で回答すると面接官も納得する

【例】
短期（〜3年後）：営業で成果を出す
中期（〜5年後）：マーケティング部署に移る
長期（〜10年後）：マーケティングで成果を出す、マネジメントを行う
```
# 分析メモ
- **型（フレーム）＋記入例**だけの最小構成。解説がない
- 3行で終わるので、読者が「自分の場合」を埋めたくなる
- 「99%聞かれる」で、準備しない理由をなくしている
- 短いのに保存されやすい。テンプレとして機能する型
