# 原文
```
1000名以上転職支援してきて気づきましたが
面接官には2種類のパターンが存在します

① 過去深堀型面接官
② 仕事深堀型面接官

①は、過去からの意思決定軸にブレがないようなストーリーを話すと100%刺さる
②は、挫折した経験から成功体験の話に持って行くと刺さる。
```
# 分析メモ
- 相手を**2タイプに分類**し、**タイプ別の攻略法**を渡す型
- 「2種類のパターンが存在します」で、読者は自分が当たるタイプを知りたくなる
- 分類のあと、①②それぞれに1行の処方を出す。短いのに実用性が高い
- 権威づけが数字（1,000名以上）なので、分類の信頼性が担保される
