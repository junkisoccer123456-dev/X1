# 原文
```
大手メーカーで人事部長してますが
仕事についての質問はこれ以外に聞かれないです

■業務について
○現職での仕事内容を簡単に説明してください
○現職の業務で大変な業務はどんなところか？
○現職の業務の責任範囲（果たす役割）や目標は？
（…20問以上。一部は子項目つき）
```
# 分析メモ
- 既存「網羅リスト型」の派生。↓ ではなく **■カテゴリ見出し＋○項目** で並べる
- 「これ以外に聞かれない」という**言い切り**が価値になる（網羅性の保証）
- 質問が生々しい（実際に使っている表現のまま）ので、現役であることが伝わる
- 子項目（- で始まる追加質問）を一部だけ入れると、単調さが消える
