# 原文
```
面接官が一瞬で「礼儀がある」と判断する言葉遣いランキングはこれ↓

20位：「よろしくお願いいたします」
19位：「失礼いたします」
（…中略）
2位：「お先に失礼いたします」
1位：相手の発言を受けてから話し始められる丁寧な言い回し
（例：「ご説明ありがとうございます。その点についてですが…」）
```
# 分析メモ
- 既存ランキング構文の派生。**20位〜1位を1投稿で一気に出す**（リプに分けない）
- 各項目が短い（セリフ1行）ので、20項目でも読み切れる
- 1位だけ毛色を変える（単語ではなく「型」＋例文）と、着地の重みが出る
- 「一瞬で判断する」という時間表現が、読む価値を上げている
