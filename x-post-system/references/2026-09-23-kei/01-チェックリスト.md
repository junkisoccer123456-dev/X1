# 原文
```
大手メーカーで人事部長してますが、
内定が取れる人の傾向はこれですね↓

□ 丸暗記&棒読みせずに、頭の中で考えながら話すことができている
□ ヌケモレなく網羅的に準備できている
□ "抽象的なパート⇆具体的なパート"を意識し、解像度を高めたり抽象度を高めたりが自在にできている
□ 転職動機を説明する際、現職で"できること・難しいこと"を切り分け、他責感なく説明できている
□ 話が複数ある場合は、先に「○点あります」と話してから端的に話せている
□ 伝える要素が多いときは順番を意識し、結論を先に伝えてから話せている
□ 主観的にならず、他人を説明するような"第三者視点"で説明できている
```
# 分析メモ
- 既存リスト構文の派生。差分は **□（チェックボックス）** を使うこと
- チェックボックスにすると、読者が自己採点を始める。保存率が上がる
- 1項目が長め（20〜50字）。できている／できていないが判定できる粒度で書く
- 冒頭は権威フック＋「これですね↓」の短い導入のみ
