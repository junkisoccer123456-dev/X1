# 参考投稿①②｜カード型 NG/OK 業界リスト（2件は同じ骨格）

## 原文（ポスト①：20代カード）

```
「転職はいつでもできる」けど
20代カードもかなり貴重だと思う。

❌ あまり使わないほうがいい業界
・SES、小売、飲食、訪問販売
・非大手コンサル、代理店、地方零細企業

逆に20代カードを使うべきなのは↓
```

リプ：
```
⭕️ 20代カードを使うべき業界

・SaaS
・大手製薬
・大手食品
・大手通信
・総合商社
・不動産デベ
・半導体メーカー
・ホワイト大手子会社


特にSaaSがおススメかなと。
```

## 原文（ポスト②：未経験カード）

```
未経験歓迎の求人はいつでもあります。
ただ、あなたが未経験として扱ってもらえる期間には終わりがあるという事実。

この1枚を切るには惜しい業界は、

・SES、小売、飲食、訪問販売
・代理店、地方零細企業、非大手コンサル

逆に未経験カードを使うべきなのは↓
```

リプ：
```
未経験カードを使うべき業界

・SaaS
・大手通信
・大手製薬
・大手食品
・総合商社
・不動産デベ
・半導体メーカー
・ホワイト大手子会社
```

# 分析メモ

## 1. 冒頭フック
- ①は「転職はいつでもできる」という**世間の言い分を一度カギ括弧で肯定**してから「けど」で返す。
  真っ向から否定しないので、反発が出ない。
- ②は「未経験歓迎の求人はいつでもあります」と事実を置いてから、
  「ただ、扱ってもらえる期間には終わりがあるという事実」で時間制限を突きつける。
- どちらも構造は同じで、**機会は無限にある → ただし資格のほうに期限がある**という切り返し。

## 2. 核になっている発明
- 転職の条件を「カード」という言葉に置き換えている。
  カードは手札であり、切れば無くなる。この1語だけで希少性と消費の概念が同時に伝わる。
- ②の「この1枚を切るには惜しい」という表現がとくに強い。
  もったいない、という感情を、説教ではなく惜しさとして出している。

## 3. 情報の並べ方
- NG群は2行に圧縮して読み飛ばせる形にしている（列挙が目的で、1つずつ吟味させない）。
- OK群はリプに置き、1行1項目で縦に並べる。こちらは**じっくり読ませる**。
- 同じリストでも、NGは横に詰め、OKは縦に開く。ここが意図的。

## 4. 引きの作り方
- 「逆に〇〇カードを使うべきなのは↓」で本文を終える。
  NGだけ見せられた読者は、答えを知らないと落ち着かない状態になる。
- リプは1本で完結。長い解説を付けない。

## 5. オチ
- ①はリストの後に「特にSaaSがおススメかなと」の一言。断定を避けた語尾で、主観だと分かる。
- ②は一言なしでリストのみ。締めがなくても成立している。

## 6. 文体・見た目
- 本文は約100〜130字、リプは約80〜100字。全体で短い。
- ①は ❌ ⭕️ の絵文字で群を分けている。②は記号なし。
- 断定を「思う」「かなと」で少し外している。強い主張なのに角が立たない。

## ⚠️ haru で使うときの注意
haru のカルテは**絵文字なし**がルール（13. 出力ルール）。
①の ❌ ⭕️ はそのまま使えないため、【使わないほうがいい】【使うべき】のように
括弧の見出しに置き換えて運用する。
