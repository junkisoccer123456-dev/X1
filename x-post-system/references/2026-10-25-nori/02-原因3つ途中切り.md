```
書類は通るのに、面接で落ち続ける人。
原因は、だいたい3つのどれかです。

1. 職務経歴書に書いたことと、話す内容がずれている
2. 退職理由が、前の会社の話で終わっている
3. 志望動機が、

リプ

書類で｢会ってみたい｣と思わせたのに、会ったら別の人に見える。
面接官は、ここで一番がっかりします。

面接の前に、自分の職務経歴書を声に出して読んでみてください。
書いてあることと、話そうとしていることが同じか。それだけで変わります。
```

# 分析メモ（CLAUDE.md 2 の全観点）
- **冒頭フック**：**矛盾の提示**。「Aは通るのに、Bで落ち続ける」。
  読者の頭の中の「なぜだろう」をそのまま文字にしているので、自分の話として読み始める。
- **権威性**：一切出さない。実績も数字も立場も書かない。短さで押している。
- **問題提起**：「原因は、だいたい3つのどれかです」。
  **範囲を有限にする**ので読める。「どれか」なので責められている感じがしない。
- **興味維持の仕掛け**：核心は**3つ目を語の途中で切る**こと。「3. 志望動機が、」で終わる。
  文として未完成なので目が止まる。「続きは↓」のような誘導文を1文字も使っていない。
- **文章展開**：フック → 範囲の確定 → 原因3つ（3つ目が切れる）→ リプで回収 → 原則 → 行動。
- **情報の順番**：ズレ（1）→ 視点が外のまま（2）→ 汎用的すぎる（3）。
  **一番言いたいことを3つ目に置く**。切るのが3つ目なので、そこが本題になる設計。
- **具体例**：職務経歴書・退職理由・志望動機という**工程の名前**で具体性を出している。
  シーン描写や数字はない。
- **比較方法**：書類での印象 vs 会った印象、という**同一人物の前後比較**。
- **感情の動かし方**：心当たり → 不安（自分も別人に見えているかも）→ 納得 → 安心（今日できる）。
- **オチ**：「それだけで変わります」。断定で短く終える。
- **CTA**：なし。フォロー誘導も固定ポストへの導線もない。
- **改行**：フック2行＋空行＋原因3行（間に空行なし）。リプは1行目を単独で置いてから空行。
- **文章量**：本文約95字／リプ約150字。かなり短い。
- **文体**：です・ます調。断定を混ぜる。1文が短い。
- **絵文字**：なし。
