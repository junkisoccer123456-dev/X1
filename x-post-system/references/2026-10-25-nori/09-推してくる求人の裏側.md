# 原文（要点のみ・全文は長文のため構造を残す形で記録）
```
【エージェントが「推してくる求人」の裏側】

10月から本格的に動き出す方も増えてきたので、これだけは先に知っておいてほしくて書きます。
元キャリアアドバイザーとして、辞めた今だからこそ言える話です。
結論から言うと、エージェントが熱心に推してくる求人＝あなたに一番合う求人、とは限りません。
むしろ会社側の都合で推されているケースが、現場には普通にあります。

① 「決まりやすいから」推される
　受かりやすい求人は、エージェントにとって一番おいしい。
　書類が通りやすい。／面接のハードルが低い。／内定が出やすい。
　求職者の希望より「決まる確率」で並べ替えられることがある、というのが実態です。

② 「報酬が高いから」推される
　紹介を成立させると、年収の何割かが成功報酬として入る。
　だから年収提示が高い求人ほど、自然と推したくなる。
　単価で優先順位が変わる瞬間がある。
　これは仕組みの話なので、担当者個人を責めても仕方ないんですよね。

③ 「早く埋めたいから」推される
　企業から急ぎと言われている求人は、エージェント側も急いで動く。
　合っているのは、あなたとではなく、企業の採用スケジュールとだったりする。

④ 「ノルマがあるから」推される
　月内に何件、四半期で何件。数字を持って働いている担当者は少なくない。
　締め日が近いと、提案のトーンが一段強くなる。
　これも構造の問題で、辞めた今だから外から言えること

ーーー
ここからが本題で、じゃあどう見抜くか。
推された時に、この一言を投げてみてください。
「なぜ、私にこの求人を勧めてくださるんですか？」
良い担当者は、あなたの経歴や希望に紐づけて、理由を具体的に語れます。
「あなたの◯◯の経験が、この会社の△△と噛み合うからです」と。

逆に危ないのは、
人気なので早く動いた方がいいです。／今が一番タイミングいいです。／他にもいい人が応募してます。
理由が「あなた」ではなく「求人側の事情」に寄っている時。
ここで違和感を持てるかどうかが、後悔するかしないかの分かれ目です。

ーーー

念のため言うと、推してくる求人が全部ダメ、という話ではありません。
本当にあなたに合うから自信を持って勧めている、誠実な担当者ももちろんいます。
大事なのは、推される理由を一度立ち止まって確かめること。それに尽きます。
転職で後悔する人の多くは、悪い求人を掴まされたわけじゃない。
「強く勧められたから、たぶん合ってるんだろう」と、自分で確かめる工程を飛ばしてしまっただけなんですよね。
決めるのはエージェントじゃなく、毎日その会社に通うあなた自身。
推されたら、まず理由を聞く。それだけで、見える景色が変わります。
「いい求人ですよ」より、「あなたにとっていい求人かどうか」を、自分の言葉で確かめてほしい。
```

# 分析メモ（CLAUDE.md 2 の全観点）
- **冒頭フック**：【カッコ付き見出し】＋「〇〇の裏側」。
  内側の話だと分かる見出しなので、それだけで止まる。
- **権威性**：「元キャリアアドバイザーとして、辞めた今だからこそ言える話です」。
  **立場を降りたから話せる**構図。これが情報の価値を一段上げている。
  さらに「書いた理由」を先に説明している（この時期に動く人が増えてきたので）。
  売るためではなく伝えるために書いている、という前提がここで成立する。
- **問題提起**：結論先出し。「熱心に推される＝あなたに合う、とは限りません」。
  長文でも読者は結論を持ったまま読めるので、読み進める負荷が低い。
- **興味維持の仕掛け**：①〜④が全部「なぜそうなるのか」の**仕組みの説明**。
  人ではなく構造を責めるので、読者は安心して受け取れる。
  中盤の `ーーー` ＋「ここからが本題で」で**折り返し点を宣言する**のが核。
  長文のどこまで来たかが見えるので、ここで離脱が止まる。
- **文章展開**：見出し → 書いた理由＋立場 → 結論 → 仕組み4つ → 本題（見抜く質問）→ 留保 → 締め。
- **情報の順番**：仕組みが**自分に近い順**に並ぶ。
  決まりやすい（選考）→ 報酬（金）→ 採用スケジュール（相手の都合）→ ノルマ（担当者の事情）。
- **具体例**：各ブロックの最後に短い言い切りを置く（「単価で優先順位が変わる瞬間がある」）。
  説明 → 言い切り、の繰り返しがリズムを作る。
  本題は**そのまま使える質問文1つ**（カギ括弧）。持ち帰れるものが1個ある。
- **比較方法**：良い担当者の答え方 vs 危ない答え方の対比。
  危ない側は**短い言葉を3〜4行並べる**。聞いたことのある言葉として刺さる。
- **感情の動かし方**：不信（そうだったのか）→ 納得（構造なら仕方ない）→ 警戒 → 自衛できる安心。
- **オチ**：「後悔する人の多くは、悪い求人を掴まされたわけじゃない。確かめる工程を飛ばしただけ」。
  原因を**読者の手が届く位置に置き直す**ので行動に変わる。
- **CTA**：なし。長文の最後も主張で終える。
- **改行**：仕組みの説明部分は**1文1行で短く折る**。折り返しは `ーーー` のみの行。
- **文章量**：約1,900字。
- **文体**：です・ますと言い切りを交互に置く。「〜なんですよね」が2回。一人称は「私」。
- **絵文字**：なし。
