# 分析メモ（CLAUDE.md 2 の全観点）
- **冒頭フック**：「【情報源】から分かる／【テーマ】⓬選は、、」。
  読点2つ（、、）で言いかけたまま終えるのが引きになっている。
  件数が**⓬（囲み数字の12）**で示されるので、情報量が一目で伝わる。
- **権威性**：出さない。情報源（求人票）が権威の代わりになっている。
- **問題提起**：各項目の「→」が全部**裏を暴く**形になっている（表記マジック、平均値のごまかし）。
- **興味維持の仕掛け**：④だけ**項目名は出して解説を `→◯◯◯` で伏せる**。
  項目名が具体的なぶん「何が書いてあるんだ」という引きが強くなる。
  さらに引きの言葉を毎回変える（続く↓↓↓ → まだまだ続く↓↓ → ↓↓↓ → 最後に↓↓）。
- **文章展開**：本文で3項目＋4項目目を伏せる → リプ4本で3項目ずつ → リプ4で原則に上げる。
- **情報の順番**：休日 → 残業 → 勤務時間（時間の話）→ 採用人数 → 給与関連 → 制度 → 試用期間。
  **読者が求人票を上から読む順**に近い並びになっている。
- **具体例**：「完全週休2日」「社保完備」「25万〜50万」など**求人票の実際の文言**を引用する。
  これがあるので「見たことある」になる。
- **比較方法**：表記 vs 実態の対比を1行の中で作る。
- **感情の動かし方**：不安（うちの求人票にも書いてある）→ 怒り（騙されていた）→ 対策。
- **オチ**：リプ4で項目に戻らず、「情報源の読み方」そのものを1段上げて締める。
- **CTA**：あり。リプ4の最後。「後悔したくないならフォロー＋@アカウント」。
- **改行**：項目名→改行→→解説。項目間に空行1つ。リプの最後に引きの言葉を単独行で。
- **文章量**：本文約150字／リプ1〜3が各約130字／リプ4約90字。合計5ツイート。
- **文体**：→の解説は**命令形か断定**で終える（「騙されるな」「論外」）。説明口調にしない。
- **絵文字**：なし。記号は囲み数字（①〜⑫・⓬）と ↓ のみ。
