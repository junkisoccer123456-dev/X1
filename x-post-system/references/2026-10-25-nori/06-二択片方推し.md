# 原文
```
年収900万で激務の大手と、年収650万で定時の会社。
20代で選ぶべきはマジで前者です。
①20代の激務は30代の年収に変わる
②大手の看板で転職市場の評価が一段上がる
③定時の会社は後からでも行けるけど、逆は無理
まったりは30代からで十分です。
```

# 分析メモ（CLAUDE.md 2 の全観点）
- **冒頭フック**：**条件の揃った二択**。数字（年収）と働き方（激務／定時）をセットで並べる。
  読者は読み始めた瞬間に自分の答えを決めるので、続きを「採点」として読む。
- **権威性**：出さない。断定の強さだけで持たせている。
- **問題提起**：二択そのものが提起。「どちらが正しいか」を読者の頭の中に立てる。
- **興味維持の仕掛け**：2行目で**言い切る**こと。「人によります」を書かない。
  賛否が生まれるので、リプ欄と引用で伸びる。強い語（マジで）が1つだけ入る。
- **文章展開**：二択 → 断定 → 理由3つ → 言い換えの締め。わずか6行。
- **情報の順番**：理由が**時間軸**で並んでいる。
  ①今の負荷が将来どうなるか → ②市場での評価 → ③あとから取り返せるか。
  3つ目の「逆は無理」＝**不可逆性**が決め手。ここで反論が消える。
- **具体例**：年収の数字だけ。会社名も職種も出さない。**条件の組み合わせ**として置いている。
- **比較方法**：2つの選択肢の直接対比。ただし否定はしない。
- **感情の動かし方**：反発（本当に？）→ 納得（③で折れる）→ 安心（締めで選ばなかった側も肯定）。
- **オチ**：「まったりは30代からで十分です」。
  選ばなかった側を**順番の話**に落とすので角が立たない。
- **CTA**：なし。
- **改行**：二択2行＋断定1行＋理由3行＋締め1行。原文は空行なしで詰めている。
- **文章量**：約150字。短い。
- **文体**：です・ます調＋断定。1行20〜30字で揃っている。
- **絵文字**：なし。記号は囲み数字（①②③）のみ。

# ⚠️ 事実の扱い
- 二択の数字は**実在の会社の提示額として書かない**。「年収◯◯万で△△な会社」という
  条件の組み合わせとして置く（カルテ8／13・個社の断定を避ける）。
- 理由に「年収が◯万上がる」のような数字を入れない。根拠が必要になる。
- 体を壊す水準の働き方を推す使い方はしない。推すのは**負荷と引き換えに何が残るか**の話に限る。
