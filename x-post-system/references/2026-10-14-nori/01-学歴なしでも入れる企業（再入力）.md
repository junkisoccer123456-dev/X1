# 分析メモ（CLAUDE.md 2 の全観点）
- **冒頭フック**：引用符で囲んだ強調が2箇所（"20代であれば" "世界一"）。
  条件を絞って（20代）、同時に最上級を置く（世界一）。狭いのに大きい、という組み合わせ。
- **権威性**：出さない。数字の塊そのものが権威になっている。
- **問題提起**：しない。条件を並べることが提起を兼ねる。読者が自分の勤務先と勝手に比べ始める。
- **興味維持**：社名を最後まで出さない。リプまで引っぱる。
- **情報の順番**：年収 → ボーナス → 残業 → **家賃6,000円** → 制度 → 休日 → 採用率 → 離職率。
  待遇の数字の中に**生活実感のある数字**（家賃）を混ぜているのがこの型の核。
  「6人に1人が採用されている」＝自分にも可能性があると思わせるハードル下げ。
- **具体例**：数字だけ。固有名詞は本文に一切出さない。
- **比較方法**：対比なし。条件の積み上げだけ。
- **感情の動かし方**：疑い（良すぎる）→ 知りたい → 納得（無名だから）→ 自分にもできそう。
- **オチ（リプ側）**：①社名を『』で単独提示 ②「社名を知ってる人はほぼいない」＝**無名を価値に変換**
  ③事業の正体を一言で言語化（「人と機械が指で触れる接点を握り続けた会社」）
  ④働き方の具体（14時30分に帰れる）⑤採用状況＋↓↓
- **CTA**：固定ポストへの誘導はなし。「積極的に採用中↓↓」で終わる。
- **改行**：条件は「・」で1行1項目。リプは段落ごとに空行。
- **文章量**：本文約300字、リプ約300字。
- **文体**：です・ます調。「〜んですよね」「というバグ」の口語を要所に混ぜる。
- **絵文字**：なし（↓↓ は記号）。
