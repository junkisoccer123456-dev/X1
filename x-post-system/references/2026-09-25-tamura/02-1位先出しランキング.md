# 参考投稿③｜1位先出しランキング（解説なし・予防線つき）

## 原文

```
異論は全部認めます

エンジニアの職務経歴書で「あって得する」
と思う資格ランキング(採用側の主観)

1位：情報処理安全確保支援士試験(セキスペ)
2位：AWS SAP(ソリューションアーキテクト プロフェッショナル)
3位：応用情報技術者試験
4位：データベーススペシャリスト
5位：CKA(Kubernetes)
6位：AWS SCS(セキュリティ スペシャリティ)
7位：LinuC レベル2
8位：AWS SAA
9位：Oracle Java Silver
10位：基本情報技術者試験
```

# 分析メモ

## 1. 冒頭フック
- 1行目が「異論は全部認めます」。ランキングという反論されやすい形式に対して、
  先に反論を全部受け入れてしまう。これで引用リプが荒れずに、議論として伸びる。
- 予防線でありながら、同時に「議論してもいい」という許可にもなっている。

## 2. 権威性の置き方
- 見出しの末尾に「(採用側の主観)」と小さく添える。
  主観だと明示しているのに、採用側という立場で信頼が残る。うまい逃げ方。

## 3. 構造の特徴
- 1位から10位へ降順。カウントダウン型（下位から発表して1位を引っぱる）とは逆。
- 解説が一切ない。順位と名称だけ。読む負荷がゼロ。
- 結果として「なぜこの順位なのか」がリプ欄で語られる余白になる。
  解説を書かないことが、そのままコメント誘発の仕掛けになっている。

## 4. オチ・CTA
- 締めの一言なし。10位で終わる。
- CTAもなし。本文は完全に情報だけ。

## 5. 文体・見た目
- 約200字。順位が縦に10行並ぶので、タイムラインでの占有面積が大きい。
- 正式名称と略称を併記している（情報処理安全確保支援士試験(セキスペ) など）。
  検索性と読みやすさを両立させている。

## 6. カウントダウン型との違い
| | カウントダウン型 | 本パターン |
|---|---|---|
| 順番 | 下位 → 1位 | 1位 → 下位 |
| 解説 | 各順位に2行 | なし |
| 引き | 「1位は…↓」でリプに続く | 引きなし・本文で完結 |
| 冒頭 | 権威づけ | 予防線（異論は認めます） |
