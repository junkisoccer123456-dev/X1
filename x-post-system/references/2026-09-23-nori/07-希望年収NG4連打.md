# 原文
```
マイナビで数多くの転職支援をしてきましたが、この質問に多くの人が失敗します。。。
💼面接官「希望年収はいくらですか？」
😅お見送りの人1「できれば今より上がれば嬉しいです」→ 根拠ゼロ。交渉材料なし。
😓お見送りの人2「御社の規定に合わせます」→ 自己評価できない人認定。
😬お見送りの人3「正直、年収アップが一番の目的です」→ 本音すぎる。商談失敗。
😵お見送りの人4「相場が分からないのでお任せします」→ 準備不足。
🚀内定とる人「（長文の模範解答：現年収→実績→根拠→希望額→すり合わせの姿勢）」
```
# 分析メモ
- 既存「NG連打→OK提示型」と同骨格。差分が3つ
- 差分1：NGが**4連打**（3つより畳みかける）。各NGの直後に**一言斬り**（→根拠ゼロ。）が入る
- 差分2：リプに逃がさず、**本文内で模範解答を長文で見せきる**
- 差分3：絵文字でラベルを立てている（面接官／お見送り／内定）
- 模範解答が長いぶん、そのまま暗記素材として保存される
