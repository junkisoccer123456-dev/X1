# 原文
```
マイナビで転職支援して気づきましたが、転職するなら"SaaS業界"がおすすめな理由はこれ。
・景気に左右されにくい「ストック型ビジネス」
・一度導入されると簡単には解約されない
（…計25項目）
・キャリアの選択肢が年々広がる
```
# 分析メモ
- 既存「網羅リスト（↓連結）型」の派生。↓ ではなく「・」で25項目を並べる
- 差分：項目が「事実」ではなく**主張・理由**。だから網羅されるほど説得力が増す
- 差分：並び順が意図的。ビジネスモデル → 働き方 → キャリア、と読者の関心が深くなる順
- 1項目1行で完結させるのが条件。説明を足すと25行が破綻する
- ⚠️ 「20代後半〜30代で年収800万が現実的」のような数値の主張は、出典がないと書けない
