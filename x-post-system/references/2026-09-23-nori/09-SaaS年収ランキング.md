# 分析メモ
- カウントダウンランキングの**企業版**。10位から1位まで順に公開する
- 各社が「社名 → 数値2項目 → 一言評価」で完全に統一されている
- 本文は10位・9位だけ。8位以降をリプに置き、2本のリプで小出しにする
- 2軸（年収 × 残業）で並べているため、単なる年収ランキングより納得感がある
- ⚠️ 企業ごとの年収・残業の数値が主役。出典のない数字は使えないため、生成時は【　】にする
