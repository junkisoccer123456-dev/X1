# 原文
```
職場で「こいつ伸びる」と思われる口癖↓
3位「確認します」
・その場でわかったふりをしない
・小さな誠実さが信頼を積み上げる
2位「どうすればよかったですか？」
・ミスを次に活かそうとする姿勢
・同じ失敗を繰り返さない人だと伝わる
1位は…↓

【リプ】1位「次はこうします」
・反省で終わらず、行動まで示せる人
・上司が一番欲しいのはこの一言
口癖は思考の習慣です。（…解釈→一般化して締め）
```
# 分析メモ
- 3位→2位と下から上げ、**1位だけ伏せてリプへ送る**
- 各順位が「見出し＋理由2行」で統一。読むリズムが一定
- リプで1位を出したあと、順位の話を離れて**思考の習慣**という一段上の話に着地させる
- 数字の根拠が要らない（口癖＝主観のランキング）ので、断定しても嘘にならない型
