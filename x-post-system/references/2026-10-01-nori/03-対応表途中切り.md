# 参考投稿③｜対応表を途中で切る型

## 原文（元ポスト）

```
20代中盤の転職でキャリアアップした事例

【新卒】　　　　　　【転職先】
・メガバンク 　　▶ 外資系投資銀行
・大手証券 　　　▶ 外資系投資銀行
・信託銀行 　　　▶ 大手デベ
・政府系金融 　　▶ 総合商社
・総合コンサル 　▶
```

## 原文（リプ）

```
・総合コンサル 　▶ 外資系IT
・大手SIer 　　　▶ ITコンサル
・メガベンチャー ▶ 外資系IT
・総合商社 　　　▶ PEファンド
・専門商社　　　 ▶ 総合商社
・大手メーカー 　▶ 総合商社
・FAS 　　　　　▶ PEファnド
```
（原文では FAS ▶ PEファンド）

# 分析メモ

## 1. 核になっている発明
- **行の途中で切る**。最後の行を「・総合コンサル 　▶」と書いて、右側を空白のまま終える。
- 矢印の先が空いているので、視覚的に未完成の状態がそのまま引きになる。
  「続きは↓」のような言葉を一切使わずに、リプを開かせている。
- リプは、切った行をもう一度書き直してから続きを並べる。読者が迷わない。

## 2. 見出しと列の作り方
- 1行目が見出し。「20代中盤の転職でキャリアアップした事例」で対象年齢と内容が確定する。
- 2行目に【新卒】【転職先】の列ヘッダを置く。全角スペースで列を揃えている。
- 以降は「・Before　▶ After」の1行1件。説明を一切書かない。

## 3. 情報の選び方
- 個人が特定される情報を出していない。**業界・職種のレベルに丸めている**。
  （メガバンク、大手証券、信託銀行…という書き方で、社名も個人名も出ない）
- そのぶん、読者が自分の経歴を当てはめやすい。自分の左側を探す読み方になる。

## 4. 並べ方の順番
- 金融系から始まり、コンサル、SIer、ベンチャー、商社、メーカーへ。
  **業界のかたまりで並んでいる**ので、自分の業界を探しやすい。

## 5. オチ・CTA
- 締めの一言なし。CTAなし。リストで終わる。
- 解説を書かないぶん、リプ欄で「自分はこうでした」という投稿が出やすい構造になっている。

## 6. 文体・見た目
- 本文は約120字、リプは約130字。
- 絵文字は使わず、▶ と ・ と【】のみ。
- 矢印は ▶（白三角ではなく黒三角）。列の区切りとして見やすい。

## ⚠️ 運用上の注意
- 事例を出す型なので、**実在の個人が特定できる粒度にしない**。業界・職種レベルに丸める。
- 支援した人数などの実績は、アカウントファイルに登録されている範囲だけ使う。
