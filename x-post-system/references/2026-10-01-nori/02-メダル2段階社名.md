# 参考投稿②｜メダル2段階・社名リスト

## 原文（元ポスト）

```
友達が勤務してるリモートワーク可能な企業
🥈部署・職種次第で可能
・花王　　　　　・第一三共
・NTTドコモ　　・電通総研

```

## 原文（リプ）

```
🥇リモート比率が非常に高い

・富士通

・ソフトバンク
```

# 分析メモ

## 1. 冒頭フック
- 「友達が勤務してる」の一言で、情報の出どころを体験に寄せている。
  調査でもランキングでもないので、**断定の責任を負わずに社名を出せる**。この逃げ方が重要。
- 権威づけも前置きもない。1行目が見出しとして機能している。

## 2. 2段階の切り分け方
- 🥈「部署・職種次第で可能」／🥇「リモート比率が非常に高い」。
- どちらも**相対表現**で、制度を断定していない。
  「リモート可」と言い切らず「次第で可能」「比率が高い」にしている点が、実在企業を扱うときの作法。
- やめとけ（🥉）が無い。否定する群がないので、企業名を出しても角が立たない。

## 3. 並べ方
- 本文の🥈は2列（2社ずつ横並び）で圧縮。リプの🥇は1列で縦に開く。
- 同じ社数でも、本文は読み飛ばさせ、リプはじっくり読ませる設計。

## 4. 引き
- 本文の最後が「🥇リモート比率が非常に高い↓」。
  ラベルだけ出して中身を伏せる。煽り文句は使っていない。

## 5. リプ
- 本文の最後の行を見出しとして繰り返し、社名を縦に並べるだけ。
- 締めの一言もCTAもない。

## 6. 文体・見た目
- 全体で約120字。極端に短い。
- 絵文字はメダル2種のみ。
- 社名は通称でよい（Google、みずほ(IT) のように）。正式名称にこだわっていない。

## ⚠️ 運用上の注意
実在企業の制度を断定すると、事実ではなく評価が拡散する。
参考投稿のように**相対表現（〜次第で可能／〜比率が高い）に留める**こと。
制度は変わるので、投稿前に各社の採用ページで確認する前提で運用する。
