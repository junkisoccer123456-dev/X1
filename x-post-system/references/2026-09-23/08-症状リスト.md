# 原文
```
日曜の夜が憂鬱→SaaS行け
朝起きるのがつらい→SaaS行け
食欲が湧かない→SaaS行け
休んでも疲れが抜けない→SaaS行け
笑う回数が減った→SaaS行け
常に気が張ってる→SaaS行け

体調やメンタルの不調って、根性が足りないんじゃなくて、環境が合ってないサイン。
合わない場所で消耗し続けても消耗するだけ。場所を変えたら不調はなくなります。
```

# 分析メモ
- 「症状→同じ処方」を**6回繰り返す**。同じ語尾を連打することがリズムになる型
- 症状が身体感覚（睡眠・食欲・笑う回数）なので、読者が自己診断してしまう
- 前置きゼロ。1行目からいきなり症状
- 最後の2段落だけ通常文に戻り、「根性ではなく環境」と解釈を与えて着地する
- ⚠️ 体調の話なので断定しすぎない配慮が要る
