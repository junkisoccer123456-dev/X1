# 原文
```
大手SaaS企業で面接官をしてますが、
職務経歴書に"評価が下がるNG表現"がマジで頻出します...

書き手は真面目に書いているつもりでも、面接官から見ると印象を下げる表現がある。
今日は、代表的なNG表現5つを共有します。

1つ目「〇〇に努めました」
"努めた"は、成果に触れないままの言葉。面接官には"結果が出ていない"と読み取られます。
「〇〇に取り組み、〇〇を達成」と、行動と結果をセットで書く。

（2つ目〜5つ目まで同じ4行構成：NG表現→なぜ悪いか→どう読まれるか→言い換え）
```

# 分析メモ
- NG→OKの比較型だが、**リプに逃がさず本文内で5つ解説する**長尺バージョン
- 各項目が「NG表現の引用 → 何が問題か → 面接官にどう読まれるか → 言い換え」で統一
- 冒頭で「真面目に書いているつもりでも」と書き手を否定しない予防線
- 引用符で表現を囲むことで、文章内でもNGワードが目立つ
