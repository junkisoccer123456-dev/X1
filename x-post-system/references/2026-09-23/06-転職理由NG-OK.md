# 分析メモ
- 「お見送りの人」というラベルを**繰り返し**てNG例を3つ並べる（リズムで読ませる）
- NGはセリフそのまま。読者は自分の答えと照合してしまう
- 本文では正解を出さず、リプ1でOK例（これもセリフ）、リプ2で原理を4つ解説
- **二段階で引っぱる**構成（本文→リプ1で正解→リプ2で理由）
