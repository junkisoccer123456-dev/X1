# 原文
```
夏のボーナスが出た今が、未経験からSaaSに移る一番いいタイミング↓

❌やめとけ（未経験からいきなりは無理ゲー）
・A社 ・B社 ・C社
⭕️無難（未経験枠はあるけど競争率は高い）
・D社 ・E社 ・F社
本当にオススメは…↓

【リプ】本当のオススメ Best7
⑦社名｜事業説明＋有報の数値＋制度＋一言評価
⑥…①まで1社ずつリプを分けて公開
最後に「面接官として断言できるのは…」で全体の結論
```

# 分析メモ
- **❌／⭕️／本命の3段階**で格付けし、本命だけ伏せてリプへ送る
- リプは1社1リプ。カウントダウン形式なので最後まで追われる
- 各社の紹介が「事業→数値→制度→評価」で統一されている
- 締めが個別企業ではなく**方法論の結論**（バーティカルSaaSのほうが受かる）
- ⚠️ 有報の数値を使う型。**出典のない数字は使えない**ため、生成時は【　】にする
