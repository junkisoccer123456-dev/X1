# 分析メモ
- **社名を伏せたまま条件だけ出す**。読者は「どこだ？」で止まれなくなる
- 条件は待遇・選考難易度・実績が混ざっている（年収／休み／選考回数／上場）
- 「たった数回の面接でうかる」で心理的ハードルを下げてから切る
- リプで社名公開 → 事業説明 → フォロー誘導（CTAが最も強い型）
- ⚠️ 数値の塊で成立する型。**出典のない数字は使えない**ため、生成時は【　】にする
