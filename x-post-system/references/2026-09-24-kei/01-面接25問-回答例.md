## 原文（リプ1〜25）

各リプは「リプ(n/25) 質問文」＋ 改行 ＋ 「カギ括弧で囲んだ回答例（2〜4文）」の形式で統一されている。
回答例の中の固有名詞・数字は 〇〇／△△／□□／〇年／〇〇万円 のようにプレースホルダで伏せられている。

代表例（1・7・13・25）：

```
リプ(1/25)簡潔に自己紹介をお願いします。

「はじめまして、〇〇と申します。現在は△△業界で約〇年、営業職として新規開拓を中心に従事してきました。
特に顧客の課題を丁寧にヒアリングし、最適な提案を行うことで、前年対比120％の売上増に貢献しました。今回、御社の□□事業に強い興味を持ち、自分の経験を活かしてさらなる成長に貢献したいと考え応募いたしました。」
```

```
リプ(7/25)あなたの短所は何ですか？

「完璧を求めるあまり、一つのタスクに時間をかけすぎてしまう傾向があります。
しかし、近年は優先順位付けを意識し、重要度の高い業務から着手することで、効率よく成果を出せるように改善しています。具体的には、ToDoリストを使い、毎朝タスクの見直しを行う習慣を身につけました。」
```

```
リプ(13/25)何か質問はありますか？（逆質問）

「はい、2点お伺いしたいです。1つ目は、御社の中で成果を出して活躍されている方に共通する特徴はありますか？
2つ目は、入社1年目に期待される役割について具体的に教えていただけますか？自身が御社で成長するために、事前に理解しておきたいと考えております。」
```

```
リプ(25/25)仕事での失敗経験とその教訓は？

「新人時代、重要な商談のスケジュール確認を怠り、クライアントとの信頼を一時的に損ねたことがあります。
その経験から、タスク管理の徹底と“報・連・相”のタイミング強化を習慣化し、以後は大きなミスを防げるようになりました。今では、上司や同僚からも“安心して任せられる存在”と言ってもらえています。」
```

（2〜6、8〜12、14〜24も同じ形式。全文はユーザー入力を参照）

# 分析メモ

## 1. 冒頭フック・権威性
- 「衝撃すぎました...」という感情の漏れから入る。まとめ投稿に見えない入り方。
- その直後に「大手メーカーで人事部長してますが」で立場を置く。感情＋立場の二段構え。

## 2. 問題提起
- 「面接対策せずに来る人がいる」→「ほぼ確実に内定を取れない」と断定。
- 続けて「本来はポテンシャルがあるのに準備不足で落ちる。勿体無い...」と読者側に立つ。
  責める構図ではなく、もったいないという言い方にしているので刺さっても反発が出にくい。

## 3. 興味維持の仕掛け
- 「質問なんて大体決まってます↓↓」で、読者の不安（何を聞かれるか分からない）を一撃で解消する宣言。
- 25項目を ↓ で連結。量そのものが価値になる。スクロールが止まらない。
- 順番が選考の流れ順（自己紹介 → 志望理由 → 経験 → 将来 → 条件 → 該当者のみ → 視野を見る質問）。
- 17・18に「（該当者のみ）」と注記を入れているのが上手い。自分に該当する人が強く反応する。

## 4. オチ・CTA
- 「準備しなければ確実に落ちます。それぞれの回答例をまとめたのでぜひ参考に↓↓」
- リストで不安を煽って終わらせず、解決策（回答例）をリプに置く。リプを開く理由が明確。

## 5. リプの構造
- 「リプ(n/25) 質問文」＋回答例。25本すべて同じ形。
- 回答例はカギ括弧で囲み、そのまま声に出せる文になっている。
- 2〜4文で、必ず「事実 → 打ち手 → 現在の状態／志望への接続」の順。
- 固有名詞と数字はプレースホルダ。読者が自分の情報を入れるだけで使える設計。

## 6. 文体・見た目
- 本文は約900字、リプは各120〜200字。
- 絵文字なし。記号は ↓ と ↓↓ のみ。
- 三点リーダ「...」を感情表現に使っている（衝撃すぎました... 勿体無い...）。
