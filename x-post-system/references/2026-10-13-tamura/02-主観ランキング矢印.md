# 原文
```
個人的に、資格そのものより勉強内容が役立ったIT資格ランキング

5位：ITIL
→ ITサービス管理

4位：Java Gold
→ プログラミングの基礎を深く理解

3位：AWS認定
→ クラウドの基礎

2位：応用情報
→ IT知識を広く整理

1位：PMP
→ プロジェクト管理
```
# 分析メモ
- **冒頭フック**：「個人的に、」が予防線。順位の根拠を主観だと先に認めるので、
  出典のない並びでも成立し、「順位がおかしい」という反応が否定ではなく議論になる。
- **見出しのひねり**：「資格そのものより勉強内容が役立った」。ただのランキングではなく
  **選び方の宣言**になっている。この一句があるから、同じ5つを並べても意味が変わる。
- **権威性**：明示しない。自分が通ってきたという前提だけで成立している。
- **興味維持**：順位（1位を知りたい）＋矢印の右（各行に小さな答え）の二重。
  5項目なので1位までのスクロールが短く、離脱しにくい。
- **情報の順番**：下位＝範囲が狭い／上位＝汎用性が高い、という順で上がる。
- **具体例**：固有名詞（資格名）をそのまま出す。ここは主観の対象ではなく事実なので強い。
- **比較方法**：対比なし。項目と「得られたもの」の対応のみ。
- **オチ・締め**：なし。1位で終わる。
- **CTA**：なし。
- **改行**：見出しの後に空行1つ。項目ごとに空行を挟んで縦に伸ばす（Gのような詰め方はしない）。
- **文章量**：全体200字前後。矢印の右は10〜25字。
- **文体**：項目は固有名詞、右は体言止め。です・ます調を使わない。
- **絵文字**：なし。
