# 誘導先記事：キーエンス中途の年収は平均2,178万円｜人事部長が勝手に分析した面接対策（kei）

保存日：2026-11-05 / ユーザー提供（kei自身の記事）
※記事冒頭に「PR：株式会社イズルの転職支援サービスの広告を含む」の表記あり。末尾でイズルの無料相談へ誘導。

要点：
- 平均年間給与は約2,178万円（2026年3月期・有価証券報告書）。直近3期：2,067万円→2,039万円→2,178万円。平均年齢約35歳、平均勤続年数約11年
- 連結売上高1兆1,692億円、営業利益5,957億円（営業利益率約51%）
- 年齢別・等級別の年収は口コミ・推計（参考値）。中途の初年度年収の公開データは見つからず
- 面接で見られるのは「実績の再現性」と著者は分析。理由は3つ（付加価値で稼ぐ会社／短時間で構造的思考を見る／説得力・反論への切り返し）。面接の進め方は口コミベースの情報
- 準備3つ：①実績を「数字＋再現できる理由」で（成果の数字／課題の分解／自分の行動／他でも使える理由）②「やめた理由」ではなく「次に出したい価値」③反論質問で模擬面接（受け止める→事実と数字で返す→再現性に戻す）
- 想定質問5選、合う人・合わない人
- 結び：面接対策の質はエージェントで変わる→イズル（内定率重視、キャリア設計から、代表は元キーエンス）
