# 分析メモ（CLAUDE.md 2 の全観点）
- **冒頭フック**：【】の見出しで現象を言い切る。助言ではなく**観測**なので身構えられない。
  続く2行目が「最初と今、全然違う会社になっていませんか？」の問いかけで、
  読者が自分の過去と現在を比べる作業を始める。
- **権威性**：「キャリア相談をしていて、かなり多いです」の1行のみ。数字も年数も出さない。
  相談を受けている立場であること自体が権威になっている。
- **問題提起**：読者が問題だと思っているもの（不採用）より**一段深い場所**（軸の崩壊）を指す。
  これが「分かってくれている人」という読後感を作る核。
- **興味維持**：セリフ4行 → 出来事4行 → 矢印4段、と**かたまりの形を変えながら**進む。
  同じ体裁が続かないので長文でも目が滑らない。
- **文章展開**：初期状態 → 悪化 → 劣化の可視化 → 転換 → 救い → 問いに戻す → 二項対比 → 再定義。
- **情報の順番**：劣化の矢印を**救いの前**に置いている。先に落としてから持ち上げるので効く。
- **具体例**：固有名詞も数字も使わない。かわりに内心のセリフ（「高望みしていたのかな」）を具体に使う。
- **比較方法**：最後の「納得して変えた／自信を失って下げた」の二項対比が主役。
  **条件を変えること自体は否定していない**ので、現実に合わせて動いた人を切り捨てない。
- **感情の動かし方**：自覚（自分だ）→ 不安（軸が壊れている）→ 救い（自分の価値ではない）→
  行動（原点に戻る）。
- **オチ**：「〇〇は〜ゲームではありません。〜を決める活動です」の再定義。
- **CTA**：フォロー誘導なし。**読者への問いかけ**（経験を教えてください／逆に譲らなかったものは）。
  リプで体験談が集まる設計。
- **改行**：矢印は単独行。セリフは1行1つ。段落間に空行1つ。
- **文章量**：約1,100字。
- **文体**：です・ます調。「〜してほしい」の希望形が多い。断定で押さない。
  ※原文の一人称は「私」。kei は「僕」なので出力時に置き換える（CLAUDE.md 7／カード6）。
- **絵文字**：なし。
