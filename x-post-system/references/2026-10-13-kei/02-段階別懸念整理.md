# 分析メモ（CLAUDE.md 2 の全観点）
- **冒頭フック**：【読者を名指す括弧見出し】＋不安をそのままセリフにした1行。
  読者が聞きたかった質問が1行目にあるので、読む理由の説明が不要。
- **権威性**：🔶の1行（「【立場】としてまず伝えたい」）だけ。記号で立場宣言を区切っている。
- **問題提起の作り**：**先に不安を否定してから「ただし」で条件を出す**。
  この順番なので、残酷な内容でも最後まで読まれる。逆順だと脅しになる。
- **興味維持**：程度別3段階。読者は自分がどの段落にいるかを探すので、飛ばし読みができない。
  しかも段階が進むごとに確認の**深さの種類**が変わる（事実 → 背景 → 採用後のリスク）。
  これが「長いほど不利」を仕組みとして納得させている。
- **文章展開**：不安の受け止め → 否定 → 段階別の確認事項 → 整理の順番 → ケース別 →
  やりすぎ注意 → 配分の数字 → 相手の本音 → 命令形 → 再定義 → 保存。
- **具体例**：各段階の「聞かれること」が**実際に飛んでくるセリフ**。要約せずカギ括弧で出している。
  ここが準備にそのまま使えるので保存される。
- **比較方法**：対比ではなく**段階の積み上げ**。前の段階の確認事項が消えず、上に増えていく。
- **感情の動かし方**：不安 → 安心（即NGではない）→ 緊張（確認は増える）→ 手順（やることが分かる）
  → 許可（謝らなくていい）。
- **数字の使い方**：【過去2：現在3：未来5】。程度の話を**数字1つに畳む**ので記憶に残る。
  出典が要る統計ではなく配分の目安なので、根拠のない数字にはならない。
- **オチ**：再定義（【過去を弁明する時間】ではなく【懸念を解消して現在と未来を伝える時間】）。
- **CTA**：フォロー誘導なし。**保存誘導**のみ（「面接前に見返せるよう、ぜひ保存を！！」）。
- **改行**：記号で階層を作る（🔶立場／◆段階／▪️ケース／【】キーワード）。
- **文章量**：約1,400字。
- **文体**：です・ます調。終盤だけ体言止めの短文を3行並べてリズムを変える。
  ※原文の一人称は「私」。kei は「僕」なので出力時に置き換える。
- **絵文字**：🔶 と ▪️ を使用。**CLAUDE.md 7 に従い、そのまま再現する**
  （kei カード8の「絵文字なし」より優先）。
